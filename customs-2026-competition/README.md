## 에이전트 사용법

이 저장소를 Claude Code로 열면 `customs-idea-award-agent`가 사용 가능한 서브에이전트 목록에 나타난다. 예:

> "customs-idea-award-agent를 써서 K-푸드 수출 관련 아이디어를 3개 제안해줘"

또는 Agent 도구를 `subagent_type: "customs-idea-award-agent"`로 직접 호출.

## 핵심 요약 (TL;DR)

- 배점: 구체성20 · **공공데이터·AI활용25** · **실현가능성25** · 독창성20 · 효과성10, **국산 AI 가점 +5**
- 관세청 데이터는 필수, 10페이지 이내, 붙임5 6개 목차 고정
- 2026년 공고문이 직접 예시로 든 **K-Food/K-컬처** 소재, 2025년 최우수 '리틀장보고'(K-뷰티) 계열이 유망 방향
- 정부 데이터 포털은 로그인 없이 자동 조회가 막혀 있어, **응모 전 반드시 사람이 직접 로그인해 최신 API 스펙을 재확인**할 것
- 유사·중복 제안은 먼저 제출한 팀이 우선권 → 방향이 정해지면 빠르게 확정·제출 권장

## 한계 및 주의

이 리서치는 자동화된 웹 조사(WebSearch + GitHub 오픈소스 라이브러리 교차검증) 기반이며, data.go.kr/tradedata.go.kr/unipass.customs.go.kr 원문 페이지는 봇 차단(HTTP 403)으로 직접 열람하지 못했다. 문서 내 "신뢰도: 확인됨/불확실/미확인" 표기를 반드시 참고하고, 실제 응모 전 각 포털에 로그인해 최신 데이터 스펙을 재확인해야 한다.
