## 1. 아이디어 개요

**관세판정 예측·실측 신뢰루프(VeriTandem)** — AI가 수출입 신고의 리스크(오분류·언더밸류 가능성)를 예측해 우선순위 큐를 만들고, **관세청 심사위원이 그 큐를 검토하며 내리는 실제 판정(승인/시정/반려)** 을 정답 레이블로 매주 자동 재학습하는 설명가능 리스크 스코어링 엔진. 세관의 미확인 API 필드에 의존하지 않고, 사람이 어차피 수행하는 검토 행위 자체를 검증 신호로 삼는다는 점이 핵심 개선점이다.

## 2. 세부 내용

- **창안 동기**: 관세청 심사관은 전체 신고를 다 볼 수 없고(HS코드 전문가 간 불일치율 30%↑), 위험탐지형 아이디어는 역대 수상작 중 드문 빈자리다. 그러나 초안(텐덤)이 의존했던 "화물통관진행정보가 판정결과를 노출한다"는 가정은 검증되지 않았다 — 이번 안은 이 가정을 완전히 제거했다.
- **핵심 기능**: (1) 국산 sLLM+RAG 기반 리스크 스코어링(HS코드 불일치·이상저가 탐지) (2) 우선순위 큐 생성(정보획득량 기준) (3) 심사위원 판정 입력 UI(기존 업무 흐름에 자연스럽게 삽입, 추가 노동 최소화) (4) 판정 결과를 정답 레이블로 자동 축적하는 오차 레지스트리 (5) 분기별 인간 위원회 검토·롤백 게이트.

## 3. 폐쇄루프 아키텍처 (핵심 개선)

**① 예측**: 매일 배치로, 국산 sLLM(RAG, 품목분류 국내사례 판례 인용)이 신규 신고 중 HS코드 불일치 의심도·이상저가 의심도를 스코어링해 우선순위 큐를 생성한다. 사용 데이터: 관세청_HS부호, HSK별 신성질별 분류, 품목별 국가별 수출입실적(가격분포 산출), 관세율표, 세관장확인대상물품.

**② 실측(★재설계된 핵심)**: 심사위원이 이 큐를 검토하며 내리는 실제 판정(이상없음/재분류 필요/추가서류요청 등)을 **UI에 1클릭으로 입력**받는다 — 이것이 이 시스템의 유일하고 확실한 정답 레이블이다(미확인 API 필드에 의존하지 않음). 보조 신호로 관세청_화물통관진행정보의 확인된 필드(통관진행상태: 수리완료 vs 장기미수리)를 "약한 참고신호"로만 사용하며, 이를 확정 판정으로 과장하지 않는다. 추가로 관세청_수출/수입 10일 단위 잠정치 vs 월간 확정치(모두 존재가 확인된 데이터)로 **품목군·국가군 단위의 거시적 정확도**도 별도로 자가검증한다.

**③ 자가교정**: 매주, 심사위원 판정 레이블과 AI 예측을 대조해 오탐/미탐을 태깅하고 스코어링 가중치를 증분 재학습한다. 이 오차이력 데이터셋(언제·어떤 품목·어떤 이유로 AI가 틀렸는지)이 시간이 지날수록 누적되는 것 자체가 후발주자가 복제할 수 없는 자산(해자)이다. 분기별로 인간 위원회가 전체 성능 추이를 검토하고, 문제가 발견되면 이전 버전으로 롤백할 수 있다.

## 4. 데이터 및 AI 기술 활용 방안

- **필수(관세청)**: 관세청_화물통관진행정보(15126268, 보조신호로만), 관세청_HS부호(15049722), HSK별 신성질별 분류(15049720), 세관장확인대상물품(15101589), 품목별 국가별 수출입실적(15100475, 확인 필요), 국가별 수출입실적(15101612), 품목번호별/국가별 관세율표(15051179/15051176), 수출 10일 단위 잠정치(15157941 외 3종)
- **획득의 지속성**: 위 데이터셋 대부분은 data.go.kr OpenAPI로 인증키 발급 후 정기 호출 가능(월 1회~10일 단위 갱신). 배치(일 1회) 처리로 설계해 실시간 폴링 대비 API 호출량·비용을 예측 가능한 수준으로 낮췄다.
- **AI 기술**: 국산 sLLM(국내 오픈소스 모델 파인튜닝) + RAG(품목분류 국내사례 인용, 설명가능) + 규칙기반 세율계산 레이어 + 이상탐지(2025 Nature Scientific Reports 게재 Dual-learning XGBoost류를 벤치마크로 인용). **화주별 개인화는 개별 파인튜닝이 아니라 공유모델+메타데이터 필터링 RAG로 구현**(확장성 확보).

## 5. 실현 가능성

- 사람 심사위원의 실제 판정을 레이블로 쓰는 구조이므로, 미확인 API 필드 존재 여부와 무관하게 폐쇄루프가 성립한다(가장 큰 리스크 제거).
- 배치 처리(일 1회) + 우선순위 큐 방식으로 실시간 폴링 대비 인프라 비용이 예측 가능.
- 1차 목표는 관세청 내부 위험관리시스템(P/L·C/S)의 **대체가 아니라 설명가능성 보강 레이어**로, 관세청이 이미 하는 일을 정교화하는 포지셔닝이라 조달 저항이 낮다.

## 6. 차별성

기존 3개 최우수/수상작(쉬핑노트=알림, 오픈태리프=단발성 시뮬레이션, 핀스킨=예측만)과 달리, **사람의 실제 검토 판정 자체를 정답 레이블로 삼아 매주 순환하는 구조**라는 점에서 근본적으로 다르다. 특히 API 필드 불확실성이라는, 앞선 초안이 안고 있던 근본적 리스크를 설계 단계에서 제거했다는 것이 이번 최적화의 핵심 성과다.

## 7. 기대 효과

관세청 심사관의 검토 처리량 확장(정보획득량 기준 우선순위), 성실 신고자의 오탐 감소(설명가능 AI), 시간이 지날수록 정확해지는 국가 자산으로서의 오차이력 데이터셋 축적.

## 8. 정직하게 남는 리스크

- 심사위원이 UI에 판정을 입력해주는 것을 전제로 하므로, **실제 관세청 업무 프로세스에 이 입력 단계를 자연스럽게 끼워넣을 수 있는지**는 관세청과의 협의가 필요한 부분이며, 이는 기획서에서 "1차 PoC로 검증할 가설"로 정직하게 서술해야 한다.
- TAM은 여전히 크지 않다(B2G 단일 구매자 중심) — 유니콘 스토리보다는 "정책정합성 기반 B2G 파일럿 → 데이터자산 축적 → B2B 확장"이라는 현실적 스토리로 승부한다.
