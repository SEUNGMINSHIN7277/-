# 이노베이티브 AI × 관세청 공공데이터 — 아이디어 기획 후보 (2단계 에이전트 결합 브레인스토밍 결과)

> `customs-idea-award-agent`(관세청 공모전 규칙·데이터·수상패턴 전문)와 `innovative-ai-expert-agent`(폐쇄루프·랩파일럿·인간병목해결 전문) 두 에이전트의 지식을 결합한 워크플로우 결과. 3개 렌즈(품목분류/리스크인텔리전스/무역예측)에서 후보 6개 생성 → 관세청 심사기준+이노베이티브 AI 체크리스트로 평가 → 상위 3개로 종합.

## 이노베이티브 AI 3대 원칙 (모든 후보에 공통 적용)

1. **폐쇄루프 24시간**: 예측 → 실제 결과 관측 → 자가교정이 사람 개입 없이 반복
2. **랩파일럿(실세계 grounding)**: 시뮬레이션이 아니라 실제 세관 판정·실제 통관결과·실제 무역통계 발표라는 "물리적 진실"과 지속 대조
3. **인간 병목 해결**: 심사관/관세사가 물리적으로 다 볼 수 없는 지점(전수 검토, 반복 이력 복기, 사후 통계 대기)을 AI가 24시간 대신 채움

## 🥇 1순위 추천: 통관판정 괴리 탐지 자가교정 리스크엔진 (가칭 '텐덤')

**한줄**: 신고인의 선언(HS코드·가격)과 세관의 실제 판정 결과 사이의 괴리를 AI가 24시간 스코어링하고, 실제 통관진행 결과로 매주 자동 채점·교정하는 상시가동 리스크 엔진

- **문제정의**: 심사관은 전체 신고를 다 볼 수 없고(HS코드 분류 전문가간 불일치율도 30% 초과), 위험탐지형 아이디어는 역대 수상작 중 드문 빈자리다.
- **폐쇄루프**: ①예측 — 국산 sLLM+RAG가 물품설명만으로 HS코드 재추정 + 신고가격 이상저가 여부 스코어링 → ②실측 — 화물통관진행정보 API로 실제 통관진행상태(수리/보완요구/보류)를 지속 관측, 예측과 실측을 별개 이벤트로 감사로그에 기록 → ③자가교정 — 매주 오탐/미탐을 태깅해 가중치 증분 재학습
- **데이터 매핑**: 화물통관진행정보(15126268), HS부호(15049722), HSK별 신성질별 분류(15049720), 세관장확인대상물품(15101589), 품목별 국가별 수출입실적(15100475, 접근경로 재확인 필요), 국가별 수출입실적(15101612), 품목번호별/국가별 관세율표, 관세환율정보
- **차별성**: 쉬핑노트(알림만, 예측 없음) / 핀스킨(예측만, 재검증 없음) / 오픈태리프(단발성 시뮬레이션, 실제 판정과 대조 없음) 모두와 "되먹임 루프 유무"로 구조적으로 다름
- **예상 점수**: 구체성 18~19, 데이터·AI활용 23~24, 실현가능성 22~23, 독창성 18~19, 효과성 8~9 (+국산AI가점 4~5) → **약 93~99점**
- **리스크**: 통관진행상태 API의 상세 필드(보완요구/경정 구분) 미확인, 15100475 접근경로 미확인 → 응모 전 반드시 로그인 후 재확인 필요. HS 재추정은 "참고의견"이며 최종판단은 인간(관세사·심사관) 승인 필수.

## 🥈 2순위: K-푸드 역직구 De Minimis 자가검증 워치독

**한줄**: 미국·EU 소액면세(De Minimis) 폐지가 K-푸드 역직구 셀러에 미치는 영향을, 관세청 10일 단위 잠정치로 실시간 채점하고 스스로 재예측을 교정하는 정책효과 조기경보

- **폐쇄루프**: 정책 발효 시 반사실(counterfactual) 기준선 설정 → 10일마다 나오는 잠정치 실측과 대조해 정책효과 추정 누적 → 월간 확정치로 자가채점, 오차를 다음 분기 모델에 반영
- **데이터 매핑**: 수출 10일 단위 잠정치(4종: 15157941/15157908/15157901/15157909), 품목별·국가별 수출입실적, 관세율표, HS부호
- **차별성**: JAI(2024, 정적 1회 분석)와 달리 지속 갱신되는 조기경보 시스템. 리틀장보고(2025 최우수, 정적 컨설팅)와도 다름. 2026년 공고문이 명시한 K-Food 소재와 정확히 부합.
- **예상 점수**: 약 86~91점 (+국산AI가점 4) → **약 90~95점**
- **리스크**: 반사실 추정은 본질적으로 검증 불가능한 가정 포함 — "유일한 정답"처럼 과장 금지, 불확실구간 명시 필요.

## 🥉 3순위: 화주별 통관판정 오차 레지스트리 (Tariff Drift Registry)

**한줄**: 화주마다 축적되는 "AI 예측 vs 세관 실제 확정" 사이의 반복적 어긋남을 학습해 다음 신고 전 개인화 조기경고를 주는 B2B SaaS

- **차별성**: 화주 단위 개인화 폐쇄루프는 기존 수상작에 전혀 없는 가장 독창적인 지점(독창성 19~20/20)이나, 콜드스타트 문제와 좁은 B2B 타깃으로 실현가능성·효과성에서 1·2순위보다 낮음(88~94점)
- 1순위 아이디어의 "화주 반복패턴" 피처로 흡수해 고도화 버전으로 결합 가능
