1. 아이템명
SENTINEL-Core — “AI가 위험한 답을 말하기 전에, 생각하는 순간 잡아내는 온프레미스 LLM 안전 엔진”
은행·병원이 자기 서버에서 돌리는 거대언어모델(LLM)의 내부 연산 상태를 실시간으로 들여다보고, 규정위반·환각·민감정보 누출을 출력 생성 이전에 탐지·억제하는 추론 거버넌스 소프트웨어.
2. 착안배경 (개발 동기 · 목적 · 필요성)
2-1. 시장을 '법'이 강제로 만들고 있다 (개발 동기)
2026년 1월 22일, 대한민국 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법(AI기본법)」이 시행되었다. EU에 이어 세계 두 번째 종합 AI법으로, 고영향(high-impact) AI에 대한 안전성·신뢰성 확보 의무, 데이터주권, 설명·검증 책임을 규정한다.
출처: https://www.cooley.com/news/insight/2026/2026-01-27-south-koreas-ai-basic-act-overview-and-key-takeaways
이 법과 기존 개인정보보호법·금융권 망분리·의료데이터 규제가 합쳐지면서, 은행·보험·병원·공공기관은 외부 클라우드 LLM을 그대로 쓸 수 없게 된다. 민감 데이터가 외부로 나가면 안 되기 때문이다. 그 결과 이들은 자기 서버 안(온프레미스)에서 LLM을 직접 돌리는 방향으로 빠르게 이동하고 있다. 정부도 주권 AI에 대규모 투자(MSIT 5개 컨소시엄 $381M, 2027년까지 GPU 50만 장 계획)를 집행 중이다.
출처: https://introl.com/blog/south-korea-735b-sovereign-ai-initiative-infrastructure-requirements-opportunities
2-2. 그런데 온프레미스에는 '안전장치'가 없다 (문제 정의)
클라우드 LLM에는 거대 벤더의 정교한 안전장치가 딸려 오지만, 기관이 자기 서버에 직접 올린 오픈 LLM(Llama·Gemma·Qwen 계열)에는 그것이 딸려 오지 않는다. 기관은 두 가지 위험에 그대로 노출된다.
위험 | 구체 사례 | 비용
환각(Hallucination) | 존재하지 않는 약관·판례·약 용량을 그럴듯하게 생성 | 불완전판매·오진 → 소송·제재
규정 위반 | 고객 개인정보(PII) 노출, 금융소비자보호법·의료법 위반 응답 | 과징금·영업정지·신뢰 붕괴
규제산업에서는 이런 사고 단 1건이 회사 존립을 위협한다. 그래서 안전장치 없이는 LLM 도입 자체를 못 한다. AI 가드레일 시장이 온프레미스 65.5%, 금융(BFSI) 30.2% 비중으로 형성된 것이 이 수요를 방증한다.
출처: https://market.us/report/ai-guardrails-market/
2-3. 기존 안전장치(출력 필터)는 구조적으로 부족하다 (기존 해법의 실패)
현재 시중 가드레일(NeMo Guardrails, Llama Guard 등)은 거의 전부 '출력 후 검사(output filtering)' 방식이다. LLM이 답을 다 만든 뒤 그 답 텍스트를 별도 검사 모델에 다시 통과시켜 위험하면 차단한다. 여기에는 세 가지 구조적 결함이 있다.
① 느리고 비싸다 — LLM 답 생성 + 검사 모델 추가 호출 = 추론을 두 번 돌리는 셈. 온프레미스는 GPU가 한정돼 이 추가 비용이 치명적이다.
② 우회된다 — 검사 모델은 완성된 표면 텍스트만 본다. 질문을 비틀거나(jailbreak·paraphrase) 돌려 말하면 같은 위험 의도가 통과한다.
③ 사후 대응이다 — 이미 위험한 생각을 다 한 뒤 결과만 지운다. 근본 차단이 아니다.
결론(필요성): 법이 온프레미스 LLM을 강제하는데, 온프레미스에는 안전장치가 없고, 있는 방식(출력 필터)은 느리고·우회되고·사후적이다. "빠르고, 우회 불가능하고, 사전 차단하는" 새로운 종류의 안전 엔진이 반드시 필요하다. 그것이 SENTINEL-Core다.
2-4. 왜 지금(Why Now)인가
법(촉발): AI기본법 시행으로 온프레미스 안전 수요가 '추세'가 아니라 '법적 의무'가 됨.
기술(가능): 2024~2025년 희소 오토인코더(SAE) 기반 기계적 해석가능성이 연구→생산 단계로 성숙. Google 공개 SAE 인프라(Gemma Scope) 덕분에 거대 자본 없이 학생팀이 핵심 기술을 부트스트랩할 수 있는 첫 시점.
시장(성장): AI 가드레일 시장 CAGR 65.8%(2034년 $109.9B 전망, market.us).

4. 보유기술 (경쟁력 기술 · 확보방안 · 기술 파급효과)
4-1. 핵심 기술의 작동 원리 (논리적 빈틈 없는 설명)
SENTINEL-Core는 'LLM의 내부 생각을 읽고, 위험한 생각이 결론이 되기 전에 개입'한다. 단계별로 정확히 설명한다.
(1) LLM의 '내부 활성화'란 무엇인가
LLM은 입력 문장을 여러 층(layer)을 거쳐 처리하며, 각 층마다 고차원 숫자 벡터인 활성화(activation)를 만든다. 이 활성화가 곧 모델의 '현재 생각 상태'다. 최종 출력 토큰은 이 내부 상태에서 마지막에 결정된다. 즉, 위험한 출력은 항상 위험한 내부 상태를 거쳐 나온다. (이것이 사전 차단이 가능한 근본 이유)
(2) 왜 그동안 내부 상태를 못 읽었나 — 그리고 무엇이 풀렸나
내부 활성화는 한 뉴런이 여러 개념을 겹쳐 표현하는 다의성(polysemanticity·중첩) 때문에 사람이 직접 해석할 수 없었다. 2024~2025년 희소 오토인코더(SAE)가 이를 풀었다. SAE는 빽빽하게 얽힌 활성화를 '개념 하나당 하나씩 대응하는 희소한 특징(feature) 다발'로 분해한다. 예: '규정을 인용하는 중', '특정 약 용량을 말하는 중', '근거 없이 추측 중(환각 징후)', '개인정보가 포함됨' 같은 해석 가능한 개념 축이 분리되어 나온다.
출처: Concept Bottleneck SAE: 해석성 +32.1%·조종성 +14.5% 보고 — https://arxiv.org/abs/2512.10805 / 공개 SAE(Gemma Scope) 활용 가능
(3) 탐지 → 개입(steering)
각 feature는 활성화 공간에서의 '방향 벡터'다. 따라서 SENTINEL-Core는 추론이 진행되는 그 한 번의 forward pass 안에서:
① '위반/환각/민감' feature가 임계치 이상으로 켜지는지 실시간 탐지하고,
② 켜지면 그 방향을 억제(clamp)·교정(redirect)해, 위험한 결론이 토큰으로 출력되기 전에 진로를 바꾼다.
(4) 왜 출력 필터보다 10배 우월한가 — 제1원리 논증
지연·연산: 표현공간의 선형 개입은 지금 돌고 있는 forward pass 내부에서 종료된다. 별도 검사 모델을 추가로 자기회귀 디코딩할 필요가 없다. 출력 필터는 본질적으로 추론을 두 번(생성+검사) 하지만, 우리는 한 번 안에서 끝낸다 → 구조적 지연·비용 우위(arXiv 2503.16851).
우회 저항: 우리는 표면 단어가 아니라 의미 표현(의도)에 개입한다. 질문을 비틀어도 내부에서 같은 위반 개념이 켜지면 잡힌다 → 패러프레이즈·jailbreak 저항.
사전성: 결과를 지우는 게 아니라 결론이 형성되기 전 진로를 바꾼다.
※ '10배'라는 배수 자체는 [가설]이며, 6개월 PoC에서 탐지율·오탐률·추가지연(ms)을 벤치마크로 입증한다. 다만 메커니즘상의 우위(추가 모델 호출 제거, 의미 개입)는 확정적이다.
4-2. 경쟁력 있는 기술인가 — '래퍼가 아니다' 증명
래퍼 킬 테스트: '유능한 팀이 공개 API·오픈소스로 주말 안에 복제할 수 있는가?' → 불가능. 가치가 화면(UI)·단순 통합이 아니라 ①모델 내부 표현 개입 알고리즘, ②수개월치 폐쇄 도메인 데이터로 만든 규정개념 사전, ③온프레미스 인증·진입에 있기 때문. 이는 '기존 서비스 + LLM API 호출'이 아니다.
3중 해자:
① 내부 steering 코어 알고리즘 — 일반 성능을 훼손하지 않으면서 위반 개념만 선택적으로 억제하는 개입 기법(난이도 최상).
② 한국 금융·의료 규정 concept feature 사전 — 공개 법령·감독당국 가이드라인 + 합성 위반 사례 + PoC 고객 감사로그로 축적되는 폐쇄 데이터. 쓸수록 쌓이는 복리 해자.
③ 온프레미스 진입·인증 장벽 — 첫 기관 레퍼런스가 후발주자를 구조적으로 차단.
4-3. 핵심 기술의 정직한 약점과 확보(극복) 방안
이 사업의 모든 가치는 'SAE feature가 위반·환각 개념을 신뢰성 있게(낮은 오탐으로) 분리할 수 있다'는 가정 위에 선다. 오탐(멀쩡한 답까지 차단)이 많으면 제품 가치가 무너진다. 이 리스크를 숨기지 않고 검증 계획으로 정면 관리한다.
기술 리스크 | 확보·극복 방안
① feature 신뢰성/오탐 (최대 리스크) | 6개월 PoC 합격 KPI를 탐지율·오탐률·지연으로 못 박음 + 백업 출력필터와의 하이브리드 안전 아키텍처(청구항③)로 안전 하한 보장 + 차세대융합기술연구원 자문과 공동 벤치
② 기반모델 업데이트 시 feature 변동 | 모델 갱신 시 도메인 feature를 자동 재추출·재정렬하는 파이프라인(청구항②)을 제품에 내장

4-4. 기술 파급효과
산업: 규제 때문에 LLM 도입을 미뤘던 금융·의료·공공이 안전하게 AI 도입 → 한국 주권 AI의 '안전 인프라 계층' 형성.
기술: 기계적 해석가능성(설명가능 AI)을 연구 도구에서 생산 안전 제품으로 끌어내려 검증가능 AI 표준에 기여.
사회: AI 사고(환각·개인정보 유출) 예방 → 국민 신뢰 제고, AI기본법의 신뢰 기반 조성에 직접 부합.
특허(IP 확보): 청구항① 폐쇄 규제도메인 텍스트로부터 concept feature 추출+forward pass 중 탐지·억제·교정 / 청구항② 모델 업데이트 시 feature 자동 재추출 / 청구항③ 내부개입+백업 출력필터 하이브리드 안전 아키텍처. 영업비밀(규정 feature 사전) 병행, 제출 전 청구항 비공개(공지예외 12개월).
