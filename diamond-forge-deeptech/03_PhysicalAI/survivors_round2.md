## 결합 설계 결정
S2(센서불변 표현)·S3(배포시스템)·S5(품질검사)는 **단독으론 약하지만 S1과 결합 시 강함**을 Phase 2에서 확인. 따라서 두 경쟁 구도를 만든다:
- **후보 α = S1+S2+S5(데이터 엔진 코어)** vs **후보 β = S4 IndustrialVLA(특화 파운데이션)**.
- S3(DeployMinutes)는 α의 제품 포장(GTM)으로 흡수.

## 후보 α — **TACTILE DATA ENGINE for Contact-Rich Assembly** (S1+S2+S5+S3)
**한 줄:** 이미 깔린 로봇팔 + $15급 촉각센서 위에서, 부품 CAD 한 장으로 삽입·조립 정책을 **수일→수십분**에 세우고, 현장 실패가 모든 고객의 정책을 함께 키우는 접촉리치 조립 데이터 엔진.

- **첫 매출:** 경기도 HMLV 전자·커넥터 조립 SME 파일럿. 셀당 프로그래밍 $18,750~80,000 / 150~400h를 대체 → 명확한 ROI. 스마트공장+ 보조 75% 활용.
- **24개월 빌더블:** π0/OpenVLA·Isaac Lab·TacSL·DIGIT 오픈 인프라 위에서 **데이터 엔진+sim2real 잔차+센서불변 표현**을 4인 ML/SW팀이 구축 가능. 하드웨어 양산 0. ✅
- **모트 깊이:** 누적 접촉/촉각/실패-보정 데이터 = 네트워크 효과. SOTA가 신규 커넥터마다 ~30분 사람 개입·45~70% 일반화에 머무는 지금, **부품간 전이·데이터 재사용**이 진짜 해자. ([Touch2Insert 86.7%](https://arxiv.org/html/2603.03627), [Tactile-Augmented 0.05mm 67%/30분](https://arxiv.org/html/2605.04649v1))
- **TAM:** 한국 공장자동화 $9.14B(2025)→$13.21B(2031). 글로벌 로봇 통합/프로그래밍 인건비 시장이 직접 타깃. ([Mordor](https://www.mordorintelligence.com/industry-reports/south-korea-factory-automation-and-industrial-controls-market))
- **리스크:** 정책 신뢰성(안전·불량), 초기 데이터 콜드스타트. → S5 품질검사를 동시 제공해 콜드스타트에도 즉시 가치.
- **판정: 진출.** 모트·빌더블·ROI 모두 강. 본 트랙 명령(지능 레이어가 모트)에 정확히 부합.

## 후보 β — **IndustrialVLA (HMLV 특화 멀티모달 VLA)** (S4)
**한 줄:** 비전+촉각+힘 멀티모달 VLA로 자연어 작업지시→접촉정책을 내는 산업 조립 특화 파운데이션 모델.

- **빌더블 리스크:** VLA 백본 풀스크래치는 4인·24개월·컴퓨트 한계 초과. π0/OpenVLA 파인튜닝으로 축소하면 **래퍼 킬 경계**에 근접(데이터·sim2real 모트 없으면 탈락). 
- **첫 매출:** 범용 지향이라 초기 수직 ROI 메시지가 α보다 흐림.
- **판정: 조건부 진출(후순위).** α의 정책 백본으로 흡수하는 게 합리적. 단독 1위 후보로는 빌더블·모트에서 α에 열세.
