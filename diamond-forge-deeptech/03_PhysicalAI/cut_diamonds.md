# Phase 4 — 컷팅 (Cut Diamond) · 후보 α 정밀 가공

## 제품명(가칭): **HAPTYX** — Contact-Rich Assembly Data Engine
(Haptic + Apt + Fix. "손맛으로 조립을 푸는 엔진")

---

## 1. 한 줄 정의 (30초 피치)
"공장에 이미 깔린 로봇팔과 1만원대 촉각센서 위에, **부품 도면 한 장으로 0.1mm급 삽입·조립 정책을 며칠이 아니라 30분 만에 세우는** 접촉리치 조립 AI 엔진. 현장의 실패 한 번이 모든 고객의 로봇을 더 똑똑하게 만든다."

## 2. 핵심 기술 돌파 (3겹 모트)
1. **힘/촉각 sim2real 잔차 엔진:** 부품 CAD→Isaac Lab/TacSL로 접촉 시뮬 대량생성→실세계 소량(수십회) admittance 잔차 보정으로 gap 자동 폐쇄. (SPARR·Direction Matters·FORGE 계열을 통합·제품화)
2. **센서-불변 촉각 표현(SITaF):** 센서 종류·젤 개체차를 흡수 → 한 번 모은 데이터를 모든 셀에 재사용. 데이터 효율의 근본 레버. (arxiv 2502.19638)
3. **부품간 전이 + 데이터 flywheel:** 스킬 라이브러리에서 기하/동역학 유사도로 사전정책 선택·파인튜닝(SRSA: +19% 성공, 2.4배 샘플↓). 현장 실패·인간보정이 익명 통합되어 전 고객 정책 동반 개선 = **네트워크 효과 해자.**

## 3. 하드 메트릭 10배 (제1원리 + 측정지표)
| 지표 | 현 산업 baseline | HAPTYX 목표 | 근거 |
|---|---|---|---|
| 신규 부품 정책 셋업 시간 | 셀당 150~400h ($18,750~80,000) | **<30분 (자동)** | 시뮬 대량생성+잔차보정+전이로 사람 프로그래밍 제거. 학술상 신규 커넥터 ~30분 사람개입을 자동화로 추가 단축. ([deploy cost](https://standardbots.com), [Tactile-Aug 30min](https://arxiv.org/html/2605.04649v1)) |
| 신규(unseen) 부품 일반화 성공률 | 45~70% | **>90%** | 센서불변 표현+부품간 전이. SOTA 86.7~90% 달성 사례 존재. ([Touch2Insert 86.7%](https://arxiv.org/html/2603.03627)) |
| 정책당 실세계 시연 수 | 수백~수천 | **수십 (10배↓)** | sim 대량생성으로 실데이터 의존 최소화. (TacSL 200배 가속) |
| 0.05mm 공차 삽입 성공률 | 67~90% | **>95% (전이 후)** | 동역학 컴플라이언스 튜닝 zero-shot 90~100% 입증. ([Dynamic Compliance](https://arxiv.org/pdf/2311.07499)) |

**제1원리:** 접촉 동역학은 결정론적 물리(마찰·강성·기하)에 지배 → 시뮬에서 충실히 샘플링 가능, 잔차만 실세계 보정하면 됨(정보이론상 보정해야 할 잔차 차원은 작음). 촉각은 비전이 못 보는 접촉 상태를 직접 관측 → 정보 추가가 본질적. **과학 킬 0건.**

## 4. 빌더블 쐐기 (24개월, 4인 + 자문)
- **6개월:** 단일 셀(UR/협동로봇 + DIGIT/GelSight) 위 1개 커넥터 종류 sim2real 삽입 데모, 셋업 <2시간. (오픈 인프라: Isaac Lab+TacSL+OpenVLA)
- **12개월:** 3~5종 커넥터, 신규 부품 전이 성공률 >80%, 셋업 <30분. 경기 SME 1곳 파일럿.
- **18개월:** 센서불변 표현으로 2번째 셀/센서 재사용, data flywheel v1, 유료 파일럿 3곳.
- **24개월:** 일반화 >90%, 품질검사(S5) 동시제공, 10곳 배포, 데이터 자산 축적.
- **자문/파트너:** 경기 로봇 SI·차세대융합기술연구원/대학 로봇연구실 교수 1~2인, 경기 전자·커넥터 SME 실증 파트너. **하드웨어는 전량 기성품(로봇팔·DIGIT) 조달**, 양산 없음.

## 5. 래퍼 킬 테스트 통과 근거
- 핵심 가치가 UI/통합/SDK 조합 아님 → **접촉 sim2real 잔차·센서불변 표현·부품간 전이 알고리즘 + 누적 독점 데이터**. 유능한 팀도 주말에 복제 불가(시뮬-실 동역학 정합, 촉각 도메인적응은 미해결 연구난제 + 데이터 축적 시간 필요).
- "기존 X + ChatGPT API"가 아님: 촉각·힘 물리 모달리티와 RL/잔차학습이 본질.

## 6. IP 전략
- 특허(청구항 비공개 우선): ① CAD→접촉 시뮬 자동 도메인랜덤화→잔차보정 파이프라인 ② 센서불변 촉각 표현 학습법 ③ 부품간 정책 전이 선택기.
- 영업비밀: 누적 접촉/실패 데이터셋·전이 가중치(핵심 해자, 비공개).
- 공모 IP 리스크 대응: 제출 전 핵심 청구항 출원 검토, 공지예외 12개월. 게임/사행성/환경오염 무관, 타 IP 침해 없음(오픈 인프라는 라이선스 준수).

## 7. 경기도 레버리지
제조 SME 밀집·HMLV 전자/커넥터 라인 = 실증 파트너 풍부 + 구조적 노동력 부족(제조고용 -8.2%)으로 수요 절박 + 스마트공장+ 75% 보조로 페이백 18개월↓ + 차세대융합기술연구원·판교 AI 인프라·반도체 후공정 인접.

## 8. 리스크 Top5 & 대응
1. 데이터 콜드스타트 → S5 품질검사로 day-1 가치 + 시뮬 부트스트랩.
2. 안전/불량 신뢰성 → 힘 임계 안전탐색(FORGE) + 품질 시그니처 동시검출.
3. 거대 플레이어(π0/Skild) 일반화 추격 → 우리는 **HMLV 산업 수직 + 부품 전이 데이터**로 좁고 깊게(범용은 셀별 30분 배포 못함).
4. 컴퓨트 → 추론/파인튜닝 중심, 백본은 오픈웨이트 활용으로 절감.
5. 현장 도입 마찰 → 기존 로봇·센서 위 retrofit, 보조금 연계로 진입장벽↓.
