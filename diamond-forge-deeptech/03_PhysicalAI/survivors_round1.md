# Phase 2 — 컬링 (Round 1) · 3종 킬 테스트

> 적용 순서: ① 래퍼 킬(Gate C #2: 주말 안에 공개 API/오픈소스로 복제 가능?) ② 하드웨어 양산 킬 ③ 과학 킬(제1원리 위반/불가능?). 하나라도 걸리면 탈락.

## 탈락 (사유)
- **5 TactileGen** — Sim2Surf/확산 도메인변환은 공개 레시피 다수, 단독으론 래퍼성 위험. (생존 아이디어의 한 모듈로 흡수)
- **6 GraspForce** — 가치 있으나 grasping 자체는 픽앤플레이스에 가까워 차별성 약, 접촉리치 난제 핵심 아님. (흡수)
- **8 ForceDirection / 11 SafeExplore / 12 PhaForce** — 각각 단일 논문 기법. 제품 단독으론 모트 얇음 → 생존 아이디어의 정책 모듈로 흡수.
- **14 TactileVLA** — "기존 VLA + 촉각 토큰 어댑터"는 **래퍼 킬 위험**(유능팀이 OpenVLA에 토큰 붙이기 주말급). 데이터·sim2real 모트 없으면 탈락. 단, 모델 백본으로는 채택.
- **15 WorldModelControl** — 접촉 월드모델 자체는 딥테크지만 24개월 4인 빌더블 위험(연구난이도 과대, 데이터 막대). 후순위.
- **16 EmbodimentAdapter / 22 InHandRepose / 21 DeformableTouch** — 기술 흥미롭지만 시장 진입·실증 경로가 모호하거나(손재주) 연구난도 과대. 후순위.
- **23 WireHarness / 24 MicroAssembly** — 매력적 수직이나 단독 시작 시 너무 좁거나(하네스 고난도 변형물) 반도체 후공정 진입장벽 큼. **생존 솔루션의 첫 수직 타깃 후보로 보존.**
- **26 TactileTransfer Marketplace** — 정책/데이터 자산 위에 서는 후행 비즈니스. 단독 시작 불가, 생존안의 GTM 2단계로 흡수.

## 생존 (5개) — 모두 하드웨어 양산 0, 모트=SW/모델/데이터, 과학 킬 0

### S1. **ContactForge — 접촉리치 조립 데이터 엔진 + sim2real 잔차 정책** (1·2·4·7·9·17 통합)
- 핵심: 커머디티 로봇팔+$15급 촉각센서 위에서, **부품 CAD→시뮬 대량생성→실세계 소량 잔차보정**으로 삽입/조립 정책을 **수일→수십분**에 세우는 데이터 엔진. 모트=힘/촉각 sim2real 알고리즘 + 누적 독점 데이터 flywheel.
- 래퍼 킬 통과: 핵심이 UI 아님. 접촉 sim2real·잔차학습·촉각 도메인적응은 주말 복제 불가.
- 과학 킬 통과: SPARR/SRSA/FORGE/Direction Matters 등 2025~26 논문이 각 요소 실현성 입증. 우리는 통합·데이터 모트.

### S2. **Sensor-Invariant Tactile Foundation (SITaF)** (3·5 통합)
- 센서·개체 편차를 흡수하는 촉각 표현 파운데이션 모델. 한 번 모은 데이터를 모든 센서/그리퍼/부품에 재사용 → 데이터 효율의 근본 레버.
- 래퍼 킬 통과: 표현학습+대규모 촉각 데이터가 모트. 과학 킬 통과(arxiv 2502.19638 입증).
- 단독 사업성은 약 → **S1의 핵심 엔진 컴포넌트**로 결합 시 강력.

### S3. **DeployMinutes — 부품 등록→정책 배포 시스템** (17·18·20)
- HMLV 셀 프로그래밍 150~400h/$18,750~80,000을 수십분/저비용으로. data-flywheel-as-a-service 네트워크 효과.
- 래퍼 킬 통과 조건부: **내부 sim2real/데이터 엔진(=S1)이 진짜 모트일 때만**. 통합층만이면 래퍼 → S1과 결합 필수.

### S4. **IndustrialVLA — HMLV 정밀조립 특화 멀티모달 VLA** (13)
- 비전+촉각+힘 멀티모달 VLA로 자연어 작업지시→접촉정책. 수직 특화.
- 래퍼 킬: 데이터·멀티모달 융합·접촉 토큰이 모트면 통과. 단 24개월 4인엔 백본 풀스크래치 과대 → π0/OpenVLA 백본+우리 데이터·sim2real로 차별화해야 빌더블.

### S5. **QualityFromTouch — 촉각/힘 시그니처 기반 조립 품질·정책 공유** (25)
- 조립 중 촉각·힘으로 불량 실시간 검출. 데이터가 조작 정책과 공유 → 검사+조작 시너지.
- 래퍼 킬 통과(촉각 이상탐지 모델+데이터). 단독은 시장 작음 → S1의 부가가치/초기 매출 쐐기로 유효.

> **관찰:** S2·S3·S5는 S1과 결합될 때 가장 강하다. S4는 빌더블 리스크 큼. Phase 3에서 S1을 중심에 두고 결합 구조를 격투한다.
