# SENTINEL-Core
### 온프렘 추론 거버넌스 엔진 — 모델 *내부 활성화*를 실시간 조종해 규정위반·환각을 출력 전에 차단하는 딥테크 SW

---

**한 줄(30초):** "금융·의료·공공이 자기 서버 안에서 LLM을 돌릴 때, 우리는 모델의 *생각 단계(내부 활성화)*를 실시간 모니터·조종해 규정위반과 환각을 **말이 나오기 전에** 막습니다. 출력 필터가 아니라 모델 뇌 속 개입이라 더 빠르고 더 정확하며, 한국 금융·의료 규정을 학습한 *concept feature 사전*은 베껴지지 않습니다."

**문제(정량):** AI기본법(2026.1.22) 시행으로 규제기관은 클라우드 LLM 사용 제약 → 온프렘 LLM 도입 급증. 그러나 (a) 온프렘엔 OpenAI/Anthropic급 안전장치 없음 (b) 기존 가드레일은 *출력 후 필터*(별도 모델 1회 더 호출 = 지연·비용↑, 우회 가능) (c) 환각·규정위반 1건이 금융·의료에선 제재·소송. 가드레일 시장 온프레미스 65.5%·BFSI 30.2%인데 *내부개입* 제품 부재.

**솔루션(왜 10배):** SAE(sparse autoencoder)로 추론모델 내부에서 "규정위반/환각/특정 민감개념" 방향(feature)을 추출 → 추론 중 활성화 단계에서 탐지·억제·교정. 제1원리: 표현공간의 선형 개입은 추가 모델 호출 없이 forward pass 내에서 끝나므로 **출력필터 대비 지연·연산 우월**(출처: arxiv 2503.16851). 우회 취약한 출력 정규식/분류기와 달리 *의미 표현*을 직접 다뤄 탐지율↑·오탐↓.

**왜 지금:** AI기본법 시행 + 가드레일 시장 CAGR 65.8% + SAE steering의 2025 생산화(Gemma Scope 등 공개 SAE 인프라 성숙) 3박자.

**차별성·해자:**
1. **내부 steering 코어** — 출력필터(주말복제)와 근본 다름.
2. **한국 금융·의료 규정 concept feature 사전** — 라벨·임상·법규 도메인 데이터 플라이휠(폐쇄). 고객이 쓸수록 두꺼워짐.
3. **온프렘 진입장벽** — 고객 사이트 통합·인증·신뢰(영업해자).
4. **모듈 흡수** — 압축(KV/activation)·예산라우팅(ACR)·기관메모리(PAM)를 같은 런타임에 → "추론 거버넌스 OS"로 확장.

**시장(가설+출처):** TAM=AI 가드레일 $109.9B(2034, CAGR 65.8%, market.us). SAM=온프렘×규제 ~40% ≈ $44B[가설]. SOM(한국 3년)=50~150기관×0.5~2억원=연 50~300억원[가설].

**단위경제(가설):** 연 구독(코어) 0.5~1.5억 + 도메인 feature팩 + 통합. SW 한계비용≈0, 마진 70%+. BEP: 유료 8~12기관[가설].

**GTM:** 경기 소재 저축은행·캐피탈·핀테크(판교) → 의료(가천대 길병원 연계 가설) → 공공 민원 LLM. PoC 무료→구독 전환.

**MVP(4인·24개월):** 6개월 공개 SAE 위 환각/규정위반 feature 탐지 PoC(1개 오픈모델), 12개월 한국 금융 도메인 feature팩+온프렘 패키지+첫 PoC고객, 18개월 유료 2~3기관·탐지율 벤치, 24개월 의료 확장+압축/라우팅 모듈.

**조직역량:** 대표(AI/데이터·금융데이터 경험=빅콘 신한카드 마케팅 AI 챗봇·세종 수상) → **founder-market fit: 규제 금융 LLM을 직접 다뤄봄**, 도메인 feature·고객 담당. 개발 2인(UMC 개발팀장·정보처리기사·풀스택/시스템) → 런타임·온프렘 통합. **확정형 자문(가정): 차세대융합기술연구원 interpretability 자문 1인 + 가천대 길병원 임상 LLM 자문 1인** — 핵심 기술모트(SAE feature 추출·개입)는 팀이 주도 구현, 자문은 도메인 검증·실증 연결.

**유료 전환 플레이북(영업주기 단축):** 경과원 규제샌드박스·가천대 길병원·판교 핀테크 PoC를 *유료 전환 레퍼런스*로 명문화 → **"PoC→유료 90일 전환"** 플레이북(무료 PoC 30일 → 도메인 feature팩 적용 30일 → 감사·인증 30일). 첫 레퍼런스 1곳이 동종 기관 영업주기를 절반으로 단축(규제기관 동형성).

**경기도 레버리지:** 판교 핀테크 PoC풀, 가천대 의료, 차세대융합기술연구원 공동검증, 경과원 규제샌드박스·온프렘 실증.

**IP:** 핵심청구항(도메인 feature 추출·개입 파이프라인)은 *영업비밀 우선* + 방법특허 선별 출원. 공모 제출 전 청구항 비공개. 공지예외 12개월 활용.

**리스크 Top5:** ①모델 업데이트마다 feature 재학습→자동 재추출 파이프라인 ②대형벤더(NeMo Guardrails) 경쟁→온프렘×내부×한국규제 빈틈 집중 ③SAE feature 신뢰성 한계→탐지+백업필터 하이브리드 ④온프렘 영업주기 길다→경과원/대학 레퍼런스 ⑤학생팀 신뢰→자문·실증 레퍼런스.

**30초 비전문가 피치(도민용):** "요즘 은행·병원이 자기 컴퓨터 안에 AI를 들여놓는데, 이 AI가 가끔 거짓말을 하거나 규정을 어기는 말을 합니다. 우리는 AI가 그 말을 *입 밖에 내기 전에*, 생각하는 순간에 잡아내는 안전장치를 만듭니다. 경기도 은행·병원이 첫 고객입니다."
