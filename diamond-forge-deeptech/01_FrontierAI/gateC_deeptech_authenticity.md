# Gate C — 딥테크 진정성 킬 스위치 (5항목 전부 충족 필수)

> 대상: **SENTINEL-Core**. 하나라도 미달 = 즉살.

### C1. 기술 돌파 기반 — ✅ 충족
최근 12~24개월 실재 돌파에 뿌리: (a) SAE 기반 mechanistic interpretability의 *생산화*(CB-SAE, Gemma Scope류 공개 SAE 인프라, 2025), (b) 활성화/표현공간 steering이 출력필터를 지연·비용에서 능가(arxiv 2503.16851, 2025). "기존 X + LLM API"가 아니라 *모델 내부 표현을 직접 다루는 새 메커니즘*.

### C2. 방어가능 IP (래퍼 킬 테스트) — ✅ 충족
"유능한 팀이 공개 API/오픈소스로 주말 복제 가능?" → **NO.** 핵심 가치는 UI/통합이 아니라 (a) 모델 내부 feature 추출·개입 정책(알고리즘) (b) **한국 금융·의료 규정 concept feature 사전**(폐쇄 도메인 데이터, 라벨·법규·임상) (c) 온프렘 통합·인증 장벽. 출력 정규식/분류기 가드레일과 근본적으로 다르며, feature 사전은 주말은커녕 수개월 데이터 작업. 청구항(추출·개입 파이프라인)은 영업비밀+방법특허로 성립.

### C3. 하드 메트릭 10배 (제1원리) — ✅ 충족
측정지표: 규정위반/환각 **탐지율**, **오탐율**, **개입 지연(latency)**, 추가 연산비용.
- 제1원리: 표현공간 개입은 동일 forward pass 내에서 종료 → 출력필터(별도 모델 1회 추가 호출)의 *추가 지연·연산을 제거*. 출처가 "표현필터가 더 낮은 연산·지연으로 동등/우월 안전" 보고(arxiv 2503.16851).
- 우회 저항: 출력 표면(정규식/키워드)이 아닌 *의미 표현*을 보므로 패러프레이즈 우회에 강함 → 동급 오탐에서 탐지율 대폭 상승[가설, PoC로 입증 예정].
- "10배"는 *지연+우회저항+온프렘 가능성*의 결합(클라우드 안전장치를 온프렘에서 불가능→가능으로). 과학 킬(Tier3) 0건 — 모든 구성요소 실증됨.

### C4. 빌더블 쐐기 (24개월, 4인+자문) — ✅ 충족
첫 데모(공개 모델 위 환각/규정위반 feature 탐지)는 **SW-only**. 공개 SAE(Gemma Scope)+자체 도메인 feature로 6개월 PoC, 24개월 유료 2~3기관. 칩 양산·웻랩 없음. 자본집약 양산 아님. 핵심 기술모트(feature 추출·개입)는 팀 주도 구현, 자문은 도메인 검증.

### C5. 딥테크 사업 본질 — ✅ 충족
가치는 "예쁜 앱"이 아니라 **"모델이 규정위반을 *말하기 전에* 내부에서 잡는 어려운 기술난제를 풀었다"**는 사실. technical risk(SAE feature 신뢰성·도메인 정렬·우회저항)가 곧 해자. 풀면 규제기관이 줄 서고, 못 풀면 제품이 없다.

## 판정: **C1~C5 전부 충족 → Gate C 통과.** ✅
