## 격투 1 — On-Prem Reasoning Appliance SW (#5통합) + Reasoning Watchdog/Compliance (#2)
### 통합 판단: **둘은 한 제품의 쐐기→플랫폼이다.** Watchdog/Compliance가 쐐기, Appliance가 확장.

**한 줄:** 규제산업이 *자기 서버 안*에서 LLM/추론모델을 돌릴 때, 모델 **내부 활성화를 실시간 조종(steering)** 해 규정위반·환각을 출력 전에 차단하고, 압축·예산라우팅으로 온프렘 추론 단가를 낮추는 딥테크 SW 스택.

- **Why now:** (a) AI기본법 2026.1.22 시행 → 온프렘/데이터주권 강제. (b) AI 가드레일 시장 $0.7B(2024)→$109.9B(2034), CAGR 65.8%, **온프레미스 65.5%·BFSI 30.2% 우세**(출처: https://market.us/report/ai-guardrails-market/). (c) **활성화 steering이 출력필터보다 지연·비용 우월**(제1원리: 표현공간 선형개입, 출처: https://arxiv.org/html/2503.16851v2).
- **모트:** ① 출력필터(주말복제)와 달리 *모델 내부 feature를 다룸* ② 금융·의료 한국어 **규정 concept feature 사전** = 폐쇄 데이터 해자 ③ 온프렘 진입(고객 사이트 통합) = 영업·인증 장벽 ④ SAE 추출·개입정책 노하우.
- **TAM/SAM/SOM [가설+출처]:** TAM = 글로벌 AI 가드레일 $109.9B(2034). SAM = 온프렘×규제(BFSI+의료+공공) ≈ TAM의 ~40% → ~$44B(2034)[가설]. SOM = 한국 규제기관 온프렘 LLM 도입 초기 3년, 50~150기관 × 연 5천만~2억원 → **연 50~300억원**[가설].
- **단위경제 [가설]:** SW 라이선스(연 구독) + 도메인 feature팩 + 설치/통합. 한계비용 ≈ 0(SW). 첫고객 PoC 무료→연 5천만~1.5억 구독. 마진 70%+ [가설].
- **첫고객 10곳:** 경기 소재 저축은행·캐피탈·핀테크, 지역 의료기관(가천대 길병원 연계 가설), 경기도 공공기관(민원 LLM), 제조 중소기업 사내 LLM. → 경기도 레버리지 직결.
- **경기도 레버리지:** 판교 핀테크·AI기업 PoC, 가천대 의료(길병원) 임상도메인 자문, 차세대융합기술연구원 공동검증, 경과원 규제샌드박스.
- **빌더블:** 쐐기(Watchdog/Compliance)는 SW-only, 오픈 SAE(Gemma Scope류)+자체 도메인 feature로 4인 24개월 가능. Appliance 확장은 이후.
- **리스크:** 모델/벤더 업데이트마다 feature 재학습(운영부담). 대형 가드레일 벤더(Nvidia NeMo Guardrails 등) 경쟁 — but 그들은 출력필터·클라우드 중심, *온프렘×내부steering×한국규제* 빈틈.

**평가:** 사업성 9 / 성장성 9 / 모트 9 / 빌더블 8. **1순위.**

## 격투 2 — Parametric Agent Memory (PAM)
**한 줄:** 에이전트 장기메모리를 벡터DB가 아니라 test-time weight update로 구현, forgetting 없이 검증가능 롤백.
- 모트: 알고리즘+안정화. 강도 中~상, but **학술 추격 매우 빠름**(Titans/ATLAS/Nested Learning 분기마다). 단일 알고리즘 모트는 논문화 시 침식.
- 단위경제: 누가 돈 내나? 에이전트 인프라 미들웨어 — Mem0/Letta와 정면충돌, 차별화 입증 길고 B2D 단가 낮음.
- 빌더블: O. but 10배 메트릭(장기 recall)의 *고객 가치→매출* 연결이 약함.
- 경기도 레버리지: 약(인프라 미들웨어는 지역색 옅음).
**평가:** 사업성 6 / 성장성 8 / 모트 7 / 빌더블 8. **탈락(차순위 보관)** — 기술은 멋지나 단위경제·첫매출 경로·경기도 적합이 1순위 대비 약함.

## 격투 3 — Adaptive Compute Router (ACR)
**한 줄:** 쿼리 난이도→최적 추론예산 학습 라우터로 추론모델 비용 3~10배 절감.
- 모트: 데이터 플라이휠. 강도 中. 그러나 **추론 프레임워크(vLLM/SGLang)가 기능으로 흡수할 위험** + LLM 벤더가 자체 라우팅 내장 추세(즉, 플랫폼 종속·해자 침식).
- 단위경제: 토큰 절감액의 일부 과금 가능(가치과금) — 좋음. but 측정·정산 복잡.
- 경기도 레버리지: 약.
**평가:** 사업성 7 / 성장성 8 / 모트 6 / 빌더블 9. **탈락(차순위)** — 모트 침식 위험 + 경기도 적합 약. 단, 격투1 Appliance의 *내부 모듈*로 흡수(예산라우팅).
