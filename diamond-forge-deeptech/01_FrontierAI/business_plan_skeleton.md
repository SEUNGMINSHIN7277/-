# Phase 8 — 사업계획서 스켈레톤 (양식1 16항목) · SENTINEL-Core

## 1. 한 줄 정의(30초 피치)
규제산업이 자기 서버 안에서 LLM을 돌릴 때, 모델의 *내부 활성화(생각 단계)*를 실시간 조종해 규정위반·환각을 **출력 전에** 차단하는 온프렘 추론 거버넌스 딥테크 SW.
- (도민용 30초) "은행·병원 AI가 거짓말·규정위반을 *입 밖에 내기 전에*, 생각하는 순간 잡는 안전장치. 경기도 은행·병원이 첫 고객."

## 2. 문제(정량)
- AI기본법(2026.1.22 시행)으로 규제기관 클라우드 LLM 제약 → 온프렘 LLM 급증.
- 온프렘엔 클라우드급 안전장치 부재. 기존 가드레일=출력 후 필터(별도 모델 추가호출=지연·비용↑, 패러프레이즈 우회 가능).
- 금융·의료 환각/규정위반 1건 = 제재·소송. 가드레일 시장 온프레미스 65.5%·BFSI 30.2%인데 *내부개입* 제품 공백.
- 출처: https://market.us/report/ai-guardrails-market/

## 3. 솔루션(왜 10배)
SAE로 추론모델 내부에서 "규정위반/환각/민감개념" feature 추출 → forward pass 중 탐지·억제·교정. 제1원리: 표현공간 선형개입은 추가 모델 호출 없이 끝나 출력필터 대비 지연·연산 우월(arxiv 2503.16851), 의미표현을 다뤄 우회저항.
