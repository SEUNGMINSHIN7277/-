## 1. 한 줄 정의 (30초 피치)
규제산업이 자기 서버 안에서 LLM을 돌릴 때, 모델의 *내부 활성화(생각 단계)*를 실시간 조종해 규정위반·환각을 **출력 전에** 차단하는 온프렘 추론 거버넌스 딥테크 SW.
- **(도민용 30초)** "은행·병원 AI가 거짓말이나 규정위반을 *말하기 전에*, 생각하는 순간 잡는 안전장치예요. 출력 검열이 아니라 모델의 머릿속에 개입합니다. 경기도 은행·병원이 첫 고객입니다."

## 2. 문제 (정량)
- **규제 강제:** AI기본법(2026.1.22 시행) → 규제기관 클라우드 LLM 제약 → 온프렘 LLM 급증.
- **안전 공백:** 온프렘엔 클라우드급 안전장치 부재. 기존 가드레일 = **출력 후 필터**(별도 모델 추가호출 → 지연·비용↑, 패러프레이즈로 우회 가능).
- **사고 비용:** 금융·의료 환각/규정위반 1건 = 제재·소송. 가드레일 시장은 온프레미스 65.5%·BFSI 30.2%인데 ***내부 개입* 제품은 공백.**
- 출처: https://market.us/report/ai-guardrails-market/

## 3. 솔루션 (왜 10배)

- **제1원리:** 표현공간 선형개입은 *추가 모델 호출 없이* 끝나므로 출력필터 대비 지연·연산 우월(arXiv 2503.16851). 의미표현 자체를 다뤄 패러프레이즈 우회에 저항.
- **10배 주장은 [가설]** — 6개월 PoC에서 탐지율/오탐/지연 벤치로 입증 예정.
