# Phase 2 — 컬링 (Survivors Round 1)

> 3대 킬: (K1) 칩/하드웨어 양산 의존, (K2) 래퍼(주말복제), (K3) 과학 불가/fab데이터 접근 불가. 생존 5~8개.

## 즉살 목록
- **9 HW-인-루프 보정:** K1/부분 — 실칩+테스터 접근 상시 필요. 학생팀 빌더블 약함. KILL.
- **18 적응형 테스트 / 20 마이크로채널 냉각:** K1 — 테스터 통합/물리 제작 의존. KILL.
- **12,13,14,19,(15) fab/테스트 데이터 의존군:** K3 — 삼성/하이닉스 내부데이터 없이 시작 불가. 경기도 파트너 있어도 NDA/접근이 곧 사업 시작 전제 = 학생팀 리스크 과대. KILL(보류군으로 강등).
- **24 포토닉/뉴로모픽 컴파일러:** K3 — 소자 미성숙, 24개월 데모 불확실. KILL.
- **26 지식그래프+RAG 보조:** K2 — LLM 래퍼 위험 최상. KILL.
- **6 위상 자동생성:** 성숙도 낮고 모트 약함 → 보류(단독으론 약함, 1/2에 흡수 가능).
- **16,17 칩렛 열 RL/surrogate:** 빌더블·딥테크 OK이나 데이터(패키지 열 측정) 접근·차별화가 1/2 대비 약함 → 보류(차순위).

## 생존 (Round 1) — 6개

### S1. 아날로그 IP 자동 노드/파운드리 마이그레이션 엔진 (원석1)
- 래퍼킬 통과: 모트=노드 간 디바이스-물리 매핑 알고리즘 + 누적 마이그레이션 데이터(주말 복제 불가, LLM API로 안 풀림). 과학: 디바이스 거동은 물리(BSIM/표면포텐셜)로 매핑 가능 — 과학 킬 0. 양산 무관(순수 SW). **STRONG.**

### S2. 물리정보 아날로그 신경 시뮬레이터(SPICE 대체 surrogate) (원석2)
- 래퍼킬 통과: 모트=회로위상-기생 GNN + 물리제약 + 자체생성 시뮬 데이터. 과학: 회로방정식은 미분방정식 → surrogate 가능(증명된 5자리수 가속 선례). 양산 무관. **STRONG.**

### S3. few-shot 회로 모델링 파운데이션 모델 (원석5)
- 래퍼킬 통과: 모트=pretraining 코퍼스+적응. 단 S1/S2와 기술 중복(같은 GNN 코어). 흡수 후보.

### S4. 아날로그 설계용 합성 데이터 파운드리 (원석21)
- 래퍼킬 통과: 모트=데이터 자산(가장 순수한 데이터 모트) + 생성 파이프라인. 양산 무관. 단 단독 사업성(누가 데이터만 사나)·차별화 점검 필요. → S1/S2의 **연료/모트 엔진**으로 통합 시 강력.

### S5. PDK-agnostic 아날로그 IR + 양방향 컴파일러 (원석22)
- 래퍼킬 통과: 모트=공정독립 IR 표준+컴파일러. S1과 강한 시너지(IR이 마이그레이션 기반). 통합 후보.

### S6. RF/mmWave neural-EM 대리설계 (원석4)
- 래퍼킬 통과: 모트=물리정보 S-parameter 대리모델. 양산 무관. 단 시장이 더 좁고 EM 전문성 요구 높음 → 차순위.

## Phase3 진입 결론 (핵심 통찰)
S1·S2·S4·S5는 **하나의 딥테크 플랫폼으로 수렴**한다:
> **"아날로그 설계 데이터 모트(S4) 위에, 물리정보 surrogate(S2)와 PDK-agnostic IR(S5)을 엔진으로, 아날로그 IP 마이그레이션(S1)이라는 명확한 첫 페인을 푼다."**

이것이 Phase 3로 가져갈 **메인 후보 A (통합 플랫폼).**
차순위:
- **후보 B = S6** (RF neural-EM, 시장협소·전문성 리스크).
- **후보 C = S2 단독** (시뮬가속 = 횡단적 페인, 사업화 경로 명확하나 거대사 정면충돌).
