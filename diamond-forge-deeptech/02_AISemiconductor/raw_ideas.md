# Phase 1 — 딥테크 원석 (Raw Ideas) — AI × Semiconductor

> 래퍼/앱/대시보드/MES통합 금지. 모트가 알고리즘/컴파일러/물리모델/데이터인 것만. 칩 양산 의존 즉살 표기.

## 그룹 1: 아날로그·RF 설계자동화
1. **아날로그 IP 자동 노드/파운드리 마이그레이션 엔진** — 한 PDK에서 검증된 아날로그 블록을 다른 노드/파운드리로 디바이스-물리-보존 매핑 + 자동 리사이징. 모트: 노드 간 디바이스 거동 매핑 알고리즘 + 누적 마이그레이션 데이터.
2. **물리정보 아날로그 신경 시뮬레이터(SPICE 대체 surrogate)** — SPICE 1회 수십분→ms. 모트: 회로위상-기생 GNN + 물리제약 학습 + 자체 시뮬 데이터.
3. **파라사이트-aware 레이아웃 사전예측** — 레이아웃 전에 기생 효과 예측해 sizing 루프 단축. 모트: 기생 GNN + 데이터.
4. **RF/mmWave 필터·매칭 회로 neural-EM 대리설계** — EM 시뮬 5자리수 가속 + RL 설계탐색. 모트: 물리정보 S-parameter 대리모델.
5. **few-shot 회로 모델링 파운데이션 모델** — 신규 PDK에 소량샘플로 적응하는 사전학습 회로 GNN. 모트: pretraining 코퍼스 + 적응 알고리즘.
6. **아날로그 회로 위상(topology) 자동 생성기** — 스펙→위상(bipartite graph + grammar decoding). 모트: 생성 알고리즘. (성숙도 낮음)
7. **PVT 코너 자동 robust sizing** — 변이 강건 sizing을 surrogate+Bayesian로. 모트: 변이모델+탐색.

## 그룹 2: 인메모리/엣지 AI 컴퓨팅 SW
8. **AIMC 비이상성-aware 컴파일러** — NN→크로스바 매핑 시 드리프트/IR drop/ADC양자화 보정 자동삽입. 모트: 보정 알고리즘+런타임. (칩 불필요, SW레이어)
9. **하드웨어-인-루프 보정 런타임** — 배포된 아날로그 가속기 per-array 캘리브레이션 진행형 fine-tune. 모트: 온라인 보정 알고리즘. (실칩 접근 필요 = 파트너 의존 위험)
10. **엣지 NPU용 비이상성 시뮬레이터** — 실칩 없이 아날로그 정확도 손실 예측. 모트: 소자물리 노이즈 모델.
11. **MoE 아날로그-디지털 이종 라우팅 컴파일러** — robust heterogeneous 컴퓨팅 매핑. 모트: 이론적 일반화 보장 알고리즘.

## 그룹 3: 수율·결함·열·신뢰성 물리 ML
12. **물리정보 결함레벨 예측** — 물리적으로 valid한 결함예측. 모트: PINN. (fab 데이터 의존)
13. **SEM 결함→전기fail 예측 + 최적 검사층 선정** — 검사비용 절감. 모트: 데이터+모델. (fab 데이터 의존)
14. **소량 데이터 수율 cold-start 모델** — 신제품/소량다품종 초기 수율예측. 모트: transfer + 물리prior. (데이터 의존)
15. **신뢰성(전계/열 가속) 물리 surrogate** — 수명예측 가속. 모트: 물리모델.

## 그룹 4: 칩렛/패키징·테스트
16. **칩렛 열-aware 배치 RL 최적화기** — 2.5D/3D 배치 열+wirelength. 모트: 멀티에이전트 RL + 열 surrogate.
17. **3D-IC 열 멀티피델리티 surrogate / 디지털트윈** — FEA 대체 ms 열예측. 모트: 멀티피델리티 모델.
18. **적응형 테스트 패턴 샘플링 엔진** — 테스트비용 34%↓. 모트: 적응 알고리즘. (테스터 통합 필요)
19. **아날로그/RF outlier(underkill) 스크리닝** — test escape 90%↓. 모트: 적응 outlier 경계 알고리즘. (테스트 데이터 의존)
20. **마이크로채널 냉각 RL 공동설계** — 열저항 31%↓. 모트: RL+CHT. (제작 의존 위험)

## 그룹 5: 융합·와일드카드
21. **아날로그 설계 검증용 합성 데이터 파운드리** — SPICE 농장으로 라벨 회로-기생-코너 데이터셋 대량생성 + 판매/구독. 모트: 데이터 자산 + 생성 파이프라인. (데이터 모트 직결)
22. **PDK-agnostic 아날로그 IP 표현(중간표현 IR)** — 공정독립 아날로그 IR + 양방향 컴파일. 모트: IR 표준 + 컴파일러.
23. **아날로그 회로 "linter"/검증 — 물리법칙 위반·robustness 취약점 자동탐지.** 모트: 물리룰+ML.
24. **포토닉/뉴로모픽 매핑 컴파일러** — 신소자용 컴파일. 모트: 컴파일러. (소자 미성숙·고위험)
25. **TSV/인터커넥트 SI 물리-guided 대리최적화** — 신호무결성. 모트: 물리 surrogate.
26. **아날로그 설계 지식그래프 + RAG 보조** — 단, LLM 래퍼 위험 높음(주의).
27. **변이/노화 aware 아날로그 마이그레이션(1+8 융합)** — 마이그레이션 시 신뢰성/변이까지 보존.
28. **소량다품종 팹리스용 클라우드 아날로그 시뮬 가속 서비스(2 기반)** — surrogate로 시뮬 iteration 폭증.

## 초기 직관 (Phase2 입력)
