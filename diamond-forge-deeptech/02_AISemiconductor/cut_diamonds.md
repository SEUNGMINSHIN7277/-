# Phase 4 — 컷팅 (Cut Diamond): 후보 A 정밀 가공

## 확정 다이아몬드 (가공본)
**제품명(가칭): RETARGET-AI (아날로그 IP 물리보존 마이그레이션 엔진)**

### 한 줄 정의 (30초 피치)
> "아날로그 회로 IP 1개를 새 공정·새 파운드리로 옮기려면 베테랑 설계자가 수개월 수작업으로 재설계한다. 우리는 **소자 물리를 보존하는 자동 리타게팅 엔진**으로 이를 며칠로 줄인다 — 핵심은 노드 간 디바이스 거동을 잇는 물리정보 매핑 알고리즘과, 우리만 축적하는 마이그레이션 데이터다."

### 기술 스택 (3-레이어 모트)
1. **PDK-agnostic 아날로그 IR (중간표현):** 회로를 공정독립 그래프(소자·연결·동작점·스펙·제약)로 정규화. 이게 양방향 컴파일의 기반.
2. **물리정보 디바이스 매핑 + surrogate:**
   - 매핑: source PDK의 동작점/스펙을 target PDK 소자 거동(BSIM/표면포텐셜 기반 물리 prior)으로 보존 변환 — 단순 스케일링이 아니라 gm/Id, 매칭, 기생 제약을 물리법칙으로 보존.
   - surrogate: 회로위상-기생 GNN + 물리제약 학습으로 SPICE iteration을 ms로 대체 → 마이그레이션 후 robust resizing 루프를 수천 배 빠르게.
3. **데이터 플라이휠:** 자체 SPICE 농장(오픈 PDK + 합성 코너) + 고객 마이그레이션 작업물(익명화)이 매핑·surrogate를 강화 → 시간이 갈수록 복제 격차 확대.

### "왜 10배" — 제1원리 논증
- 현재 아날로그 노드 이전 = 수동, 회로당 수주~수개월(설계자 노동시간이 비용·일정의 지배항). (출처: semiengineering, thalia-da)
- surrogate가 SPICE(1회 수십분~수일)를 ms로 → iteration 횟수 제약이 사라짐(5자리수 가속 선례 존재: Alpha-RF). 설계 탐색은 본질적으로 iteration-bound이므로, iteration 비용을 ~0으로 만들면 탐색량이 곧 품질·속도. → **시간 10~50배 단축은 정보이론적으로 iteration 병목 제거의 직접 귀결**(가설은 배수, 메커니즘은 제1원리).
- 매핑이 물리 prior를 보존하므로 "from scratch 재설계" 대비 탐색공간을 초깃값 근방으로 축소 → 추가 가속.

### 래퍼 킬 통과 (핵심)
- 주말 복제 불가: 가치가 UI가 아니라 (a)물리정보 디바이스 매핑 알고리즘, (b)자체 축적 마이그레이션·기생 데이터, (c)PDK-agnostic IR에 있음. LLM API로는 디바이스 물리 보존·기생 정확도가 나오지 않음(few-shot/PINN 연구가 증명하는 난제).
- 특허 청구항: 노드 간 동작점-보존 매핑 방법, 물리제약 surrogate 학습, IR 표현.

### 첫고객 쐐기 (wedge)
오픈/레거시 PDK 기반 소량다품종 팹리스·IP社 — Synopsys/Cadence가 안 챙기는 롱테일. "노드 이전 1건"을 유료 PoC로 → 데이터 축적 → 구독.
