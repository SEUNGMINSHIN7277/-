# Phase 3 — 사업화 격투 (Survivors Round 2)

> 격투 기준: 첫 매출 경로 / 데이터 모트 부트스트랩 / 거대사 회피 / 4인 빌더블 / 경기도 레버리지 / 글로벌 TAM.

## 후보 A — 아날로그 IP 마이그레이션 플랫폼 (S1+S2+S4+S5 통합)
**한줄:** 아날로그 IP를 한 PDK→다른 노드/파운드리로 자동 리타게팅. 물리정보 surrogate로 시뮬 iteration을 ms로 압축, 자체 마이그레이션 데이터가 복제불가 모트.
- 첫매출: 소량다품종 팹리스/IP社의 "노드 이전 1건" 프로젝트 과금 → 점진적 SaaS+데이터 구독.
- 데이터 부트스트랩: 오픈 PDK(SkyWater 130nm 등) + 자체 SPICE 농장 합성데이터 → cold start 가능(외부 fab 데이터 불필요!). 이것이 fab데이터 의존군 대비 결정적 우위.
- 거대사 회피: Synopsys/Cadence는 대형 풀스택·선단 노드 집중. 소량다품종·신흥/오픈 PDK·중소 팹리스 롱테일은 사각.
- 4인 빌더블: GNN/surrogate/매핑 = AI·SW 코어. 디바이스 물리 자문 1~2인(경기도 반도체 교수/현직).
- 경기도: 판교 팹리스 클러스터·팹리스 아카데미·가천대 = 첫고객+자문+데이터 파이프라인 직결.
- 평가: 사업성 강, 모트 강, 빌더블 강, 글로벌 TAM 강. **1순위.**

## 후보 B — RF/mmWave neural-EM 대리설계 (S6)
- 첫매출: 5G/6G RF 팹리스 EM 시뮬 가속.
- 약점: 시장 협소, EM 도메인 전문성 진입장벽(팀이 EM 약함), 데이터 모트 부트스트랩이 EM 솔버 라이선스 비용 의존. 4인 빌더블 약간 약함. **3순위로 강등.**

## 후보 C — 물리정보 아날로그 surrogate "시뮬 가속기" 단독 (S2)
- 첫매출: 아날로그 설계 iteration 가속 플러그인.
- 강점: 횡단적 페인(모든 아날로그 설계자), 빌더블 명확.
- 약점: 거대사·오픈소스 surrogate와 정면충돌, "왜 10배"가 정확도-신뢰성 의심으로 약해질 수 있음(설계자는 정확도 안 믿으면 안 씀). 단독으론 차별화 모트가 데이터로만 가야 함 → 후보 A의 일부로 흡수가 더 강함. **2순위(후보A의 폴백/구성요소).**

## Round 2 생존 (3개)
