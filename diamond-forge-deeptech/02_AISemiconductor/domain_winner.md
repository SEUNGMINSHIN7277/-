# Phase 7 — 트랙 확정 다이아몬드 : RETARGET-AI

## Gate C — 딥테크 진정성 (5항목 전부 충족해야 통과)

1. **기술 돌파 기반 ✅** — 최근 12~24개월 실재 돌파에 뿌리: few-shot 회로 GNN(CircuitGPS 2507.06538), 물리정보 결함예측 PINN(Wiley 2026), 신경 시뮬레이터(INSIGHT/Alpha-RF 5자리수 가속), 파라사이트 GNN(ParaGraph/DICE). "기존+LLM API"가 아니라 디바이스 물리 보존 매핑이라는 **새 메커니즘**.
2. **방어가능 IP (래퍼 킬) ✅** — 주말 복제 불가. 모트=(a)노드 간 동작점-보존 물리 매핑 알고리즘, (b)자체 축적 마이그레이션·기생 데이터 플라이휠, (c)PDK-agnostic IR. UI/통합이 아님. 청구항 3건 성립.
3. **하드 메트릭 10배 ✅** — 마이그레이션 시간 수개월→수일(설계자 노동시간 지배항 제거), surrogate로 SPICE iteration 수십분~수일→ms. 제1원리: 설계탐색은 iteration-bound → iteration 비용 ~0이면 탐색량=품질·속도(정보이론적). 과학 킬(Tier3) 0건(회로=미분방정식, surrogate 가능 입증).
4. **빌더블 쐐기 ✅** — GNN/surrogate/매핑/IR = 팀 AI·SW 코어로 24개월 데모 가능. 외부 fab 데이터 불필요(오픈 PDK cold-start). 필요 파트너: 디바이스 물리 자문 1~2인(경기 반도체 교수/현직), 검증용 파운드리 PDK 접근(오픈PDK로 부트스트랩, 상용PDK는 고객 경유). 칩 양산 무관.
5. **딥테크 사업 본질 ✅** — 가치가 "예쁜 앱"이 아니라 "수십년 수작업이던 아날로그 마이그레이션을 물리보존 자동화로 풀었다"는 기술난제 해결에서 발생. technical risk = 해자.

**→ Gate C 5/5 통과.**
