# Phase 2 — Culling Round 1 (Gate C 래퍼킬 + 과학킬 + 웻랩의존킬)

> 적용 순서: (1) 래퍼 킬(주말 복제 가능? 가치가 알고리즘/데이터/물리인가?) → (2) 과학 킬(제1원리 위반?) → (3) 웻랩의존 킬(자체 합성/플랜트 의존?) → (4) 데이터 조달 현실성.

## 즉살 (탈락) + 사유
- **#3 RadioTox / #2 NonNovel (단독):** 단독은 룰/유사도 필터 — 주말 복제 가능, 래퍼 킬. (단, 통합의 부속으로는 생존)
- **#20 RecipeLLM-Extract:** LLM 추출 = GPT 래퍼 위험 최상. 핵심 가치가 모델이 아니라 프롬프트/통합 → 래퍼 킬.
- **#9 CalibUQ / #10 DataFusion-FF / #18 MultiFidelity:** 강한 알고리즘이나 **방법론 컴포넌트** — 단독 사업 아님(논문성). 통합 모트의 일부로만 생존.
- **#16 ProcessPINN / #17 PhaseDiagramNet:** 딥테크지만 데이터 조달이 사내 시뮬/실험 의존 강하고 고객·단가 모호, 24개월 검증루프 비현실 → 보류 탈락.
- **#15 DegradeNet:** 필드 데이터(셀 운영) 확보가 학생팀에 비현실(완성차/배터리사 독점). 데이터 조달 킬.
- **#12 SSE-Diffuse:** AIMD 검증은 가능하나 단독 surrogate는 메트릭만, 사업 빈약. 통합으로 흡수.
- **#22 MOF / #23 Polymer / #24 Alloy:** 좋은 수직이나 합성 데이터·검증 인프라 접근이 약함(경기도 정합 낮음). 차순위 보류.
- **#25 SelfDrivingLab-Brain:** 하드웨어 파트너 의존이 사실상 자율실험실 구축 동반 → 24개월 빌더블 위험. 부분 흡수.
- **#26 SynthRisk-Industrial / #19 NegDB(단독):** 인프라/데이터 컨소시엄 — 단독 창업 부적합. NegDB는 모트의 핵심 자산으로 흡수.
- **#29 MatterMaker-API / #30 ActiveSynth-CRO:** 사업모델 변형 — 코어 기술 동일, Phase 3에서 모델로 검토(별도 원석 아님).

## 생존 (5~8개) + 사유

### S1. RetroForge — 무기 역합성 엔진 (#4+#5+#6+#7)
목표 무기상 → 전구체·소성조건·경로 추천. **상용 무기반응 DB 부재 = 데이터 모트의 빈 들판.** 텍스트마이닝+실패데이터+능동학습으로 자체 반응그래프 구축. 래퍼 불가(주말 복제 불가, 데이터+알고리즘 모트). 과학 킬 통과(열역학·반응속도 prior 가능). 검증=경기도 파트너 외주. **최강 후보.**

### S2. SynthGate — 합성가능성 게이트 (#1+#2+#3)
생성기 출력에 합성가능성·신규성·유용성 점수. 빅테크 생성기 뒤에 붙는 필수 레이어(GNoME/MatterGen의 공인된 약점 해결). 단독은 게이트만 — S1과 결합 시 강력.

### S3. CloseLoop-AL — 능동학습 검증 폐루프 (#8+#9+#18)
UQ 기반 다음실험 추천으로 검증 실험 횟수 최소화. 검증 파트너와 폐루프 = 경기도 정합. 알고리즘 모트(베이지안 실험설계+보정 UQ). 단독보다 S1/S2 결합 시 모트 완성.

### S4. ForgeStack (통합) — post-generative 합성가능성+역합성+능동검증 (#27)
S1+S2+S3 통합. "목표상 → 만들 수 있나 + 어떻게 + 다음 실험". 빅테크 생성 레이어가 못 푸는 빈 공간 전체를 점유. 가장 큰 모트지만 24개월 빌더블 범위 검증 필요.

### S5. RetroForge-Battery (수직 집중) — 배터리 소재 역합성+검증 (#28+#11+#14)
S4를 배터리 양극/전해질/촉매 수직에 집중. 데이터 좁고 고객 명확(경기도 소부장·이차전지), TAM 거대(에너지). 빌더블·검증루프가 가장 현실적. **사업화 1순위 후보.**

### S6. CO2/GreenH2-Cat — 기후촉매 역설계+합성가능성 (#13+#14)
계면 능동학습(OC25 활용)으로 비귀금속 촉매 탐색. 기후 TAM. 검증 난도 높음(전기화학 셀) — 차순위.

> Phase 3로: S1·S4·S5를 사업화 격투의 본선으로(코어 동일, 범위·수직 차이). S2·S3는 코어의 모듈, S6는 대체 수직.
