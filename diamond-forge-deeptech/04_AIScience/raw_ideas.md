# Phase 1 — Raw Ideas (원석 발산) · AI for Science & Materials

> 규칙: 래퍼/앱 금지. 딥테크 원석만. 각 원석 = 한 줄 컨셉 + 기술 모트 후보 + 하드 메트릭 후보.
> 좌표: domain_brief 결론(합성가능성·역합성·능동검증) 중심 + 트랙 전 범위 탐색.

## A. 합성가능성 (Synthesizability) 레이어
1. **SynthGate** — 생성형 모델(GNoME/MatterGen) 출력 결정구조에 "합성가능성 확률 + 신규성 + 유용성" 점수를 매기는 게이트 모델. 모트: 합성성공/실패 라벨 데이터 + 물리 디스크립터. 메트릭: 합성성공 예측 precision@k.
2. **NonNovel Filter** — 예측 구조가 기존 물질의 사소한 변형인지 판별(Cheetham 비판 자동화). 모트: 구조 유사도+프로토타입 임베딩. 메트릭: false-novel 제거율.
3. **RadioTox Screen** — 비현실(방사성·독성·고가 원소) 후보 자동 제거 + 대체 조성 제안. 모트: 제약·규제·가용성 그래프. (단독은 약함)

## B. 무기 역합성 (Inverse/Retro-synthesis) 엔진 ★
4. **RetroForge** — 목표 무기상 → 전구체 조합 + 소성 온도/분위기/시간 경로를 추천하는 무기 역합성 엔진. 모트: 텍스트마이닝+능동학습으로 구축한 무기합성 반응 그래프(상용 DB 부재). 메트릭: top-k 경로 실험 성공률.
5. **PrecursorRank** — 신규 목표상에 대한 전구체 추천 일반화(unknown precursor 외삽). 모트: 화학 유사도 잠재공간 + 열역학 제약. 메트릭: novel-reaction 일반화 정확도.
6. **CalcineNet** — 소성(calcination) 조건(온도램프·분위기) 물리정보 예측 모델. 모트: 반응속도+상평형 물리 prior. 메트릭: 조건 MAE vs 실험.
7. **FailMine** — 실패 합성(negative data) 능동수집·라벨링 파이프라인 + 모델. 모트: 산업/연구 실패 데이터 독점 수집(아무도 안 모음). 메트릭: 실패 예측 recall.

## C. 능동학습 실험설계 + UQ
8. **CloseLoop-AL** — 검증 파트너와 폐루프: UQ 기반 다음 실험 추천(최소 실험으로 목표 물성 달성). 모트: 신뢰가능 UQ + 베이지안 실험설계. 메트릭: 목표 도달까지 실험 횟수 감소배수.
9. **CalibUQ** — 오설정(misspecified) MLIP용 보정된 불확실성 — OOD 탐지. 모트: 새 UQ 알고리즘. 메트릭: OOD AUROC.
10. **DataFusion-FF** — 실험+DFT 융합으로 실험물성 직접 맞추는 force field 보정. 모트: 차등가능 시뮬+실험 손실. 메트릭: 실험물성 MAE.

## D. 응용 수직 (배터리/촉매/기후)
11. **ElectrolyteGen** — 리튬금속/SSE용 전해질 조성 역설계 + 도메인전이(카보네이트→에테르 일반화). 모트: 전해질 특화 데이터+물리. 메트릭: 이온전도도 예측 R².
12. **SSE-Diffuse** — 고체전해질 비정질/결정 이온확산 surrogate(MLIP). 모트: 비정질 데이터. 메트릭: 확산계수 정확도 vs AIMD 속도배수.
13. **CO2Cat** — CO2 환원 촉매 역설계 + 고체-액체 계면(OC25 활용). 모트: 계면 능동학습. 메트릭: 선택성·과전압 예측.
14. **GreenH2-Cat** — 그린수소(OER/HER) 전극촉매 비귀금속 대체 탐색. 모트: 활성+안정성+합성가능성 멀티목표. 메트릭: 활성 예측 + 합성성공.
15. **DegradeNet** — 배터리 셀 열화 물리정보 surrogate(소재→수명). 모트: 필드+랩 데이터 브릿지. 메트릭: 수명 예측 오차.

## E. Surrogate / PINN / 시뮬레이션 대체
16. **ProcessPINN** — 소재 공정(소결·CVD·결정성장) 물리정보신경망 대체모델. 모트: PDE+공정 데이터. 메트릭: 시뮬 대비 속도×정확도.
17. **PhaseDiagramNet** — 다성분 상평형도 ML 예측(CALPHAD 대체/가속). 모트: 열역학 일관성 제약. 메트릭: 상경계 정확도.
18. **MultiFidelity-Surrogate** — 저정확도(빠름)~고정확도(DFT/실험) 멀티충실도 능동학습 surrogate. 모트: 멀티충실도 GP/NN. 메트릭: 비용당 정보획득.

## F. 데이터/표현 레이어
19. **NegDB** — 무기합성 "음성·실패·조건" 데이터 표준 스키마 + 능동수집 컨소시엄. 모트: 데이터 독점. (인프라성)
20. **RecipeLLM-Extract** — 논문 PDF에서 합성 레시피 구조화 추출(맥락·결측 보정). 모트: 도메인 파인튜닝+검증. 메트릭: 추출 F1. (래퍼 위험 — 주의)
21. **CrystalRep** — 합성경로 인지 결정 표현학습(구조+공정 공동임베딩). 모트: 표현. 메트릭: 다운스트림 전이.

## G. Wildcard / 인접
22. **MOF-Synth** — 다공성 MOF 역합성+합성가능성(가스분리·탄소포집). 모트: MOF 합성 데이터. 메트릭: 합성성공.
23. **Polymer-Inverse** — 고분자 역설계(서열→물성). 모트: 고분자 표현. 메트릭: 물성 예측.
24. **Alloy-Process** — 고엔트로피 합금 조성+공정 공동최적. 모트: 공정-조성 결합. 메트릭: 경도/연성 예측.
25. **SelfDrivingLab-Brain** — 자율실험실용 "두뇌" SW(하드웨어는 파트너)= 능동학습 의사결정 엔진. 모트: 의사결정 알고리즘. 메트릭: 실험효율.
26. **SynthRisk-Industrial** — 신소재의 산업 스케일업 합성 리스크/원가 예측. 모트: 공정경제+합성. 메트릭: 스케일업 성공/원가 오차.

## H. 통합 콘셉트 (결합형)
27. **★ ForgeStack** — 생성기(외부) 뒤에 붙는 통합 "post-generative" 레이어: 합성가능성 게이트(1) + 무기 역합성(4) + 능동검증 폐루프(8). 목표상 입력 → 만들 수 있는지 + 어떻게 + 다음 실험까지. 모트: 합성/실패 반응그래프 데이터 + 역합성 알고리즘 + UQ 능동학습 통합.
28. **★ RetroForge-Battery** — 27을 배터리 양극/전해질 수직에 집중(경기도 소부장 정합). 좁은 데이터·명확 고객.
29. **MatterMaker-API** — 27을 API로 빅테크 생성기·연구실에 공급(B2B 인프라). 
30. **ActiveSynth-CRO** — 27 + 검증 파트너 네트워크로 "인실리코→검증" CRO형 서비스(모트는 모델, 합성은 외주).
