# Phase 8 — 사업계획서 스켈레톤 (양식1 16항목) · RetroForge-Battery

> 표기: 숫자에 출처 없는 것은 **(가설)**. 핵심 모트는 팀 주도 인실리코, 검증·합성은 경기도 파트너 외주.

## 1. 한 줄 정의 (30초 피치)
"신소재 AI는 '뭘 만들지'까지만 답합니다. RetroForge는 목표 배터리 소재를 넣으면 **만들 수 있는지·어떤 전구체와 소성조건으로·다음에 무슨 실험을 해야 가장 빨리 성공하는지**까지 알려주는 무기소재 'AI 합성 레시피' 엔진입니다."

## 2. 문제 (정량)
- 생성형 소재 AI(GNoME 2.2M 후보)가 쏟아낸 구조의 다수가 **기존 변형·비현실·합성불가** — Cheetham/Seshadri(2024) 비판, Nature(2025) "쓸만한가?". [출처](https://www.nature.com/articles/d41586-025-03147-9)
- 무기소재는 **상용 합성 반응 DB 부재**, 합성은 통일이론 없이 시행착오 — 신조성 양극 소성조건 잡는 데 수개월·수십~수백 실험·수천만원 **(가설, 산업 통념)**. [출처](https://pmc.ncbi.nlm.nih.gov/articles/PMC10256153/)

## 3. 솔루션 (왜 10배)
SynthGate(합성가능성)+RetroForge Core(전구체·소성조건 역합성)+CloseLoop-AL(능동학습). 목표 상순도 도달 실험 횟수 **5~10배 감소(가설)** + novel-target 일반화(현 SOTA 불가→가능).

## 4. 왜 지금 (Why Now)
생성·UMLIP 돌파로 "뭘 만들지"는 풀렸으나(2023~25) "어떻게 만들지"가 비어있음. 공개 텍스트마이닝 데이터(31,782 반응)로 부트스트랩 가능 시점 + 한국 이차전지 산업 소재 경쟁 격화. [출처](https://github.com/CederGroupHub/text-mined-synthesis_public)

## 5. 차별성·해자
독점 실패/조건 폐루프 데이터(세상에 거의 없음) + 역합성/UQ 알고리즘 + 물리 prior. 빅테크는 생성 레이어만, 기존 플랫폼(Citrine 등)은 워크플로우/데이터에 머묾. 시간이 갈수록 폐루프로 복제불가 심화.

## 6. 시장 TAM/SAM/SOM
- TAM: AI in Materials Discovery 2034 **$5.58B**(CAGR 26.4%). [출처](https://market.us/report/ai-in-materials-discovery-market/) / Materials Informatics 2035 **$1.31B**. [출처](https://www.precedenceresearch.com/material-informatics-market)
- SAM **(가설):** 배터리/이차전지 소재 R&D 도구 — 글로벌 소부장·셀·연구소.
- SOM **(가설):** 경기도+한국 이차전지 소부장·연구소 R&D 라이선스 초기 타깃 수십~수백곳.

## 7. 수익모델·단위경제 (가설)
- 가격: SaaS 구독 시트당 월 **(가설)** + 폐루프 검증 프로젝트 성과형 수수료 + 향후 API 종량.
- 원가: 주로 GPU/DFT 컴퓨팅(융기원·클라우드 크레딧) + 인건비. SW 한계비용 낮음 → 목표 그로스마진 **70%+ (가설)**.
- BEP **(가설):** 유료 PoC/구독 고객 누적 + 공동연구비로 24~36개월 내 운영 BEP 지향.

## 8. GTM (초기고객 10곳·파트너·해외)
- 초기 10곳 후보 **(가설):** 경기도 이차전지 양극재·전구체·전해질 소부장 + 셀 R&D + 융기원/가천대/KAIST 연구실.
- 파트너: 융기원(검증합성·컴퓨팅), 가천대(자문·합성), 소부장(파일럿·데이터).
- 해외: 일본·유럽·미국 배터리 소재 R&D → API/구독(공모 '글로벌 진출' 방향성 정합).

## 9. MVP & 마일스톤 (6/12/18개월, 4인)
- 6개월: 공개데이터 학습 v0(합성가능성 게이트+전구체 추천) + 융기원/가천대 공동연구 협약 + 소부장 LOI 3건.
- 12개월: 소성조건 역합성 + 능동학습 폐루프 v1 + **킬러 웻지 데모**(단일 양극 소성조건 추천→파트너 합성→상순도 성공) + 유료 PoC 1~2건.
- 18~24개월: novel-target 일반화 입증(하드 메트릭) + 구독 전환 + 2차 수직(고체전해질/촉매) 착수.

## 10. 조직역량 (역할 매핑)
- 김범수(대표·AI/데이터): 모델·역합성/능동학습 알고리즘·사업.
- 신승민·송채우(SW/풀스택): 데이터 파이프라인·폐루프 시스템·플랫폼.
- 자문(가천대 무기화학/NCM 연구진): 합성 도메인·검증 설계. (핵심 모트 팀 주도, 합성 외주)

## 11. 경기도 레버리지

- 영업비밀: 실패/조건 폐루프 데이터셋·파이프라인.
- 공모 제출 전 핵심 청구항 비공개/출원 검토(R6: 공개 시 보호불가 주의).

## 13. 리스크 Top5 & 대응
1. novel-target 일반화 실패 → 좁은 수직·물리 prior·폐루프로 단계적 입증.
2. 실패데이터 확보난 → 파트너 NDA 폐루프·공동연구비로 독점 수집.
3. DFT↔실험 격차 → 실험라벨 보정, DFT-only 주장 안 함.
4. 빅테크가 합성 레이어 진입 → 한국 수직·폐루프 데이터·경기도 락인으로 선점.
5. 검증 파트너 의존 → 다중 파트너(융기원·가천대·소부장) + 협약 명문화.

## 15. 예상 심사질문 10 + 모범답변 (요지)
1. GNoME/MatterGen과 뭐가 다른가 → 그들은 생성, 우리는 합성가능성·역합성·검증(비어있는 레이어).
2. 학생팀이 합성을 하나 → 안 한다, 모델이 모트·합성은 융기원/가천대 외주.
3. 데이터 어디서 → 공개 31,782 반응 부트스트랩 + 파트너 폐루프 독점 확장.
4. 복제 안 되나 → 음성/실패데이터·역합성 알고리즘·특허, 주말 복제 불가.
5. 첫 매출 → 소성조건 추천 유료 PoC(성과형)+공동연구비, 6~12개월.
6. 10배 근거 → 능동학습 실험횟수 5~10배 감소(정보이론), novel-target 불가→가능.
7. 과학적 타당성 → 열역학+반응속도+정보이론 제1원리, DFT 격차 정직 보정.
8. 경쟁(Citrine 등) → 그들은 워크플로우/데이터, 우리는 역합성 코어 알고리즘.
9. 경기도 연결 → 용인·평택 배터리 클러스터·융기원·가천대.
10. 글로벌 → 일·유·미 배터리 R&D에 API/구독.
