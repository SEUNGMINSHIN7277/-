# Phase 3 — 사업화 격투 (Business Combat) Round 2

> 격투 기준: 데이터 조달 현실성 / 24개월 빌더블 / 고객·단가·단위경제 / 경기도 정합 / 빅테크 비복제성 / 검증루프 현실성.

## 결정적 접지 사실 (Phase 3 리서치)
- **데이터 모트 부트스트랩 가능:** CederGroupHub 텍스트마이닝 무기합성 데이터셋 = **고체합성 31,782 반응 + 졸겔 9,518 반응 공개**(전구체·조작·조건·균형반응식 포함). 학생팀이 즉시 학습 시작 가능, 이후 실패데이터·파트너 실험으로 독점 확장. [출처](https://github.com/CederGroupHub/text-mined-synthesis_public) · [Nature Sci Data](https://www.nature.com/articles/s41597-019-0224-1)
- **팀 모교 정합:** **가천대**가 NCM 양극 합성최적화(소성온도·코팅) 논문 발표 — 팀의 교수 자문·검증 파트너 접근이 실재. [출처](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC11243152/)
- **KAIST 양극 역설계 surrogate** 연구 존재 — 역합성 방향 과학적 타당성 확인. [출처](https://pure.kaist.ac.kr/en/publications/machine-learning-assisted-synthesis-of-lithium-ion-batteries-cath/)

## 본선 3종 격투

### F1. RetroForge (수평 무기 역합성 엔진) — S1/S4
- 강점: 가장 넓은 모트, 빅테크 미보유 빈 공간 전체.
- 약점: 수평이라 첫 고객·검증루프가 분산. 24개월에 전 화학공간 검증 불가. 메트릭 입증 표적이 흐림. 단위경제 모호.
- 판정: **모트는 최강이나 사업화 초점 약함.** 수직으로 좁혀야 빌더블·채점 산다.

### F2. ★ RetroForge-Battery (배터리 소재 역합성+합성가능성+능동검증) — S5
- 강점:
  - **데이터:** 공개 데이터셋에 배터리 산화물(양극 NCM/LFP, 고체전해질) 비중 큼 → 좁고 깊게 학습. 실패·조건 데이터를 경기도 소부장·융기원·가천대와 폐루프로 독점 확장.
  - **고객 명확:** 경기도 이차전지 소부장(양극재·전구체·전해질 기업), 연구소 R&D팀. 통증: 신조성 소성조건 시행착오에 수개월·수천만원.
  - **단위경제:** SW 구독(라이선스) + 검증 폐루프 성과형. 한계비용 낮음(SW).
  - **24개월 빌더블:** 좁은 수직 + 공개데이터 부트스트랩 + 가천대/융기원 검증 외주 → 현실적.
  - **경기도 정합 최상:** 용인·평택 클러스터, 이차전지 소부장, 융기원, 가천대 모두 정렬.
- 약점: 배터리 데이터 일부 영업비밀. → 공개데이터로 시작 + 파트너 NDA 폐루프로 해소.
- 판정: **1순위.** 모트·빌더블·경기도·고객 전부 정합.

### F3. CO2/GreenH2-Cat (기후촉매 역설계) — S6
- 강점: 기후 TAM, OC25 계면 데이터.
- 약점: 전기화학 셀 검증이 배터리보다 복잡·고비용, 학생팀 검증루프 비현실. 고객·단가 모호.
- 판정: 차순위. 동일 코어의 2차 수직으로 후순위.
