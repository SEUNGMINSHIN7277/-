# Phase 4 — Cutting (컷팅) · RetroForge-Battery

## 한 줄 정의 (30초 피치)
**"신소재 설계 AI가 '뭘 만들지'는 답해도 '어떻게 만들지'는 못 답한다. RetroForge는 목표 배터리 소재(양극·고체전해질)를 입력하면, 실제로 합성 가능한지(게이트) + 어떤 전구체·소성조건으로 만들지(무기 역합성) + 다음에 어떤 실험을 해야 가장 빨리 성공하는지(능동학습)를 내놓는, 무기소재 합성가능성·역합성 딥테크 엔진이다."**

## 정밀 컷팅된 정의 (3개 모듈, 1개 모트)

### 모듈 1 — SynthGate (합성가능성 게이트)
생성형 모델(GNoME/MatterGen/사내 후보) 출력 또는 목표 조성을 입력받아 **합성가능성 확률 + 신규성(기존 변형 여부) + 유용성**을 점수화. Cheetham/Seshadri가 지적한 생성모델의 공인된 약점을 자동 해결.

### 모듈 2 — RetroForge Core (무기 역합성 엔진) ★핵심
목표 무기상 → **전구체 조합 + 소성 온도램프·분위기·시간 경로**를 top-k로 추천. 
- 학습 자산: 공개 텍스트마이닝 반응그래프(31,782 고체 + 9,518 졸겔) + **자체 확장 실패/조건 데이터(모트)** + 열역학/반응속도 물리 prior.
- 미해결성: 무기는 상용 반응 DB 부재, known-precursor 외삽 실패가 SOTA 한계 → 화학유사도 잠재공간 + 물리제약 랭킹으로 일반화.

### 모듈 3 — CloseLoop-AL (능동학습 검증 폐루프)
보정된 UQ 기반으로 **다음 실험을 최소비용 최대정보**로 추천. 경기도 검증 파트너(융기원·가천대·소부장)의 합성 결과를 다시 학습 → 모델·데이터가 누적되는 **데이터 플라이휠**.

## 단일 모트 (왜 복제 불가)
> **"무기 배터리 소재의 합성성공/실패·조건 반응그래프 데이터 + 그 위의 역합성 랭킹·UQ 능동학습 알고리즘"** 
> = 공개 API/오픈소스로 주말에 복제 불가. 빅테크 생성 모델은 "구조 생성"까지만 하고 합성가능성·역합성 레이어를 비워둠. 데이터는 폐루프로 매주 독점 누적(특히 음성/실패 데이터는 세상에 거의 없음).

## 컷팅 결정 (다이아몬드 형태)
- **수직 고정:** 배터리 소재(양극 NCM/LFP/하이망간, 고체전해질 산화물·황화물) — 데이터 밀도·고객·경기도 정합 최상. (촉매·MOF는 후속 확장)
- **첫 검증 표적:** 양극 산화물 소성조건 추천 → 파트너 합성 → XRD 상순도/전기화학으로 성공 라벨. 좁고 측정가능.
- **하드 메트릭(검증 표적):** ① 역합성 top-5 경로 실험 성공률, ② 목표 상순도 도달까지 실험 횟수 감소배수(능동학습), ③ novel-target(학습 외 조성) 일반화 정확도.
- **사업모델:** SW 구독(소부장·연구소 R&D 라이선스) + 능동검증 폐루프 성과형 + 향후 API 인프라.
- **팀-시장 적합:** 대표(AI/데이터)·개발 2인(SW/풀스택)이 모델·파이프라인 주도, 합성은 가천대/융기원 외주 — 트랙 제약(웻랩 자체구축 금지)과 정합.
