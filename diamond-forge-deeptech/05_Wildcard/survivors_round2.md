# Phase 3 — 사업화 격투 (생존 2~3개)

> 격투 기준(_SHARED_CONTEXT R1): 사업성·실현가능성 최중량 + 성장성·차별성 두 축 8.5/10. 24개월 빌더블 + Gate C 진정성.

## 후보 재구성
생존 5개를 사업 단위로 묶으면 사실상 3개 사업 명제로 압축된다.

### 명제 X — "HE-Cast 컴파일러 플랫폼" (1+2+3+4 통합, 수평 툴체인)
- 정의: 일반 ML 모델 → FHE 배포 가능 모델 자동 변환 + 멀티-GPU 서빙. 개발자 도구/플랫폼.
- 사업성: 개발자 툴 = 채택은 강하나 초기 매출 느림(오픈코어). BEP 늦음.
- 차별성/모트: ★최고(알고리즘 그 자체). Zama와 정면.
- 빌더블: 컴파일러 풀스택 24개월 빌더블(MVP는 CNN/소형 트랜스포머 범위로 한정 가능).

### 명제 Y — "HE-Risk: 규제특화 암호화 추론 PoC" (5 단독, 수직 SaaS)
- 정의: 韓 금융/의료가 민감데이터를 평문 비저장으로 스코어링/분석. 도메인 수직.
- 사업성: 규제 강제(MyData/PIPA) → 지불의사 높음, 첫 매출 빠름(PoC 유상). ★
- 차별성: 도메인 데이터+규제 적합이 해자. 단, 코어 알고리즘이 약하면 Gate C 위험.
- 빌더블: 단일 유스케이스(예: 신용/이상거래 또는 의료 코호트 통계)면 24개월 충분.

### 명제 Z — "HE-Cast + 첫 수직(금융 이상거래)을 한 제품으로" ★최종 채택
- 정의: **코어=HE-Cast 컴파일러(수평 모트)**, **쐐기=금융 이상거래/신용 스코어링 암호화 추론(수직 매출·규제 강제)**.
- 왜 우승: 컴파일러의 깊은 알고리즘 모트(Gate C·Gate A 만족) + 수직의 빠른 첫 매출·규제 강제 수요(Gate B 사업성·시장진출 만족). 둘의 결합으로 두 축(차별성·사업성) 모두 8.5+.
- 24개월 현실 쐐기: "표 형식/소규모 신경망(이상거래·신용) 모델을 FHE 추론으로 자동 변환·서빙"으로 범위 한정 → 곱셈깊이 낮아 bootstrapping 부담 최소, 정확도-지연 실증 용이. LLM 풀-FHE는 로드맵 후기로 분리(현실 쐐기).

## 생존 2개 → 결선
1. **명제 Z (HE-Cast + 금융 수직 쐐기)** — 본선 진출.
2. **명제 Y (의료 MyData 수직)** — 차순위 백업(코어 알고리즘 모트 약하면 Z가 흡수).

> 탈락: 명제 X 순수 수평 툴(첫 매출 경로 약 → Gate B 사업성 미달 위험). 단 X의 코어 기술은 Z에 그대로 내장.
