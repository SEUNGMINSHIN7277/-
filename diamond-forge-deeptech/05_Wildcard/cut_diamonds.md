# Phase 4 — 컷팅 (다이아몬드 정밀 가공)

## 확정 원석: 명제 Z — **HE-Cast**
**코어(수평 모트):** 일반 신경망을 **곱셈깊이(multiplicative depth)·정확도·bootstrap 횟수를 공동최적화**하여 FHE(CKKS) 추론 가능 모델로 자동 변환하는 컴파일러+재훈련 엔진.
**쐐기(수직 매출):** 금융 이상거래/신용 스코어링 — 은행/PG가 **고객 민감 피처를 평문으로 보지 않고**(암호문 그대로) 스코어링.

---

## 깎아낸 면(facet) 정의

### 1. 한 줄 정의 (30초)
"개발자가 자기 AI 모델을 넣으면, 데이터를 **암호화된 채로 추론**할 수 있게 자동 변환·배포해주는 컴파일러. 첫 시장은 한국 금융의 암호화 이상거래 탐지."

### 2. 핵심 기술 돌파 3종 (이 팀이 주도 가능한 알고리즘 모트)
- **(a) Depth-Accuracy 공동최적화 컴파일러:** 비선형 활성화(ReLU/GELU)를 *입력분포 인지 적응 다항*으로 치환하되, 전체 네트워크 곱셈깊이 예산 하에서 다항 차수·구간·QAT를 **공동 최적화**(혼합정수/경사기반). 기존: 레이어별 수동 근사. 우리: depth-budget 제약 자동 탐색.
- **(b) Bootstrap 최소 스케줄러:** 연산 그래프에서 bootstrap 삽입 위치를 DAG 최단경로/ILP로 최소화(레벨 소비 추적). 목표 지표: 동일 정확도에서 **bootstrap 호출 수 최소화 = 지연/비용 직접 절감.**
- **(c) 적응 다항 라이브러리 + 자동 캘리브레이션:** 입력 범위 벗어남으로 인한 발산을 클립·구간분할로 방지, 정확도 손실 한계(예: <1%p) 보장 탐색.
> (a)(b)(c) 모두 **공개 API/오픈소스로 주말 복제 불가** — 미해결 알고리즘 난제. 핵심 청구항 출원 대상.

### 3. 하드 메트릭 10배 목표(가설, 제1원리 논증)
- **bootstrap/추론 횟수 10x↓** 또는 **동일 지연에서 모델 깊이 10x↑** (제1원리: bootstrapping이 CKKS 비용의 지배항 → 깊이/부트스트랩을 줄이면 비용 선형 감소; 깊이최적화는 NP-hard 근사이나 도메인 한정(표/소형망)에서 실용해 존재).
- **불가능→가능:** "민감데이터를 클라우드에 평문 전송 없이 외부 ML 모델로 스코어링" — 규제상 현재 불가한 워크플로를 가능케 함.

### 4. 24개월 빌더블 범위 한정(현실 쐐기)
- MVP 대상 = **표형식/소규모 CNN·MLP(이상거래·신용)** → 곱셈깊이 낮음 → bootstrapping 최소 → 단일 GPU(클라우드)에서 실증 가능. (LLM 풀-FHE는 명시적 후기 로드맵.)
- 기반: OpenFHE/FIDESlib(오픈소스 GPU CKKS) 위에 컴파일러·스케줄러·서빙 구축. 칩 양산 0.

### 5. 보강 포인트(게이트 대비 선제)
- **Gate B 도민 이해도:** "은행이 내 개인정보를 *못 보면서* 사기 잡는다" — 30초 비유 확보.
- **Gate C 진정성:** 가치=알고리즘 난제 해결. UI 아님. 특허 청구항 (a)(b)(c).
- **첫 매출:** 유상 PoC(은행 1곳, 핀테크 1곳) → 라이선스/처리량 과금.
