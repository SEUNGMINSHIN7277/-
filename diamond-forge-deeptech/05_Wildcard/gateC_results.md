### C-1. 기술 돌파 기반 (12~24개월 실재 메커니즘) — ✅ 충족
- 뿌리: 적응 다항 근사(arXiv 2404.03216, 2508.11575, 2605.22237), HEIR cross-scheme IR(NDSS 2024), GPU CKKS 70x bootstrapping(FIDESlib 2025), Orion bootstrap DAG 배치(2025). **"기존+ChatGPT API"가 아님** — 새로운 *컴파일러 최적화 메커니즘*(depth-accuracy-bootstrap 공동최적화).

### C-2. 방어가능 IP (래퍼 킬 테스트) — ✅ 충족
- "유능한 팀이 공개 API·오픈소스로 주말 안에 복제?" → **NO.** 핵심 가치가 UI/통합이 아니라 **미해결 알고리즘**(depth-budget 제약 다항/구간/QAT 공동최적화 + bootstrap 최소 스케줄링). OpenFHE/FIDESlib는 *저수준 라이브러리*일 뿐, "모델 넣으면 깊이최적 FHE 모델 자동 산출"은 부재. 특허 청구항 3종(앞서 (a)(b)(c)) + 학습 캘리브레이션 데이터/벤치 영업비밀.

### C-3. 하드 메트릭 10배 + 제1원리 — ✅ 충족
- 지표: **bootstrap 호출 수 / 추론 지연 / 비용**. 목표 동일 정확도에서 10x↓(가설). 제1원리: bootstrapping이 CKKS 비용 지배항 → 깊이·부트스트랩 감소 = 비용 선형 절감. 표/소형망 도메인 한정에서 실용해 존재(NP-hard지만 근사 가능). **불가능→가능**: 규제상 평문 전송 불가한 외부 ML 스코어링 워크플로 해제. 과학 킬(Tier3) **0건**(정보이론·물리 위배 없음; FHE 안전성은 RLWE 표준 가정).

### C-4. 빌더블 쐐기 (24개월) — ✅ 충족
