## 4. 🏆 다이아몬드의 다이아몬드 확정: **SENTINEL-Core**

### 한 줄 정의
규제산업이 자기 서버 안에서 LLM을 돌릴 때, 모델의 *내부 활성화(생각 단계)*를 실시간 조종해
규정위반·환각을 **출력 전에** 차단하는 온프렘 추론 거버넌스 딥테크 SW.

### 왜 이게 수상 1순위인가 (반박 가능한 3대 근거)

**근거 1 — 데모 가능성 × 사업성의 동시 우위 (수상 확률의 결정 변수).**
G스타는 결선이 **현장 공개 발표 심사**다. 작동하는 데모를 못 보여주면 "아이디어"로 격하된다.
- HAPTYX는 결선장에 로봇팔+촉각센서+조립지그를 들고 와야 하고(물리·예산·안전 장벽), RetroForge는 10배 주장의 핵심인 "추천→실제 합성→순도 성공" 폐루프가 외부 웻랩 다개월 의존이라 **결선 전 입증 불가**, RETARGET은 데모가 오픈 Sky130에 갇혀 "상용노드에서 되냐"는 직격을 맞는다.
- SENTINEL은 **오픈 모델 + 공개 SAE 인프라(Gemma Scope) 위에서 노트북/클라우드로 탐지율·오탐·지연 벤치를 라이브 시연**할 수 있다. 데모 리스크가 5개 중 가장 낮고, C1·C4 둘 다 최고점.

**근거 2 — Why-now가 "추세"가 아니라 "법"이다.**
AI기본법(2026.1.22 시행)이 규제기관의 클라우드 LLM 사용을 제약 → **온프렘 LLM은 선택이 아니라 강제**. 온프렘에는 클라우드급 안전장치가 없고, 기존 가드레일은 출력 후 필터(별도 모델 호출=지연·우회). SENTINEL은 시장이 *법으로 만들어지는* 유일한 후보다. 나머지 4개의 Why-now(파운드리 위기, 인력난, 합성 병목, 프라이버시 규제)는 강하지만 *법적 강제*만큼 결정적이진 않다.

**근거 3 — founder-fit이 진짜로 박혀 있다.**
대표 김범수가 신한카드 데이터로 마케팅 AI를 만든 **규제 금융데이터 직접 경험**이 곧 첫 도메인(금융 규정 concept feature)과 일치. 개발 2인은 풀스택/시스템으로 온프렘 런타임 통합을 담당. 핵심 모트(내부 steering)는 팀의 AI/SW 코어로 주도 구현 가능 — 외부 웻랩(RetroForge)·실물 로봇(HAPTYX)·디바이스 물리 전문성(RETARGET)·암호 전문성(HE-Cast) 같은 **팀 밖 의존이 가장 적다.**

### 왜 나머지는 1순위가 아닌가 (정직한 탈락 사유)
- **HE-Cast (2위, 가장 근접):** 메시지·데모·모트 모두 강하나, C1에서 SENTINEL에 밀린다. FHE 절대지연(10^5배)으로 표·소형망에 갇히고, 핵심 가치가 암호 도메인이라 자문 의존이 크다. 데모는 되지만 "느려서 실서비스 되냐"는 질문에 SENTINEL만큼 깔끔히 못 답한다. **최강 대안.**
- **RETARGET (3위):** 경기도 정합 최고지만, 데모가 오픈 PDK에 갇혀 정량 주장(10~50배)이 상용노드에서 의심받고, 도민 공감·founder-fit(디바이스 물리 갭)이 동시에 약하다.
- **RetroForge (4위):** 모트는 5개 중 가장 깊으나, 그 모트의 증명(음성 합성데이터·폐루프 성공)이 결선 시점에 외부 웻랩 의존으로 보여줄 수 없다 — 모트가 깊을수록 **18개월 내 입증이 어려운** 역설.
- **HAPTYX (5위):** 도민 공감 1위지만 결선 데모가 실물 하드웨어·조립지그·안전펜스를 요구해 4인 학생팀·발표 무대에서 **물리적으로 가장 막힌다.** cold-start도 실물 로봇 없이는 불가.

### 2~3순위(대안)
- **2순위(대안): HE-Cast** — 도민 메시지가 가장 강력. SENTINEL이 SAE 신뢰성 벽에 막히면 즉시 승격할 폴백.
- **3순위(대안): RETARGET-AI** — 경기도 정책 레버리지(반도체 클러스터)가 가장 강해 *지역 심사위원 가점* 시나리오에서 역전 가능성.

## 5. 우승작 보강 루프 1회 — SENTINEL-Core

### 가장 약한 rubric 항목 2개 식별 (Gate B 기준)
원 Gate B(91.0)에서 잔여 감점이 남은 항목:
1. **사업성 (23/25):** 학생팀의 **온프렘 엔터프라이즈 영업 실전 미검증** + 첫 유료고객 경로가 "가설"에 머묾(DCVC 조건부 YES의 핵심 우려).
2. **조직역량 (13.5/15):** 자문이 "가정형"이고, SAE feature 신뢰성을 책임질 interpretability 자문이 확정 아님.

### 구체 보강 (첫고객 LOI·자문 확정·데모·단위경제·IP 청구항)

**보강 A — 첫고객 LOI 전략 (사업성):**
- **3-LOI 게이트:** 결선 전까지 ① 판교 저축은행·캐피탈 1곳, ② 가천대 길병원 임상 LLM TF 1곳, ③ 경과원 규제샌드박스 실증 1건의 **의향서(LOI) 3건**을 확보 목표. LOI는 "PoC 무료 → 탐지율/오탐 기준 충족 시 12개월 내 연 0.5억 유료 전환" 조건을 명문화 → 영업주기를 *레퍼런스 기반*으로 단축.
- **90일 PoC→유료 플레이북:** (1) 고객 온프렘 모델에 SAE feature 사전 주입(2주) → (2) 규정위반/환각 탐지율·오탐·지연 벤치(4주) → (3) 백업 출력필터 하이브리드로 안전기준 충족(4주) → (4) 유료 전환 SOW. 단위 영업주기 6~9개월 → 3개월.

**보강 B — 자문 확정 (조직역량):**
- **확정형 자문 2인 명문화:** ① 차세대융합기술연구원 mechanistic interpretability 자문 1인(SAE feature 신뢰성·재추출 파이프라인 검증 책임), ② 가천대 길병원 임상 LLM 자문 1인(의료 도메인 concept feature·임상 안전기준). MOU를 6개월 마일스톤으로 못박음.
- **신뢰성 책임 분리:** 자문 1이 "feature 신뢰성 벤치 설계"를 공동 서명 → 최대 기술리스크(SAE 오탐)를 외부 검증으로 흡수.

**보강 C — 데모 계획 (발표·데모):**
- 결선 라이브 데모 스크립트: 오픈 모델(예: 한국어 LLM) + Gemma Scope류 공개 SAE 위에서 ① "거짓 규정 인용" 프롬프트 입력 → ② **출력 직전 내부 활성화에서 위반 feature 점등 시각화** → ③ steering으로 교정된 안전 출력 → ④ 출력 후 필터 대비 지연(ms) 막대그래프. 30초 안에 "말하기 전에 잡는다"를 눈으로 보여줌.

**보강 D — 단위경제 정밀화 (사업성):**
- 가격: 코어 구독 연 0.6억(소형기관)~1.5억(은행), 도메인 feature팩 연 0.2억/도메인, 통합 1회성 0.3억.

## 6. 우승작 남은 최대 리스크 (정직)

**최대 리스크 = SAE feature 신뢰성의 기술 입증.**
내부 steering의 10배 우위는 SAE가 "규정위반/환각" 개념을 *신뢰성 있게* 분리·억제할 수 있다는 가정에 의존한다. mechanistic interpretability는 활발하지만 미성숙 분야이고, 도메인 feature의 오탐/미탐이 높으면 제품 가치가 붕괴한다.
→ **완화:** (1) 6개월 PoC 1단계의 핵심 KPI를 탐지율/오탐/지연 벤치로 고정, (2) 백업 출력필터 하이브리드로 안전 하한선 보장, (3) 융기원 interp 자문이 신뢰성 벤치 공동 설계. 그래도 이 벽을 못 넘으면 폴백은 **HE-Cast(2순위)**.

**부차 리스크:** 학생팀의 온프렘 엔터프라이즈 영업 실전 부재(LOI는 의향서일 뿐) + NeMo Guardrails 등 대형벤더의 한국 규제도메인 진입 가능성(→ 온프렘×내부개입×한국 규정 feature 사전의 빈틈 선점으로 방어).
