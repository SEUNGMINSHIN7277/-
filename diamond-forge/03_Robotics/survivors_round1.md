## ✅ 생존 6개 (Phase 3 진입)

### S1. 자연어·시연 기반 cobot Teaching & 고혼합소량 자동 재배치 SW  ⭐최유력
(#1+#2+#4+#5+#30 통합)
- **핵심:** 기성 cobot(두산·유니버설로봇·한화 등) 위에 얹는 "말로 가르치고, SKU 바뀌면 비전이 알아서 재배치" 소프트웨어 레이어.
- **과학성:** LLM 코드생성(미성숙→정형 안전검증 게이트로 보완) + 비전 그라운딩 + imitation. 현 기술로 제한범위(픽앤플레이스·검사·디버링 등 구조화 태스크) 내 실현 가능.
- **하드웨어 의존:** 0 양산. cobot은 고객 보유/임대. **SW only.**
- **첫 매출:** SME 라이선스/SaaS + 경기도 정부지원금 연계 도입.
- **해자:** 현장 teaching·재배치 행동 데이터 축적(쓸수록 스킬 라이브러리 강화) + founder-market fit(팀의 AI/LLM·풀스택 강점 직결).

### S2. 무질서 빈피킹(bin-picking) 비전 AI SaaS (#6+#7 흡수)
- 기성 팔+카메라 위 6DoF 자세추정 픽킹 + few-shot 결함검사.
- 과학성: 빈피킹은 성숙 영역(경쟁 다수: 다수 SI·솔루션). 차별성 확보가 관건.
- 하드웨어 의존 0, 첫 매출 명확. 단 레드오션 위험.

### S3. 로봇 시연 데이터 운영 플랫폼 "로봇판 Scale AI" (#10+#11+#12 통합)
- 텔레오퍼/인간시연/합성 데이터 수집·정합·품질·라벨 SaaS. VLA 시대 데이터 병목 정조준.
- 과학성: 데이터 운영은 명확히 실현 가능. 글로벌 TAM 거대.
- 리스크: 고객이 글로벌 로봇 AI랩(B2B 딥테크) → 학생팀이 초기 신뢰·접근 확보 난이도↑, 첫 매출 한국 SME 아님.

### S4. 이종 AMR 통합 관제·오케스트레이션 SW (#14+#15)
- 멀티벤더 사내 물류로봇 통합 관제·작업배분.
- 하드웨어 0, 사내라 규제 낮음. 단 기존 WES/RMS 강자(다수)와 경쟁, 차별성 중간.

### S5. 제조 검사(AOI) 로봇 비전 few-shot 결함학습 SaaS (#7 단독)
- 소량 샘플로 결함 검출 자동학습. 머신비전 시장 큼.
- 단 머신비전 레드오션, 로봇 의존 약(고정 카메라로도 가능) → "로봇 도메인" 적합성 애매.

### S6. 경기도 SME "로봇 도입 진단→ROI 시뮬레이터 + Teaching 번들" (#23, S1의 GTM 무기화)
- S1을 정부지원금·진단 컨설팅과 묶은 GTM 패키지. 단독 다이아 아님 → S1의 시장진입 전략으로 통합 권고.
