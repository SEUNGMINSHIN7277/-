# 03_Robotics — Phase 3 사업화 격투 (Survivors Round 2)

> 격투 렌즈: 첫 매출 현실성 / 단위경제 / 해자 지속성 / 경쟁(incumbent) 생존 / 글로벌·해외 / 4인 18개월.

## ★ 결정적 경쟁 인텔리전스 (재포지셔닝의 근거)
- **"자연어로 cobot 가르치기"는 이미 incumbent가 흡수 중.** Universal Robots 플랫폼 통합, Standard Bots(RO1 노코드), Mbodi, 그리고 **두산로보틱스+NVIDIA(2026.2) "자연어 지시로 이틀 만에 자동화"**. [출처: emergenresearch, standardbots, g-enews 2026.02]
- ⇒ **순수 "teaching UI" 단독은 incumbent 하드웨어+SW 번들에 압살된다.** 해자 불충분.
- **반전 기회:** incumbent SW는 **자사 하드웨어에 락인**. 그러나 한국·글로벌 SME 현장은 **여러 브랜드 cobot/로봇이 섞여 있고(두산·UR·한화·자카·플렉시브 혼재)**, 제품 SKU가 자주 바뀌는 **고혼합소량**이다. incumbent가 안 푸는 곳: **벤더-중립 + 고혼합소량 자동 재배치 + 누적 변경(changeover) 데이터 해자.**

## 생존 평가

### S1 → 재정의 ✅✅ **최종 1순위 (재포지셔닝)**
**"벤더-중립 cobot 작업 오케스트레이션 + 고혼합소량 자동 재배치 레이어"**
- teaching UI 단독이 아니라, **여러 브랜드 cobot을 한 SW로 다루고, SKU/라인 변경 시 비전이 부품을 재인식→스킬을 자동 재매핑**하는 것이 핵심 가치.
- **첫 매출:** 경기도 고혼합소량 제조 SME(전자·부품·식품 포장 등). 2026 로봇활용 제조혁신 지원사업(최대 2.5억·50%) 연계 → 고객 도입비 부담↓, 우리 첫 레퍼런스 확보.
- **단위경제(가설):** 라인당 SaaS 월 80~150만원 + 초기 셋업. SW 한계비용 낮음 → 마진 70%+. (가설, 출처: 로봇SW SaaS 일반 마진 추정)
- **해자:** ① 벤더-중립 통합(incumbent 락인 회피) ② 현장 재배치·changeover 행동 데이터 누적(쓸수록 자동화율↑) ③ 안전검증 게이트(LLM 코드생성 신뢰성 보강) ④ founder-market fit(팀 AI/LLM·풀스택 직결).
- **글로벌:** SW SaaS → 자카/플렉시브 강세인 동남아·인도 고혼합 SME로 확장, 멀티벤더 수요 동일.
- **4인 18개월:** cobot 1~2대 임대/실증 파트너로 충분(양산 0). 핵심은 비전·LLM·안전검증 SW = 팀 강점. **실현가능.**

### S3 → ✅ 2순위 **"로봇 시연 데이터 운영 플랫폼"**
- VLA 데이터 병목 정조준, TAM 거대, SW only.
- **약점(사업성):** 초기 고객이 글로벌 로봇 AI랩 → **학생 예비창업팀의 신뢰·접근·첫 매출 경로 매우 험난.** 경기도 도민/현장 와닿음 낮음(Gate B 도민평가 불리). 한국 SME GTM 부적합.
- 판정: 기술 매력 높으나 **사업성·조직역량·도민 적합성에서 S1에 밀림.** 백업으로 유지.

### S4 → ⚠ 3순위 **"이종 AMR 통합 관제"**
- 사내 물류, 규제 낮음, 멀티벤더 가치 분명.
- **약점:** WES/RMS/RMF(다수 강자, 오픈소스 포함) 레드오션, 차별성 중간, 영업 사이클 길고 대형 고객 위주 → 학생팀 첫 매출 난이도↑.
- 판정: 백업.

### (탈락) S2 빈피킹 / S5 AOI
- 머신비전 레드오션, 차별성·성장성 두 축 동시 8.5 도달 어려움. 컷.
