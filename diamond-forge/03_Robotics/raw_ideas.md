# 03_Robotics — Phase 1 발산 (Raw Ideas)

> 규칙: 모두 "기성 로봇 위 AI/SW 쐐기" 또는 로봇 데이터/시뮬/제어 SW. 하드웨어 양산 0.
> 4인 AI/SW 학생팀 실현 관점 표기. 발산 단계이므로 거친 아이디어 포함.

## A. SME 제조 cobot teaching/재배치 SW
1. **자연어 cobot teaching ("말로 가르치는 cobot")** — 작업자가 자연어+시연으로 cobot 태스크 생성/재배치. LLM 의도인식+비전 그라운딩+안전검증. (SW only)
2. **고혼합소량 자동 재배치 엔진** — 제품 SKU 바뀌면 비전이 새 부품 인식→기존 스킬 재매핑. 재프로그래밍 0.
3. **cobot용 "스킬 라이브러리 마켓플레이스"** — 픽앤플레이스/디버링/검사 등 검증된 스킬 SaaS 배포.
4. **스마트폰 시연 → cobot 프로그램 변환** — 작업자가 폰으로 손작업 촬영→imitation으로 cobot 코드 생성.
5. **cobot 안전영역·충돌 자동 셋업 SW** — 비전으로 작업셀 스캔→안전존/속도 자동 구성(SI 작업 단축).

## B. 로봇 비전·인지 레이어
6. **무질서 빈피킹(bin-picking) 비전 AI SaaS** — 기성 팔+카메라 위, 섞인 부품 6DoF 자세추정 픽킹.
7. **제조 검사(AOI) 로봇 비전 — few-shot 결함학습** — 소량 불량 샘플로 결함 검출 모델 자동학습.
8. **로봇 와이어/유연물체 조작 비전** — 케이블·천 등 비강체 조작 인지(난제, 차별성↑).
9. **드론 인프라 점검 인지 SW** — 기성 드론 영상→균열/부식 자동 탐지·리포트(하드웨어 비의존).

## C. 로봇 데이터/시뮬레이션 운영 SW
10. **로봇 시연 데이터 운영 플랫폼("로봇판 Scale AI")** — 텔레오퍼 데이터 수집·정합·품질관리·라벨 SaaS.
11. **합성 데이터/시뮬→실제(sim-to-real) 생성 SW** — 도메인랜덤화로 학습데이터 대량 생성.
12. **스마트폰/웹캠 인간시연 → 로봇학습 데이터화** — egocentric 영상으로 저비용 데이터 수집(데이터 해자).
13. **로봇 정책 평가/회귀 테스트 SaaS** — 시뮬에서 VLA 정책 자동 벤치마크·안전 회귀 테스트.

## D. 사내 물류/AMR 오케스트레이션
14. **이종(heterogeneous) AMR 통합 관제 SW** — 여러 벤더 AMR을 한 화면에서 작업배분·교통관리.
15. **창고 픽킹 동선 최적화 AI** — 주문→로봇/사람 협업 픽킹 경로 실시간 최적화.
16. **로봇 가동률·고장예지(PdM) SaaS** — cobot/AMR 텔레메트리로 다운타임 예측.

## E. 서비스 로봇 SW
17. **식당/호텔 서빙로봇 멀티로봇 협업·메뉴 자동매핑 SW** (서비스 현장).
18. **요양/돌봄 로봇 대화·모니터링 AI 레이어** (규제·안전 민감).
19. **무인매장 로봇 재고/진열 인지 SW.**

## F. 개발자 도구·플랫폼
20. **VLA 파인튜닝/배포 MLOps(로봇용)** — 현장 데이터로 파운데이션 정책 미세조정·OTA 배포.
21. **로봇용 자연어 작업지시 → 안전검증 컴파일러** — LLM 코드생성 + 정형검증 안전 게이트.
22. **ROS2 위 "로봇 앱스토어"·저코드 통합 IDE.**

## G. 틈새·실증 레버리지
23. **경기도 SME 전용 "로봇 도입 진단→ROI 시뮬레이터" + teaching SW 번들** (정부지원금 연계 GTM).
24. **농업 로봇(기성) 작물 인지·수확 판단 비전 SW.**
25. **건설 로봇(기성) 현장 인지·진척 측정 SW.**
26. **재활용/분류 로봇 비전 — 폐기물 자동분류 인지** (자원순환 도메인 중복 회피).
27. **로봇 원격조작(teleop) 저지연 웹 SW + 데이터 동시수집.**
28. **로봇 작업 "디지털 트윈" 셀 셋업·검증 SW(설치 전 시뮬).**
29. **휴머노이드 손/그리퍼 조작 스킬 SDK(기성 휴머노이드 위).**
30. **cobot 음성 코파일럿 — 현장 작업자가 음성으로 로봇 상태질의·재시작·미세조정.**
