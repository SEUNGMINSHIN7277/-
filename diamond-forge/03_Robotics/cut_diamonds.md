# 03_Robotics — Phase 4 컷팅 (Cut Diamonds)

## 💎 D1 (주력) — "ReFlow" (가칭): 벤더-중립 cobot 고혼합소량 자동 재배치 레이어

### 한 줄 정의
**여러 브랜드의 협동로봇을 한 소프트웨어로 다루고, 생산 품목이 바뀔 때마다 비전이 새 부품을 스스로 인식해 로봇을 재프로그래밍 없이 재배치(re-task)해 주는 — 고혼합소량 SME 제조 현장의 'cobot 재배치 자동조종' SaaS.**

### 무엇이 10배인가
- 현재: 품목 바뀔 때마다 전문 엔지니어/SI가 재프로그래밍 → **백로그 6~12개월, 1회 수백만~수천만원**, SME는 사실상 멈춤.
- ReFlow: 작업자가 새 품목 샘플 몇 개 보여주면 **비전이 6DoF로 인식→기존 스킬에 자동 매핑→안전검증 후 수십 분 내 재가동.** 재프로그래밍 비용·시간 ~10배↓.

### 왜 지금 (Why now)
1. VLA/비전 기반 그라운딩이 2025~26 실용 임계 돌파(구조화 태스크 한정 신뢰성 확보). [domain_brief §1]
2. 한국 로봇밀도 1위지만 SME 활용률 12.1%·인력 40% 미훈련 → 미충족 폭발. [domain_brief §3]
3. 2026 정부·경기도 로봇활용 제조혁신 지원금(최대 2.5억·50%)으로 SME 도입 마찰 급감. [domain_brief §4]
4. incumbent는 자사 HW 락인 → **멀티벤더·고혼합 틈새 무주공산.**

### 차별성·해자 (incumbent 생존 논리)
- **H1 벤더-중립:** 두산·UR·한화·자카·플렉시브 혼재 현장을 단일 SW로. incumbent SW는 자사 HW 전용 → 구조적으로 못 따라옴.
- **H2 데이터 해자:** 현장 changeover(품목전환) 행동·실패·복구 데이터 누적 → 재배치 자동화율이 시간이 갈수록 상승(네트워크/데이터 플라이휠).
- **H3 안전검증 게이트:** LLM/비전 출력의 미성숙(고차 코드·엣지케이스)을 정형 안전검증·시뮬 프리체크로 보완 → 현장 신뢰. (과학 리스크의 방어막)
- **H4 founder-market fit:** AI/LLM·비전·풀스택 = 팀 정확한 강점. teaching UI는 commodity지만 "재배치 자동화+데이터+멀티벤더 통합"은 SW 난제 → 팀이 잘하는 영역.

### 첫 매출 경로
경기도 고혼합소량 SME(전자부품·식품포장·화장품·자동차부품 2차 협력사) → 정부지원사업 컨소시엄으로 파일럿 → 라인당 SaaS.

### 단위경제 (가설 명시)
- 가격: 라인/로봇셀당 월 80~150만원 구독 + 초기 셋업 300~800만원. (가설)
- 원가: SaaS 한계비용 낮음(클라우드+추론) → **공헌이익 70%+** (가설, 로봇SW SaaS 일반치 추정).
- BEP: 약 40~60 활성 라인(가설).

### 규제
- **사내(in-facility) cobot SW → 실외이동로봇 운행안전인증 대상 아님.** KC는 로봇 HW(고객 보유분) 소관, 우리 SW는 산업안전(협동로봇 안전 ISO/TS 15066 준수 설계)만. 규제 부담 낮음. [domain_brief §5]

### 리스크 & 방어
- R1 incumbent가 멀티벤더 개방 → 방어: 데이터 해자·중립성 신뢰·SME 밀착.
- R2 LLM/비전 신뢰성 → 방어: 구조화 태스크로 범위 한정 + 안전검증 게이트 + human-in-the-loop.
- R3 SI 채널 충돌 → 방어: SI를 적이 아닌 배포 파트너로(화이트라벨).

## 💎 D2 (백업) — "로봇 시연 데이터 운영 플랫폼"
- 정의: 텔레오퍼/인간시연/합성 데이터 수집·정합·품질·라벨 SaaS, VLA 데이터 병목 정조준.
- 강점: TAM 거대, SW only, 글로벌. 약점: 첫 고객=글로벌 AI랩 → 학생팀 신뢰·매출 경로 험난, 도민 적합성 낮음.
- 용도: D1이 Gate 미달 시 대체. 현재는 D1 우위.
