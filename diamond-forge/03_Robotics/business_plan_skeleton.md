# 03_Robotics — Phase 8 사업계획서 골격 (16항목)

## 💎 ReFlow — 벤더-중립 cobot 고혼합소량 자동 재배치 레이어
> 2026 경기 G스타 오디션 「도약리그」 제출용 골격. (가설 수치는 명시, 출처는 domain_brief.md 참조)

---

### 1. 한 줄 정의 (30초 피치)
여러 브랜드의 협동로봇을 하나의 SW로 다루고, 생산 품목이 바뀔 때마다 비전 AI가 새 부품을 인식해 **재프로그래밍 없이 자동 재배치**해 주는 고혼합소량 중소 제조 현장의 'cobot 재배치 자동조종' SaaS.

### 2. 문제 (정량)
- 한국 로봇밀도 세계 1위(1,220대/만명)인데 **중소기업 자동화 수용 12.1%**(대기업 24.5%). [IFR World Robotics 2025, xpert.digital]
- 도입해도 **품목 바뀌면 재프로그래밍 필요 → SI 백로그 6~12개월, 회당 수백만~수천만원.** [smartindustry, globalgrowthinsights]
- **제조 인력 40%가 로봇 운용 훈련 부족**, SME 초기투자 USD 500k+ 부담. [kenresearch]
- 결과: 고혼합소량 SME는 로봇을 사놓고도 못 쓰거나 라인이 멈춘다.

### 3. 솔루션 (왜 10배)
- 작업자가 새 품목 샘플 몇 개를 보여주면 → 비전 6DoF 인식 → 기존 스킬 자동 재매핑 → **안전검증 후 수십 분 내 재가동.**
- 재배치 시간/비용 **~90%↓(KPI 가설)**, 가동률 **+20%p(가설)**. 전문 SI 없이 비전문 작업자가 운용.
- 여러 브랜드(두산·UR·한화·자카·플렉시브) 혼재 라인을 단일 SW로.

### 4. 왜 지금 (Why now)
- VLA·비전 그라운딩이 구조화 태스크에서 실용 임계 돌파(2025~26). [arxiv 2505.04769]
- 2026 정부·경기도 로봇활용 제조혁신 지원금(최대 2.5억·50%)으로 SME 도입 마찰 급감. [bizinfo PBLN_116712]
- incumbent의 자연어 teaching은 자사 HW 락인 → 멀티벤더·고혼합 틈새 무주공산. [emergenresearch, g-enews 2026.02]

### 5. 차별성·해자
- ① **벤더-중립 통합**(incumbent 구조적 회피 불가) ② **changeover 데이터 플라이휠**(쓸수록 자동화율↑) ③ **안전검증 게이트**(신뢰+장벽) ④ **founder-market fit**(AI/LLM·비전·풀스택).

### 6. 시장 TAM/SAM/SOM (숫자·출처 / 가설 명시)
- **TAM:** 글로벌 로봇 SW 시장 2030 **USD 64.46B**(CAGR 21.6%). [giiresearch/Mordor]
- **SAM(가설):** 글로벌 cobot SW + 고혼합소량 제조 재배치 세그먼트 — 보수적으로 로봇SW의 8~12% ≈ **USD 5~7B** (가설).
- **SOM(가설, 5년):** 한국+초기 동남아 고혼합 SME 라인 침투 → 활성 라인 3,000~5,000개 × 라인당 연 1,200만원 ≈ **연 ARR 360~600억원** (가설).

### 7. 수익모델·단위경제 (가격/원가/마진/BEP — 가설)
- **구독:** 라인/셀당 월 80~150만원 + 초기 셋업 300~800만원(정부지원금으로 고객 실부담 최소화).
- **2차 매출:** 검증 스킬 라이브러리 구독, 현장 데이터 인사이트 리포트 → ARPU↑.
- **원가:** SaaS 한계비용 낮음(클라우드+추론) → **공헌이익 70%+** (가설).
- **BEP:** 약 40~60 활성 라인 (가설).

### 8. GTM (초기고객 10곳·파트너·해외)
- **초기 10곳:** 경기도(성남·화성·안산·시흥) 전자부품·식품포장·화장품·자동차 2차 협력사 고혼합소량 SME.
- **채널:** ①2026 로봇활용 제조혁신/경기도 로봇 실증 컨소시엄 ②SI 화이트라벨(적이 아닌 배포 파트너) ③cobot 벤더 리셀러.
- **해외:** SaaS이므로 멀티벤더·고혼합 동일한 동남아·인도·동유럽 SME로 확장.

### 9. MVP & 마일스톤 (6/12/18개월, 4인)
- **0~6개월:** 1개 브랜드 cobot + 비전 빈피킹/픽앤플레이스 재배치 PoC, 안전검증 게이트 v1, 경기도 실증 1곳. (cobot 임대)
- **6~12개월:** 2~3개 브랜드 통합(벤더-중립 추상화 레이어), 실증 3곳, 유료 파일럿 전환, 스킬 라이브러리 v1.
- **12~18개월:** 멀티벤더 정식 SaaS, 유료 라인 10~20개, changeover 데이터 플라이휠 가동, 해외 1개국 파일럿 LOI.

### 10. 조직역량 (역할·강점 매핑)
- **김범수(대표):** AI·데이터·기획 — VLA/비전 정책, 사업기획, 정부지원·실증 컨소시엄 총괄.
- **신승민:** SW 풀스택 — 벤더-중립 통합 레이어·SaaS 백엔드·로봇 드라이버 추상화.
- **송채우:** SW 풀스택 — 안전검증 게이트·프론트(작업자 UI)·데이터 파이프라인.
- (+) 4번째 팀원/멘토: 제조현장 세일즈·SI 파트너십(보완 영역).
- **하드웨어 양산 0** → 팀 강점에 100% 정렬.

### 11. 경기도 레버리지
경기도 제조 중소기업 밀집(스마트제조·로봇 실증 최적) + 2026 로봇활용 제조혁신 지원사업(2.5억·50%) + 가천대 창업지원단(성남)·경과원 G-PMS·차세대융합기술연구원. [bizinfo, pms.gbsa.or.kr]

### 12. IP 전략
- **특허(우선):** 멀티벤더 추상화 재배치 매핑 방법, 비전→스킬 자동 재매핑 파이프라인, 안전검증 게이트 청구항. **제출 전 핵심 청구항 비공개/출원 검토**(공고: 공개 아이디어 보호 불가, 공지예외 12개월 활용).
- **영업비밀:** changeover 데이터셋·자동화율 모델.

### 13. 리스크 Top5 & 대응
1. incumbent 멀티벤더 개방 → 데이터 해자·중립 신뢰·SME 밀착으로 선점.
2. LLM/비전 신뢰성(엣지케이스) → 구조화 태스크 범위 한정 + 안전검증 + human-in-the-loop.
3. SI 채널 충돌 → 화이트라벨로 SI를 파트너화.
4. SME 영업 사이클·예산 → 정부지원금 연계 "실부담 0원 파일럿".
5. 팀 제조현장 경험 부족 → 멘토·실증파트너·현장 상주 PoC.

### 15. 예상 심사질문 10개 + 모범답변
1. **두산+NVIDIA가 자연어 자동화 하는데 죽지 않나?** → 그들은 자사 HW 락인. 우리는 멀티브랜드 혼재 현장 + 재배치 자동화 + 데이터 해자. 보완재이자 무주공산.
2. **LLM이 잘못된 로봇 동작 만들면?** → 안전검증 게이트+시뮬 프리체크+human-in-the-loop, 구조화 태스크로 범위 한정.
3. **첫 매출 언제·어떻게?** → 6개월 내 경기도 실증, 12개월 유료 파일럿, 정부지원금으로 고객 실부담 최소.
4. **4인 학생팀이 로봇을 만든다고?** → 로봇은 안 만든다. 기성 cobot 위 SW 레이어. 하드웨어 양산 0.
5. **데이터 해자 진짜 생기나?** → changeover 실패·복구 데이터는 현장 독점적, 누적 시 자동화율↑(플라이휠).
6. **단가 근거?** → 가설이며 SI 재프로그래밍 회당 비용 대비 압도적 저렴. 파일럿으로 실측 예정.
7. **일자리 뺏나?** → 단순 재프로그래밍 노역 제거, 작업자를 로봇 운용·감독 상위직무로 상향(인력 40% 미훈련 문제 해소).
8. **해외 진출 현실성?** → SaaS라 국경 무관, 멀티벤더·고혼합 동남아/인도 SME 동일 수요.
9. **IP 보호?** → 핵심 청구항 출원·비공개, 공지예외 12개월, 데이터는 영업비밀.
10. **왜 너희가?** → 팀 AI/LLM·비전·풀스택 정확 일치 + 경기도 실증·지원망 접근.

### 16. 결선 피치 스토리라인
- **30초:** "한국은 로봇 1위인데, 중소 공장은 제품 하나 바뀔 때마다 로봇이 멈춥니다. 재프로그래밍에 수백만원·수개월이 들거든요. ReFlow는 작업자가 새 제품을 보여주기만 하면, 비전 AI가 어떤 브랜드 로봇이든 수십 분 만에 자동 재배치합니다. 로봇을 산 모든 중소기업의 '재배치 자동조종'입니다."
- **3분:** ①문제(로봇밀도1위 vs SME 12.1%, 재배치 지옥) ②솔루션 데모(샘플 보여주기→자동 재배치) ③왜 지금(VLA+정부지원금) ④해자(벤더중립·데이터·안전게이트) ⑤시장($64B/CAGR21.6%)·단위경제 ⑥경기도 실증→글로벌 ⑦팀 fit ⑧일자리 상향 메시지로 마무리.
