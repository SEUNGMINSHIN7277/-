## Gate C — 딥테크 진정성 관문 (NEW · 킬 스위치 · 최우선)

다음 **5개 전부 충족**해야 통과. 하나라도 미달이면 즉살.

1. **기술 돌파 기반:** 최근(12~24개월) 실재하는 과학·공학 돌파(논문/특허/신소자/신알고리즘)에 뿌리를 둔 **새로운 메커니즘**일 것. "기존 X + ChatGPT/LLM API 붙임"은 딥테크 아님.
2. **방어가능 IP (래퍼 킬 테스트):** *"유능한 팀이 공개 API·오픈소스로 주말 안에 복제 가능한가?"* → YES면 즉살. 핵심 가치가 UI/통합이 아니라 **알고리즘·모델·소자·데이터·물리** 그 자체에 있을 것. 특허/영업비밀로 청구항이 서는가.
3. **하드 메트릭 10배:** 측정 가능한 *기술* 지표(정확도·지연·에너지·비용·수율·해상도·처리량 등)에서 기존 대비 10배(또는 불가능→가능)이며, **제1원리(물리·수학·정보이론)로 달성 가능성**을 논증할 것. 과학 킬(Tier3) 0건.
4. **빌더블 쐐기:** 이 딥테크의 *첫 기술 데모*를, **AI/ML·SW 핵심 역량 팀(+필요시 명시된 경기도 연구기관·교수·현직 전문가 자문 1~2인 또는 파운드리/장비 파트너)**이 **24개월 내** 만들 수 있을 것. 단, 칩 자체 양산·웻랩 신약·중장비 제작처럼 4인+자문으로도 불가능한 자본집약 양산은 폐기(소프트웨어/알고리즘/데이터/펌웨어 레이어가 핵심 모트인 딥테크만 허용).
5. **딥테크 사업 본질:** 가치가 "예쁜 앱"이 아니라 **풀기 어려운 기술 난제를 풀었다는 사실**에서 나올 것. 기술 난제(technical risk)가 곧 해자.

> **딥테크 정의(이번 작전):** 이 팀이 *주도해 만들 수 있는* 알고리즘/모델/시스템/펌웨어/데이터 레이어의 **하드 기술 모트** + (필요시) 경기도 딥테크 인프라(반도체 클러스터·차세대융합기술연구원·판교·대학 연구실) 레버리지. 순수 SaaS 래퍼·콘텐츠앱·행동넛지·노코드툴은 전부 제외.
