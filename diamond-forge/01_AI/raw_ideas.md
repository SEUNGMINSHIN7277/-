# Phase 1 발산 — AI 원석 아이디어 (문샷 × 딥테크)

> 형식: [번호] 제목 — 1줄 가설 / 왜 지금(Why now)
> 굵게=Dasi 행동데이터·복귀엔진 강점 확장·전이 방향(가점)

## 그룹 1: 복귀·완료 엔진 전이 (founder-market-fit 핵심)
1. **ReFocus-EDU** — 국비훈련/에듀테크 수강생의 이탈 직전 신호를 잡아 0마찰 복귀를 유발하는 에이전트(SaaS, 기관 과금). / KDT 전액지원 축소(2026)로 기관이 수료율 압박↑, SLM으로 저비용 개인화 가능.
2. **CompletionGuard** — 기업 L&D 의무교육 완주를 보장하는 복귀 에이전트, 미완료시 환불/리포트. / 수료율 80%+ 기업 몰입 +34%, 마이크로러닝+개입 수요.
3. **OnboardBack** — SaaS 신규고객 첫 90일 온보딩 이탈을 복귀시키는 에이전트(B2B). / SMB 손실 43%가 첫 90일.
4. **복귀엔진 API(Re-engagement-as-a-Service)** — 어떤 앱이든 호출하면 이탈자 복귀 시퀀스를 생성하는 행동개입 API. / MCP·A2A 표준화로 통합비용↓.
5. **대학 중도탈락 조기경보+복귀 코디네이터** — 예측에 그치지 않고 학생을 실제 자원(상담·튜터)에 0마찰 연결. / 대학 연 $2.3B 절감, 한국 학령인구 급감으로 대학 리텐션 사활.
6. **재활/만성질환 치료순응(adherence) 복귀 에이전트** — 약·운동 중단자를 복귀시키는 코칭. / Stanford HAI AI 헬스코치, 헬스 버티컬 에이전트 $402M 펀딩.
7. **헬스장/구독 윈백 에이전트** — 이탈 직전 행동 패턴으로 0마찰 재방문 유발. / 구독경제 이탈 5%↓→이익 25~95%↑.

## 그룹 2: 에이전트 신뢰성·검증 (미해결 painful)
8. **AgentAudit** — 에이전트 결정마다 근거·출처를 추적하는 감사로그/검증 레이어. / 기업 1/5만 감사가능, KPMG 환각 리포트 회수 사건.
9. **HalluGuard for 법률/의료** — 인용·사실 자동 검증 게이트. / 환각 10~20%(의료), 단일 허위인용=제재.
10. **AI기본법 컴플라이언스 자동화** — 생성결과 AI표시·고지·고영향 분류를 자동 처리하는 SDK. / 2026.1.22 시행, 1년 계도 후 과태료.
11. **에이전트 회귀테스트 플랫폼** — 프롬프트·모델 변경시 행동 회귀를 잡는 CI. / 멀티에이전트 프로덕션化.

## 그룹 3: 온디바이스·SLM 딥테크
12. **PrivateCoach (온디바이스 SLM 코치)** — 개인 행동데이터가 폰을 안 떠나는 프라이버시 우선 복귀코치. / Phi-4-mini/Gemma 3 폰 구동, 개인정보법 강화.
13. **SLM 파인튜닝 자동화 for 버티컬 에이전트** — 도메인 데이터로 4B 모델 자동 증류. / Gartner: 소형모델 사용 3배.
14. **엣지 행동센싱 SDK** — 폰 사용패턴으로 이탈 신호를 온디바이스 추론. / 개인정보 가명처리 요구.

## 그룹 4: 노동·생산성·교육 인접
15. **AI 면접/취업 코치 for KDT 수료생** — 수료→취업 전환을 끌어올리는 에이전트. / KDT 평가지표=취업률.
16. **신입사원 적응(이탈방지) 에이전트** — 입사 6개월 조기퇴사 예측+개입. / 초기 churn=기업 비용.
17. **학습 동기 게임화 + 복귀 트리거** — 게임화 단독(리텐션 +19%)을 복귀엔진으로 증폭. / 게임업종 R3 위반 주의 → 게임 아님(학습보조).
18. **AI 스터디그룹 매칭+이탈복귀** — 사회적 연결로 완주율↑. / 사회적 고립=이탈 예측인자.

## 그룹 5: 데이터·인프라
19. **이탈→복귀 행동데이터 표준 스키마+벤치마크** — 업계 공용 데이터셋·리더보드(데이터 해자). / 표준 부재.
20. **리텐션 에이전트 마켓플레이스** — 버티컬별 복귀 플레이북 거래. / 플레이북 파편화.

## 그룹 6: 고위험 문샷 (대부분 컬링 예상)

22. 범용 AGI 비서 — 빅테크 정면충돌, 해자 없음(컬링).
23. 자율 멀티에이전트 기업운영 OS — 범위 과대, 18개월 불가(컬링).
24. AI 신약 타깃 발굴 — 바이오 도메인·웻랩 필요(도메인 외).
25. 실시간 영상 감정인식 출석관리 — 프라이버시·규제 리스크 큼, 거부감(컬링).
26. AI 교사 완전대체 — 신뢰·규제·거부감(컬링).
27. 메타버스 학습공간 — Why now 약함, 하드웨어 의존(컬링).
28. AI 자동 커리큘럼 생성기 — 차별성 약, 레드오션(컬링).
29. 음성 only 복귀 코치(노인 대상) — 좋은 변형이나 단독 다이아 약(후보 변형).
30. **B2G: 경기도/고용부 훈련기관 수료율 대시보드+개입** — 정책수요 직결, 경기도 레버리지 최강(강한 후보).
