## [D1] ReBoot — "이탈을 복귀로 바꾸는 AI 복귀엔진" (★ 본선 다이아)

**한 줄 정의(30초):** ReBoot는 온라인 학습·온보딩에서 *그만두기 직전*의 사람을 행동신호로 포착해, 알림폭격이 아니라 **딱 한 번의 0마찰 복귀 액션**을 선제 제안하는 AI 에이전트입니다. 첫 시장은 수료율이 곧 생존인 **국비훈련(KDT)·에듀테크 기관**입니다.

| 항목 | 내용 |
|---|---|
| **문제** | 온라인 과정 이탈 30~50%(오프라인의 최대 5배). 2026 KDT 전액지원 축소→기관은 수료율로 위탁·정산이 좌우. 기존 churn 툴은 "예측"만, 실제 복귀 *행동*은 공백. |
| **솔루션(왜 10배)** | (1) 예측이 아닌 *복귀 유발*: 이탈 직전 맥락에 맞는 단일 next-action(다음 5분 과업/자원연결/동기 리프레임). (2) 알림폭격 0—타이밍·라포 최적화(CHI 2026 동기인식 코칭 근거). (3) 검증가능 개입+감사로그(에이전트 신뢰성 위기 정면 해결). |
| **왜 지금** | SLM 온디바이스(Phi-4-mini/Gemma 3 폰 구동)로 개인화 개입 변동원가 급감 + MCP/A2A로 LMS 통합비용↓ + KDT 지원축소로 기관 수료율 압박 정점 + AI기본법 2026.1.22로 "설명가능 개입"이 진입장벽→해자. |
| **차별성·해자** | ① 이탈→복귀 *행동데이터 해자*(Dasi 자산 전이, Leroy&Glomb 2018) — 개입-복귀 라벨이 쌓일수록 정확도↑(데이터 플라이휠). ② 검증가능·컴플라이언스 내재(AI기본법). ③ founder-market-fit("내가 이탈자였다"). |
| **시장(가설+출처)** | TAM(글로벌 학습·리텐션 에이전트) $3~6B; SAM(한국 KDT·국비·에듀테크) 500~1,500억/년; SOM 3년 수도권 200기관×1,200만원≈24억/년. 모기시장 AI에이전트 $294B(2035, precedenceresearch). |
| **단위경제** | 기관 SaaS 월 50~150만원(수강생 구간) + 성과형. 변동원가 수강생당 월 수백원(SLM). 마진 80%+. BEP 기관 ~30곳. |
| **GTM** | 가천대 LINC·교내 원격강좌 PoC→성남·판교 KDT 학원→경기 평생교육 위탁기관→에듀테크 임베드→글로벌(직업훈련 이탈은 만국 공통). |
| **MVP(4인,18개월)** | 6M: LMS 1곳 연동·이탈예측+단일개입 PoC, 수료율 A/B. 12M: 유료기관 10곳·성과형·감사로그·AI기본법 고지. 18M: 30곳·기업 L&D 확장(CompletionGuard 모듈)·해외 PoC 1건. |
| **조직역량** | 대표(AI/데이터: 예측모델·개입정책), 신승민·송채우(풀스택: LMS연동·에이전트·온디바이스). 전원 AI/SW 자체구현→조직역량 만점권. |
| **경기도 레버리지** | 경기 KDT·평생교육 기관 밀집(첫고객), 경과원 글로벌 사업화(판교 AI 가점), AI GPU 지원(학습비↓), 가천대 LINC, 도민체감 높음(내 자녀·내 재교육 완주). |
| **IP 전략** | 핵심=영업비밀(개입정책·행동피처·복귀 라벨 데이터). 특허는 "행동신호→타이밍 최적 단일개입 선택 방법" 청구항 출원 검토(공지예외 12개월). 제출 전 청구항 비공개. |
| **리스크 Top** | 정책의존(→기업/글로벌 분산), 개인정보(→온디바이스·가명·동의), 빅테크 LMS 내장(→데이터해자+버티컬 깊이). |
| **1조 서사** | "디지털 학습/구독의 이탈 경제"는 교육·기업교육·SaaS 전반 수십조 손실. ReBoot가 복귀엔진 표준이 되면 모든 학습·구독 제품의 리텐션 레이어 → AI에이전트 시장의 '복귀 인프라'. |
