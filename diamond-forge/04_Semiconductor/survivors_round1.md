# Phase 2 — 과학·레드팀 컬링 (생존 7개 + 폐기사유)

> 즉살 기준: ① 칩 양산/팹 운영/EDA 코어 의존 ② 대형 IDM 독점 데이터 없으면 불가 ③ 4인 18개월 불가 ④ 대형 벤더 정면충돌.

## 폐기 (사유)
- **#3 AOI 오버킬 저감 / #15 가상계측:** 양산 라인 실데이터·장비 연동 깊음, IDM 협조 없으면 학습 불가 → 학생팀 데이터 접근 불가. 폐기.
- **#4 칩렛 X-ray/CT:** 장비·데이터 희소, 도메인 난이도 高. 차순위 보류.
- **#12 테스트 커버리지 분석:** 테스트 프로그램 IP 접근 필요, 시장 작음. 폐기.
- **#16 부품 잔존수명:** 장비 텔레메트리 표준화 안됨, 데이터 확보 난망. 폐기.
- **#18~21 설계/검증 SW:** 대형 EDA 벤더·ChipAgents/Bronco가 이미 점령, RTL/검증 데이터 접근·전문성 벽. 정면충돌 → 폐기(코어 회피 원칙).
- **#22 공급망 예측:** 반도체 특화 데이터 부족, 일반 SCM과 차별화 약함. 보류.
- **#26 인증문서 자동화:** 시장 협소·해자 약함. 폐기.
- **#27 노광 레시피 최적화:** 양산데이터 의존 = 즉살. 폐기.
- **#28 ESG 모니터링:** 차별성·성장성 약함, 환경 테마는 별 도메인. 보류.
- **#1과 #2, #5, #6은 "결함검출" 클러스터로 통합.** #7/#8(저가카메라)는 정밀도 한계로 보조 기능화.

## 생존 7개 (Phase 3 진출)
- **S1. 소부장/후공정 중소기업용 on-prem 소량학습 결함검출 비전 플랫폼**
  - 과학근거: FCCIL 15–20shot 85%+, Cosmos VLM 96%+, Tiny ViT. 데이터 반출 없이 학습 가능 → 기밀 장벽 극복. ★Why now 최강.
- **S2. fabless·소부장 테스트/수율 데이터 자동통합 + 인사이트 SaaS** (#9+#10+#11+#13)
  - 근거: 데이터 단편화 painful·문서화된 고통. 단 대형 벤더(exensio/yieldWerx) 존재 → 중소 언번들로 차별.
- **S3. 합성 결함데이터 생성 + 소량학습 툴킷(개발자 도구)** (#5)
  - 근거: 라벨부족 해결. 단 단독 제품성 약함 → S1 엔진으로 흡수 가능.
- **S4. 소부장 장비 경량 예지보전 구독 SW** (#14+#17)
  - 근거: 다운타임 비용 큼. 단 센서·데이터 확보·신뢰성 입증 장벽.
- **S5. 공정 지식 RAG + 엔지니어 온보딩 AI 튜터** (#24+#25)
  - 근거: 인력난(5.4만 부족)에 직격. 구현 쉬움(학생팀 강점). 단 사업성·단가·해자 약함 우려.
- **S6. 품질 ECN/8D 리포트 자동작성 SW** (#23)
  - 근거: 인력난 대응, 구현 용이. 단 시장·단가 작음.
- **S7. SEM/wafer map 결함 자동라벨링·검수 어시스턴트** (#6+#2)
  - 근거: S1의 핵심 모듈. 단독보다 S1 통합이 유리.

> 관찰: S3·S7은 S1의 구성요소. S5·S6은 인력난 진입점이나 단가·해자 약함. **결함검출(S1)과 테스트데이터(S2)가 두 강자.**
