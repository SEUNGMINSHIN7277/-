# Phase 8 — 사업계획서 골격 (양식1 매핑 16항목) : WaferGuard

## 1. 한 줄 정의 (30초 피치)
"WaferGuard는 반도체 후공정·소부장 중소기업이 **라벨 20장으로 신규 결함을 1일 만에 학습**하고, **데이터를 공장 밖으로 한 번도 내보내지 않고(on-prem/edge)** 결함을 잡고 '왜 불량인지(공정 원인)'까지 알려주는 AI 검사 어시스턴트입니다. 기밀 때문에 클라우드 검사 SaaS를 못 쓰던 중소기업을 위한 단 하나의 선택지입니다."

## 2. 문제 (정량)
- 반도체 전문인력 **2031년 약 5.4만명 부족**, 인재 대기업 쏠림 → 소부장 중소기업 품질·수율 엔지니어 공동화(한국반도체산업협회/경향).
- wafer/검사 데이터는 영업기밀 → **외부 클라우드 검사 SaaS 도입 불가.**
- 결함 라벨링 비용 매우 높고 데이터 희소 → 기존 딥러닝 적용 난망(ScienceDirect).
- 룰베이스 AOI 오버킬·수작업 재검 → 양품 폐기·재작업 비용. 다운타임/품질사고 단가 큼.

## 3. 솔루션 (왜 10배)
- 소량학습(FCCIL/VLM): 라벨 20–40장, 1일 내 신규 결함 적용(기존 수천 장 대비 10배 빠름).
- on-prem/edge 추론: 데이터 비반출 → 기밀 장벽 제거(기존 SaaS가 못 들어오는 영역).
- 검출→**근본원인(공정스텝) 인과 추천** → 엔지니어 부족 메움.
- 결과 누적 → 수율 트렌드·재발방지 DB(워크플로 락인).

## 4. 왜 지금 (Why Now)
- 2025 소량학습/Vision Foundation Model 돌파(Cosmos 96%+, FCCIL 85%+/15shot)로 **기밀·라벨난 환경에서 비로소 실용화.**
- 용인 클러스터·소부장 협력단지 조성, K-반도체 특별법(기반시설 50~100% 국비), 인력난 심화 → 수요·정책·기술 동시 점화.
- 공정관리 AI 시장 CAGR 18.6%, APAC 55% 점유.

## 5. 차별성·해자
- ① 기밀 비반출 on-prem 아키텍처(대형 클라우드 SaaS 구조적 진입불가) ② 반도체 도메인 결함 파운데이션 모델 + 고객별 소량학습 누적(연합학습, 기밀 보호) ③ 검출→인과 워크플로 락인. ④ founder-market fit: Dasi의 "복귀 마찰 0" 노하우 → 재검 루프 제거 UX.

## 6. 시장 TAM/SAM/SOM (숫자·출처)
- **TAM:** 글로벌 반도체 공정관리 AI USD 6.74B(2033, CAGR 18.6%, dataintelo) + 수율 애널리틱스 2.18B(2034, Precedence) + AI 결함검출 6.63B(2034). OSAT 본시장 $68.46B(2026).
- **SAM:** APAC(55%) 후공정/소부장 검사·수율 SW. [가설] 약 USD 1.5~2B.
- **SOM(3–5년):** 한국 후공정·소부장 중소·중견 중심 라인 구독. [가설] 국내 타깃 라인 수천 개 × 라인당 연 구독 → 5년 내 수십억~수백억원 매출 목표.

## 7. 수익모델·단위경제 (가격/원가/마진/BEP)
- **2단 과금:** ① 1일 무료 PoC → **유료 진단 리포트(수율 손실 정량화) 컨설팅** (소액 즉시매출) → ② **라인당 월 구독** + 초기 셋업비.
- [가설] 라인당 월 구독 80~150만원, 셋업 수백만원. 원가: 추론은 고객 edge(서버비 낮음), 주원가는 인건비·온보딩. SW 마진 70%+.
- BEP: [가설] 유료 라인 30~50개 확보 시 4인 운영 BEP. 정부 바우처로 고객 자부담↓ → 전환율↑.

## 8. GTM (초기고객 10곳·파트너·해외)
- **초기 10곳:** 경기(용인·이천·평택·화성·안성) + 충청 후공정/소부장 중소기업(외관검사·기판·패키징 라인 보유). 가천대 창업지원단·경과원 네트워크로 소개.
- **파트너:** 경과원(실증·바우처), 차세대융합기술연구원, 가천대 반도체 교수 자문, 검사장비 OEM(번들 채널).
- **해외:** 대만/동남아 OSAT 밀집(글로벌 박람회 연계, 공고 해외진출 방향성 부합) → on-prem 동일 강점 그대로 이전.

## 9. MVP & 마일스톤 (6/12/18개월, 4인)
- **0–6개월:** 공개셋(WM-811K 등) 사전학습 결함모델 + on-prem 추론 앱 + 소량학습 파이프라인. 경기 PoC 고객 2곳 무료 진단.
- **6–12개월:** 인과 추천 모듈 + 유료 진단 컨설팅 전환 3곳, 유료 구독 라인 5~10개. 경과원 실증과제 1건 선정 목표.
- **12–18개월:** 연합학습(기밀보호) v1, 라인당 구독 20~30개, 첫 해외 OSAT 파일럿 1곳. 시드 투자.

## 10. 조직역량 (역할·강점 매핑)
- **김범수(대표, AI·산업공학):** 결함모델/이상탐지·인과 분석, 데이터 전략, 사업기획(빅콘 수상 트랙).
- **신승민(풀스택):** on-prem 앱·edge 추론 배포·MLOps(UMC 개발팀장, 정보처리기사).
- **송채우(풀스택):** 데이터 파이프라인·대시보드·고객 온보딩 SW.
- **자문단(예비창업 허용):** 반도체 교수 1 + 현직 품질엔지니어 1(현장지식·세일즈). 코어 4인 유지 → 자격·청년가산점 충족.

## 11. 경기도 레버리지
용인·이천·평택 반도체 메가클러스터 + 용인 소부장 협력단지(14만평) = **첫 고객·실증·레퍼런스가 한 곳에 밀집.** 경과원 실증사업·데이터바우처·소부장 R&D 매칭으로 고객 도입비 부담 제거, 가천대(성남) 창업지원단·차세대융합기술연구원 연계.

## 12. IP 전략
- **핵심 청구항(소량학습+on-prem 인과 검사 파이프라인) 영업비밀 우선 + 선출원**, 공모 제출 전 비공개 유지(공고: 공개 아이디어 법적보호 불가, 공지예외 12개월 활용).
- 연합학습 기밀보호 방식·결함-공정 인과 매핑은 특허 검토. 공개데이터셋 라이선스 준수(IP 침해 0 → R3 클리어).

## 13. 리스크 Top5 & 대응
1. 반도체 세일즈 사이클 보수적 → 1일 무료 PoC + 진단 컨설팅 + 정부 바우처로 단축.
2. 양산 실데이터 접근 제한 → 공개셋 사전학습 + 고객 소량 PoC 부트스트랩 + 연합학습.
3. 대형 벤더 다운마켓 진입 → on-prem 중소 틈새·도메인 인과·가격으로 방어, 빠른 레퍼런스 선점.
4. 범용 비전벤더(Lincode/Averroes) 경쟁 → 반도체 결함 도메인+기밀비반출+수율인과로 차별.
5. 4인 인력 한계 → MVP 범위 결함검출 쐐기로 집중, 자문·액셀로 보완.

## 14. Rubric 자체채점표
기획 18/20 · 사업 24/25 · 성장 18/20 · 진출 18/20 · 조직 14/15 = **92/100 +청년가산 0.5 = 92.5.** 전 항목 ≥80%.

## 15. 예상 심사질문 10 + 모범답변(요지)
1. 범용 AI비전과 뭐가 다른가 → 반도체 결함 도메인+기밀 비반출+수율 인과(범용은 외관검출만).
2. 학생팀이 반도체 회사에 팔 수 있나 → 1일 무료 진단으로 손실금액 먼저 증명 + 교수·현직 자문 + 경과원 실증.
3. 양산데이터 없는데 모델 학습? → 공개셋 사전학습 + 고객 소량(20장) 파인튜닝 + 연합학습.
4. 대형 벤더가 따라오면? → on-prem 중소 long-tail은 그들이 못 들어오는 구조적 틈, 우리가 레퍼런스 선점.
5. 첫 매출 언제·어떻게 → 6개월 PoC→진단 컨설팅(즉시 소액매출)→12개월 구독 전환.
6. 단가·마진 근거 → 라인당 월 구독, 추론 edge로 원가 낮음, SW 마진 70%+.
7. 데이터 기밀 어떻게 보장 → 추론·학습 모두 on-prem/edge, 외부 반출 0, 연합학습은 가중치만 공유.
8. 해외 진출 경로 → 대만·동남아 OSAT, on-prem 강점 동일 이전, 박람회 연계.
9. 경기도와 무슨 상관 → 용인·이천·평택 클러스터+소부장 단지=첫고객 밀집, 일자리·수율로 지역 기여.
10. IP 보호 → 핵심 청구항 영업비밀+선출원, 제출 전 비공개.
