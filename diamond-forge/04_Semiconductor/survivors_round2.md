# Phase 3 — 사업화 격투 (생존 2개 + 탈락사유)

> 격투 기준: 단위경제, 첫매출 경로, 진입장벽 돌파, 대형벤더/범용벤더 대비 차별성, 4인 18개월 실현.

## 시장 현실 체크 (Phase3 추가 리서치)
- **범용 AI 비전(Lincode LIVIS, Averroes 20–40장 no-code, Inspekto 박스):** 이미 "소량 이미지·노코드"를 제공. → **순수 외관검출만으론 차별성 없음.** 반도체 특화 + 데이터 비반출 + 수율 인과분석이 있어야 함.
- **OSAT 시장:** 2025 $64.95B → 2026 $68.46B. 한국 후공정 소부장 다수(한미반도체·이오테크닉스·해성디에스 등) = 경기/충청 밀집, 중소 다수.
- **테스트데이터 대형벤더:** PDF.com exensio, yieldWerx, yieldHUB → 대형·고가·SI 무거움, 중소 미충족.

## 격투 결과

### ❌ 탈락
- **S4 예지보전:** 센서 데이터 확보·현장 PoC·안전신뢰성 입증이 무겁고, 4인 18개월에 레퍼런스 만들기 난망. 첫매출 경로 불확실. 탈락.
- **S5 공정지식 RAG / S6 ECN 자동화:** 구현은 쉬우나 **단가 낮고(월 수십만원), 해자 약하고(범용 RAG·문서SW와 경쟁), 성장성 8.5 미달.** 글로벌 TAM·비선형 성장 서사 약함. 탈락.
- **S3·S7:** 단독 제품 아님 → 생존자(S1)의 핵심 모듈로 흡수.

### ✅ 결선 진출 2개

#### D-A. "WaferGuard(가칭)" — 소부장·후공정 중소기업용 **on-prem 소량학습 결함검출 + 수율 인과 어시스턴트**
- 한 줄: 라벨 20장으로 신규 결함을 배우고, **데이터가 공장 밖으로 안 나가는** 반도체 특화 결함검출 + "왜 불량인가(공정스텝)" 인과 추천.
- 차별: 범용 비전과 달리 ① 반도체 결함 도메인(wafer map/SEM/패키지) 특화 ② **on-prem/edge = 기밀 비반출 = 대형 SaaS 못 들어오는 틈** ③ 소량학습(FCCIL/VLM)으로 라벨난 극복 ④ 수율 인과(검출→근본원인).
- 단위경제: 라인당 월 구독 + 초기 셋업. 범용 대비 도메인 정확도·인과로 프리미엄.
- 첫매출: 경기 후공정/소부장 중소기업 PoC → 클러스터 레퍼런스.
- 흡수 모듈: S3(합성데이터), S7(자동라벨링).

#### D-B. "YieldHub-Lite(가칭)" — fabless·소부장용 **테스트/수율 데이터 자동통합 + 이상탐지 코파일럿**
- 한 줄: 여러 OSAT/파운드리의 제각각 STDF/비STDF를 자동 정규화·병합하고, 이상 bin·수율 드롭을 자연어로 알려주는 경량 SaaS.
- 차별: 대형 exensio/yieldWerx의 언번들·저가·중소 타깃 + LLM 자연어 분석.
- 리스크: 대형 벤더가 다운마켓 내려오면 압박. 데이터 포맷 다양성 대응 공수.

> 다음(Phase4): D-A vs D-B 컷팅. D-A가 ①Why now(소량학습 돌파) ②기밀 비반출 해자 ③경기 후공정 클러스터 직결에서 우위. D-B는 대형벤더 그림자·차별성 약점.
