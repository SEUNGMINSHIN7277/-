## 연마된 다이아몬드 정의 (Gate 진입 버전)

**"WaferGuard" — 반도체 후공정·소부장 중소기업을 위한, 라벨 20장으로 학습하고 데이터가 공장 밖으로 절대 나가지 않는(on-prem/edge) 결함검출 + 근본원인 어시스턴트.**

### 왜 10배인가
- 기존: 외관검사 엔지니어 수작업/룰베이스 AOI 오버킬 + 결함 라벨 수천장 필요 + SaaS는 기밀 때문에 도입 불가.
- WaferGuard: ①라벨 20–40장(소량학습)으로 1일 내 신규 결함 적용 ②**데이터 비반출 on-prem** → 기밀 장벽 해소(기존 SaaS 진입불가 영역) ③검출에 그치지 않고 "어느 공정스텝이 원인" 인과 추천 → 엔지니어 부족(5.4만명) 메움.

### 3겹 해자
1. **기밀 비반출 아키텍처(on-prem/edge 추론):** 대형 클라우드 SaaS가 구조적으로 못 들어오는 틈. 중소 소부장이 데이터 줄 수 없는 현실 = 우리만의 진입로.
2. **도메인 결함 파운데이션 모델 + 고객별 소량학습 누적:** 고객이 쌓을수록 모델·라벨 자산 축적(데이터 네트워크 효과, 단 연합학습으로 기밀 보호).
3. **검출→인과 워크플로 락인:** 검사 결과가 수율 트렌드/근본원인 DB로 쌓여 교체비용 상승.

### founder-market fit
- 팀의 "다시(Dasi)" = 이탈→복귀 행동데이터 해자 노하우 → **"오검출/재검 루프를 0으로 만드는 복귀 마찰 최소화 UX"**로 전이 가능(검사 워크플로의 재작업 마찰 제거).
- AI/데이터(김범수) + 풀스택(신승민·송채우) = 비전모델+on-prem 앱 구현 적합.

### 정직성 체크
- 칩 양산/팹운영/EDA 코어 의존 0 → R3·팀적합성 통과.
- 양산 실데이터 없이도 공개 wafer map 데이터셋(WM-811K 등) + 고객 PoC 소량데이터로 부트스트랩 가능. [가설: PoC 고객 2곳 6개월 내 확보]
