# Phase 1 — 발산 (Raw Ideas) : 28개, SW/데이터 쐐기 중심

> 제약: 4인 AI/SW 학생팀, 칩 양산·EDA코어·팹운영 의존 금지. 경기도 클러스터·소부장 첫고객 레버리지.

## 그룹 1 — 수율/결함 (소량학습 비전·이상탐지)
1. **소부장 중소기업용 on-prem 소량학습 결함검출 비전 SaaS** — 라벨 20장으로 신규 결함 학습(FCCIL/ViT), 데이터 반출 없이 edge 추론.
2. wafer map 패턴 분류 + 근본원인(공정스텝) 추천 어시스턴트.
3. 후공정(패키징) AOI 오버킬 저감 — 가짜불량(과검) 재분류 AI로 양품 살리기.
4. 칩렛/어드밴스드 패키징 X-ray·CT 결함 자동판독 SW.
5. 합성 결함 데이터 생성기(GenAI) — 희귀결함 학습용 데이터 부족 해소 툴킷.
6. SEM 이미지 결함 자동 라벨링·검수 어시스턴트(VLM).
7. PCB/기판 외관검사 경량 비전 (소부장 기판업체 타깃).
8. 광학검사 장비 보유 못한 소형업체용 스마트폰/저가카메라 기반 표면결함 스크리너.

## 그룹 2 — 테스트/수율 데이터 플랫폼 (데이터 단편화 해소)
9. **fabless·소부장용 STDF/비STDF 자동 통합·정규화 + 수율 인사이트 SaaS** — 파운드리/OSAT 제각각 파일 자동 파싱·병합·이상 bin 알람.
10. 멀티-OSAT 테스트 데이터 실시간 대시보드(경량, 중소형 타깃).
11. 수율 회귀분석 자동화 — 어떤 공정파라미터가 수율 떨어뜨렸나 자동 탐지.
12. 테스트 프로그램 커버리지/중복 분석 → 테스트시간(=원가) 절감 추천.
13. 자연어로 묻는 수율 데이터 분석(Text-to-SQL on yield DB) 코파일럿.

## 그룹 3 — 예지보전/장비 데이터
14. 소부장 장비업체용 경량 예지보전(이상진동·온도 이상탐지) 구독 SW.
15. 챔버 컨디션/드리프트 모니터링 — 가상계측(virtual metrology) 경량판.
16. 펌프·밸브·진공 부품 잔존수명 예측 어드바이저.
17. 장비 알람 로그 → 근본원인·조치 추천 LLM 어시스턴트.

## 그룹 4 — 설계/검증 SW 레이어 (코어 회피, 주변 자동화)
18. RTL 코드리뷰/린트 자동화 어시스턴트(오픈 LLM, 중소 팹리스용 저가).
19. 검증 회귀 실패 로그 자동 분류·트리아지 봇.
20. 데이터시트→레지스터맵/드라이버 코드 자동생성 툴.
21. 칩 사양서(스펙) 일관성 검사·요구사항 추적 SW.

## 그룹 5 — 공급망/품질/문서/인력
22. 반도체 부품 공급망 리스크·리드타임 예측 데이터 플랫폼.
23. 소부장 품질 ECN/8D 리포트 자동작성·추적 SW(인력난 대응).
24. 공정 SOP·트러블슈팅 지식 RAG 어시스턴트(은퇴 엔지니어 노하우 보존).
25. 신입/소부장 엔지니어 온보딩 AI 튜터(공정·장비 도메인).
26. 고객감사(audit)/인증(IATF·ISO) 문서 자동준비 SW.

## 그룹 6 — 확장/엣지
27. EUV/노광 레시피 최적화 추천(데이터 기반) — [양산데이터 의존, 위험].
28. 반도체 ESG/탄소·용수 데이터 모니터링 SaaS(클러스터 규제 대응).
