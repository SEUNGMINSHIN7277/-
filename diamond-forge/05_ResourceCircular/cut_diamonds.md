# Phase 4 — 컷팅 (Cut Diamonds)

## 다이아몬드 후보 D1 (메인): "탄소여권(가칭 CarbonPass / 順)"
### CBAM 쐐기로 진입하는 한국 수출 제조 SME·공급망 탄소데이터 OS

**한 줄 정의(30초):** 한국 수출 제조 중소기업이 EU 탄소국경세(CBAM)에 내야 할 탄소배출량을, 인보이스·전력고지서·생산데이터만 올리면 AI가 자동 산정하고 EU 제출양식과 검증추적까지 만들어주는 SaaS. "탄소 산정을 못 해 관세폭탄 맞는" 중소기업을 구한다.

**왜 10배인가:**
- 현행: 외부 컨설팅 1건 수백만~수천만원·6개월, 매년 반복, 협력사 데이터는 수기 취합 불가 → 대부분 EU default값(+10/20/30% 마크업)으로 과다 관세.
- 제품: 데이터 업로드→AI OCR·자동 배출계수 매핑→산정→EU양식→검증추적까지 **수주→수시간**, 매년 반복 자동화, **실측으로 default 대비 관세 절감액을 ROI로 즉시 제시**. 비용 1/10, 시간 1/30.

**해자(쌓이는 자산):**
1. **한국 활동데이터 ↔ EU/IPCC 배출계수 매핑 데이터셋**(국내 ERP/전력/연료/구매 자유텍스트 → 표준계수) — 사용할수록 정확·자동화↑.
2. **공급망 협력사 데이터 네트워크**: 원청이 끌어들인 1차협력사가 누적 → 망효과(원청이 바꾸기 어려움).
3. 검증추적(audit trail)·재사용 가능 산정 템플릿 = 전환비용.
4. EU SaaS는 한국 활동데이터·한국어 인보이스·국내 배출계수 약함; 국내 컨설팅사는 SW·자동화 약함 → 틈새.

**왜 지금:** 2026.1.1 CBAM 정식 시행, default +10%(2026)→+30%(2028), 미신고 톤당 €100. 중기 80% 미인지·38% 산정역량부족(중기중앙회). 환경부가 컨설팅 예산·해설서로 수요 가시화 → **정부가 시장과 GTM 채널을 만들어줌.**

**확장(Land & Expand):** CBAM 산정(쐐기) → 제품탄소발자국 PCF/LCA → 디지털제품여권 DPP(2027 EU 의무) → Scope3·K-ESG 보고 → 재생원료 함량 증명. 하나의 "탄소데이터 OS".

**글로벌:** CBAM은 대EU 수출국 공통 고통(인도·터키·중국·베트남·튀르키예). 한국에서 검증된 산정엔진을 동일 구조 타국 수출 SME로 복제. 공고의 "해외진출" 요건 충족.
