# Phase 7 — 도메인 확정 다이아몬드 (05_ResourceCircular)

## ★ 확정: "CarbonPass(가칭 順·탄소여권)"
### CBAM 쐐기로 진입하는 한국·글로벌 수출 제조 SME 공급망 탄소데이터 OS

**한 줄 정의:** 수출 제조 중소기업이 인보이스·전력고지서·생산데이터만 올리면, AI가 EU 탄소국경세(CBAM) 배출량을 자동 산정하고 제출양식·검증추적까지 만들어 관세폭탄을 막아주는 SaaS.

### 확정 근거 (AND 전부 충족)
- **Gate A:** YES 6/7 (통과선 5) — Sequoia/a16z/Founders Fund/Khosla/DCVC/한국딥테크 YES, Lux 조건부 NO.
- **Gate B:** 91.5/100 (자기개선 루프 #1 후). 전 항목 ≥80%, R3 위반 0.
- **과학 킬 0:** 순수 SW/AI, 플랜트·중장비·화학공정 불요.
- **레드팀 치명결함 반박:** cold-start 없음(고객이 데이터 제공), 데이터 폐쇄 문제 없음, IP moat 우려는 배출계수 매핑 특허+영업비밀로 보강.
- **4인 18개월 MVP 가능:** 데이터파이프라인+OCR+산정엔진+EU양식 산출 = 학생팀 SW 역량 정합.

### 팀 적합성 (정직)
- 대표 김범수: AI/데이터 산정엔진·배출계수 매핑 모델·기획·영업.
- 신승민/송채우: 풀스택 SaaS·OCR 파이프라인·대시보드·공급망 데이터 수집 봇.
- 보강필요: CBAM 검증 도메인 자문 1인(인증기관/LCA 전문) — 자문/지분으로 충원.

### 경기도 레버리지 (1줄)
경기도는 대EU 수출 제조 중소기업이 최다 밀집한 광역 = CBAM 피해 모수 최대, 경과원·가천대 창업지원단·환경부 CBAM 컨설팅 채널로 초기 60~100사 확보 경로.

### 차순위 보관
- D2 PCF/LCA 자동화: 확장축으로 흡수. D1 실패 시 단독화 가능(불필요 — D1 통과).
