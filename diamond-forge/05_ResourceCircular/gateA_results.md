# Phase 5 — Gate A: 글로벌 딥테크 VC 7인 심사 (D1: CarbonPass)

심사 대상: **CBAM 쐐기 → 한국/글로벌 수출 SME 공급망 탄소데이터 OS.**
통과선: 5/7 YES + "1조 회사 가능" 서사.

| VC | 판정 | 한 줄 이유 |
|---|---|---|
| **Sequoia** | ✅ YES | 규제로 강제된 현금성 수요(관세 회피)는 최고의 "왜 지금". 쐐기→OS 확장 서사 명확. Bill.com식 SME 백오피스 카테고리. |
| **a16z** | ✅ YES | 한국 활동데이터-EU계수 매핑 + 공급망 협력사 망효과 = 데이터 해자. AI OCR/산정 자동화는 적기 기술. |
| **Founders Fund** | ✅ YES | "탄소 무역장벽"이라는 비가역적 거시 변화에 베팅. CBAM 품목 확대(석화·플라스틱 2030)로 TAM 비선형 확장. |
| **Khosla** | ✅ YES | 컨설팅 6개월·수천만원을 SW로 1/30. 클린테크×AI 교차점, 다국가 복제 가능. |
| **Lux Capital** | ⚠️ NO (조건부) | 딥테크 관점 기술moat가 "데이터+워크플로우"라 모방 위험; 검증·측정 IP가 더 깊었으면. 단 실행속도 인정. |
| **DCVC** | ✅ YES | 산업 디지털화·측정/검증(MRV) 인프라 테제와 정합. 공급망 데이터망이 진짜 자산. |
| **한국 딥테크 VC형** | ✅ YES | 경기도 제조 SME 모수 최대 + 환경부 채널 + 정부 예산. 한국에서 PMF 후 동남아/인도 복제 현실적. founder-market fit 강함. |

## 결과: **YES 6 / 7 → Gate A 통과** (통과선 5 초과)
- 공통 강점: 규제강제 현금수요, cold-start 없음(고객이 데이터 제공), 망효과, 글로벌 동형시장.
- Lux의 우려(IP moat 얕음) → Gate B/사업계획서 IP 전략에서 "산정·검증 핵심 알고리즘 특허 + 매핑 데이터셋 영업비밀"로 보강.
- "1조 서사": CBAM(쐐기)→PCF→DPP→Scope3→재생원료 증명까지 전 수출 제조 SME의 탄소데이터 OS, 대EU 수출국 다국가 복제 = 수십조 TAM의 측정·증명 레이어 표준.
