# Phase 2 — 과학·레드팀 컬링 (Survivors Round 1)

> 즉살 기준: (K1) 플랜트/중장비/화학공정·HW 양산 자체구축 의존, (K2) 4인 18개월 SW 실현 불가, (K3) 데이터 접근 불가능(폐쇄 데이터 의존), (K4) 양면시장 cold-start 치명, (K5) 차별성/해자 없음(레드오션 미투).

## 폐기 (사유)
- #9 폐배터리 SOH AI — **K3**: BMS 로그는 OEM 폐쇄 데이터, 학생팀 데이터 확보 불가. (보류 가능하나 진입장벽).
- #11 E-waste 역물류 — **K4**: 가정 회수 양면시장 cold-start, 물류 실행은 비-SW.
- #13 사용후배터리 ESS 매칭 — **K4 + K3**: 공급(배터리)·수요 양쪽 cold-start, 안전인증 HW 영역.
- #14/#15/#16/#17 부산물·골재·유기성 매칭 — **K4**: 양면 마켓플레이스 cold-start + 물류/품질이 비-SW 핵심. (#14는 데이터 인텔리전스로 축소하면 생존 가능하나 차별성 약).
- #18 선별 비전 SW — **K1 근접/K5**: HW 종속(파트너 선별기 필요), AMP 등 글로벌 강자 포화, B2B 침투 느림.
- #24 다회용기 순환 — **K5**: 트래쉬버스터즈 등 기존 플레이어, HW(용기·세척) 결합 필요.
- #25 폐열 매칭 — **K1**: 배관·열교환 HW 인프라 의존.
- #12 블랙매스 가격 인텔리전스 — **K5**: 니치, 데이터 소스 확보난, 단독 사업성 약(부가기능).

## ★ 생존 6개 (SW/AI/데이터 순수 + 규제강제수요 + 데이터접근가능)

### S1. CBAM/공급망 탄소 산정·증명 SaaS (#1+#2+#3 통합)
- 한국 수출 제조 SME + 원청-협력사 공급망 탄소데이터. **규제강제수요(2026 CBAM), 순수 SW, 데이터=고객이 제공(인보이스/전력/연료), 친환경 가점.** founder-market fit(AI/데이터). **최강 후보.**

### S2. 제품 탄소발자국(PCF) 자동 LCA SaaS (#4)
- BOM→배출계수 매칭→PCF. CBAM/DPP/조달 요구 대응. S1과 인접(통합 가능).

### S3. 중소기업 간이 탄소회계 + ESG 자동보고 (#5+#28)
- Scope1/2/3 + K-ESG/CSRD 보고서. 시장 큼이나 EU/US SaaS 경쟁 치열, 한국 SME 특화로 차별.

### S4. 재생원료 함량 증명 / 그린워싱 방지 SaaS (#29+#23)
- 브랜드 "재활용 30%" 주장 데이터 검증·인증. EU 그린클레임 규제 Why-now. 데이터 소스 확보가 관건(K3 경계).

### S5. EV 배터리 디지털 패스포트·이력 추적 (#10+#8)
- EU 배터리규정 DPP 2027 의무. 데이터 체인 SW. 단 데이터 입력처(OEM/재활용사) 협조 필요(K4 경계), 시점이 다소 이름.

### S6. 폐기물 배출자 신고(올바로) 자동화 + EPR 실적관리 (#21+#22)
- 규제 강제 수요(국내), 전표 OCR→신고 자동. 순수 SW. 단 TAM 국내한정·글로벌 약(공고 "해외진출" 요건 불리).

## 컬링 메모
- 글로벌 TAM + 해외진출 요건(공고 명시) → S1·S2·S3·S4가 유리, S6은 국내한정으로 불리.
- 데이터 접근성: S1·S2·S3는 **고객이 직접 자기 데이터를 올림 = cold-start/폐쇄데이터 문제 없음(가장 안전).**
- 다음 라운드(Phase 3 사업화)로 S1·S2·S3 + 와일드카드 S4 진출.
