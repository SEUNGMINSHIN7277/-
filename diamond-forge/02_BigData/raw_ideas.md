# Phase 1 발산 — Raw Ideas (빅데이터)

> 기준: 데이터 수집·축적 해자(LLM 미보유 현장 1차 데이터) 우선. 4인/18개월 실현. 글로벌 TAM. 곡괭이 전략.
> 표기: [해자유형] / 한 줄. (C=수집해자, W=워크플로우, R=규제lock-in)

## 클러스터 1 — 공급망 탄소/ESG 데이터 (규제강제 수요)
1. **[C+R] CBAM 협력사 제품단위 탄소데이터 수집·산정·검증·전달 SaaS** — 중소 수출 협력사가 라인/품목별 1차 배출데이터를 입력·자동산정, EU 수입자에게 검증가능 포맷 전달.
2. [R] CBAM 인증서 비용 시뮬레이터 + default값 회피 컨설팅 자동화.
3. [C] 공급망 탄소데이터 "원장(ledger)" — 1차~N차 협력사 배출데이터 연결망 축적.
4. [C+R] 디지털제품여권(DPP) 대비 제품 생애주기 데이터 수집 플랫폼.
5. [R] CSDDD(공급망 실사) 중소 협력사 ESG 실사 응답 데이터 자동수집.
6. [C] 중소제조 에너지·유틸리티 미터 데이터 수집 → 탄소·원가 동시 산정.
7. 탄소배출 측정 IoT 센서 + 데이터 (하드웨어 양산 → 학생팀 부적합, 보류).

## 클러스터 2 — 제조 현장 1차 데이터 (PdM/품질)

9. [C] 공장 불량/품질 이미지·공정파라미터 라벨 자동축적 데이터셋.
10. [C] 노후 설비(통신X) 진동·전류 레트로핏 데이터 수집 키트+SaaS.
11. [C] 작업자 숙련 노하우(암묵지) 작업로그 데이터화.

13. [C] 금형/사출 공정 데이터 표준 수집(특정 버티컬).
