# Phase 4 — 컷팅 1-pager

## 다이아몬드 후보: CarbonRoot (탄소뿌리)

**한 줄 정의 (30초 피치)**
EU 수출 한국 중소 제조·협력사가 제품 1개의 탄소발자국을 직접 못 내면 EU가 '최고 배출량'으로 간주해 돈을 더 뜯어간다. CarbonRoot는 현장 작업자가 라인·품목·공정 데이터를 30분 만에 입력하면 EU 산정식대로 제품단위 배출량을 자동계산하고, 검증가능한 CBAM/탄소발자국 리포트로 바이어에 바로 전달한다. 협력사 데이터가 쌓일수록 한국에 없던 '제품·공정별 배출 벤치마크'가 우리에게만 축적된다.

**문제 (정량)**
- EU CBAM 본 시행 2026.1.1 — 데이터 없으면 default(최고배출) 적용→비용폭증. (EU/asuene/carbonchain)
- 한국 중소기업 10곳 중 8곳 CBAM 미파악(중기중앙회 300사). 對EU CBAM 대상 수출 $5.1B(철강 89%). (KITA/한경)
- "대기업은 준비, 협력사는 멈췄다 — 공급망 탄소데이터 격차." (이코노믹데일리)

**솔루션 (왜 10배)**
1차데이터 수집 UX(30분 입력) + EU 산정식 엔진 + 제3자 검증 연계 + 바이어 전달 포맷을 한 흐름으로. 기존 컨설팅(건당 수백만, 수주 소요)·글로벌 SW(EU 수입자向) 대비 협력사가 직접·반복·저비용으로 데이터 생산.

**왜 지금**: CBAM 첫날부터 지불의사 발생(규제강제 수요) + DPP/CSRD로 영구 확장.

**차별성·해자**: ① 협력사 1차 배출데이터 = LLM·외부 복제불가, 축적될수록 한국형 emission factor·벤치마크 독점 ② 규제 컴플라이언스 lock-in ③ 검증기관·바이어 워크플로우 임베딩.

**시장**: 글로벌 탄소회계 SW $20B+급 두자릿수 성장 / SAM 한국 CBAM·PCF 대응 수천~1만+ 사업장 / SOM 200~400사 × 240만원 = 5~10억 ARR.

**단위경제**: ARPU 240만/년, 마진 75~85%(가설), BEP 약 125 유료사(가설).

**MVP(18개월/4인)**: 철강·금속가공 1버티컬 산정엔진+입력UX → 검증연계 → 바이어 전달 → 멀티규제 확장.

**경기도 레버리지**: 경기 금속·철강 협력사 밀집 + 경과원 ESG지원 + 차세대융합기술연구원 실증.

**IP**: 산정·검증 알고리즘·데이터 스키마 영업비밀 + 핵심 청구항 사전 출원(공지예외 12개월).

**R3 점검**: IP침해 無 / 게임·사행성·환경오염·반사회 無 (오히려 친환경). 클리어.

→ Gate A·B 심사로 진행.

## [자기개선 루프 R1] 보강판 (Gate B 89.5 미달 → 재컷팅)

**보강1 — 단위경제 접지 강화 (사업성↑)**
- 신규접지: 중소기업 CBAM 애로 1위 = **탄소배출 산정·검증 역량부족 38%, 컨설팅비 부담 22%, 전문인력 부족 18.7%** (KOSME/MSS 2025 조사). → 우리 제품이 정확히 이 3대 애로를 직격.
- **정부 보조채널 결합**: 중진공(KOSME) "중소기업 CBAM 대응 인프라(MRV) 구축" 사업이 제품별 배출 산정·국제검증을 **보조**(esg.kosmes.or.kr / bizinfo). → 고객 체감가↓·도입장벽↓·우리 GTM에 보조금 매칭. 단위경제: 정부보조로 첫고객 CAC 대폭 절감(가설), ARPU 240만 중 일부 보조 충당 가능 → BEP 도달 가속.
- 컨설팅 대체 ROI 명확화: 기존 산정·검증은 건당 컨설팅 의존(역량부족 38%가 증거) → 우리 SaaS는 반복·자가생산으로 건당비용 1/N. default값(최고배출) 회피 절감액 > 구독료.

**보강2 — 조직역량 보강 (조직역량↑)**
- 4인 코어(데이터분석 대표 + 풀스택 2)는 SaaS 자체구현 충분. 탄소·검증 도메인 공백은 **자문단으로 보강**: 가천대 환경·산업공학 교수 자문 + CBAM 검증기관(KFQ/KTR 등) 파트너십 + 경과원/차세대융합기술연구원 멘토링(공고 액셀러레이팅 제공). → "양산 아닌 데이터·소프트웨어 레이어 + 도메인 자문"으로 4인 실현 범위 내.
- 검증은 우리가 하지 않고 **인증검증기관 연계**(리스크·인력 외주화) → 4인 부담 최소.

**보강3 — 도민 30초 카피 (기획성·도민코멘트↑)**
- 기존: "제품단위 탄소발자국 데이터..." (어려움)
- 개선: **"유럽이 우리 동네 수출공장에 '탄소세'를 매깁니다. 배출량을 못 내면 가장 비싸게 매겨집니다. CarbonRoot는 공장이 30분 만에 '우리 제품 탄소량'을 증명해 세금을 깎고 수출을 지킵니다."**

→ 보강 반영하여 Gate A·B 재심사.
