# Phase 2 — 과학·레드팀 컬링 (Round 1)

> 컬링 렌즈: (1) 과학/기술 실현성(4인·18개월) (2) 데이터수집 해자 진짜인가(LLM/기성SaaS가 복제 불가?) (3) 레드팀 치명결함 (4) 글로벌 TAM (5) R3 위반 (6) founder-market/조직역량.

## 생존 (7개)

### S1. CBAM 협력사 제품단위 탄소데이터 수집·산정·검증·전달 SaaS (raw#1/30)
- 과학: 배출산정은 LCA/EU 산정식(확립된 공식) → 학생팀 구현 가능. 데이터수집 UX·검증워크플로우가 핵심.
- 해자: 협력사가 입력한 **라인·품목·공정별 1차 배출데이터**는 외부·LLM이 못 만듦 → 축적될수록 emission factor 라이브러리·벤치마크 독점.
- 레드팀: 글로벌 탄소SaaS(CarbonChain 등) 존재 → **반박: 그들은 EU 대기업/수입자向, 한국 중소 협력사의 제품단위 1차데이터 입력·검증·전달 공백은 미점유**(koreatechdesk 근거).
- 글로벌: CBAM은 전세계 對EU 수출국 공통 → TAM 글로벌. R3 위반 없음. **생존(최강).**

### S2. 중소제조 설비 운전·고장 1차데이터 → PdM 데이터셋 해자 (raw#8/10)
- 과학: 엣지 수집은 가능하나 **고장 라벨 데이터 수년치 부재**가 본질 장벽(HelloT). 소량학습 기법 있으나 정확도 리스크.
- 레드팀: 데이터 모으는 동안 매출 공백 길다. 센서 레트로핏=하드웨어 의존. → **생존하되 약점 표시.**

### S3. 공장 불량/품질 데이터 라벨 자동축적 데이터셋 (raw#9)
- 과학: 비전 라벨링 가능. 해자: 공장별 불량 이미지+공정파라미터 짝데이터 독점.
- 레드팀: 비전검사 솔루션 레드오션(코그넥스/씨메스 등). 차별성=데이터셋이나 lock-in 약. **생존(차순위).**

### S4. 멀티규제 1소스 ESG 1차데이터 수집 (raw#30) — S1의 확장형
- CBAM+DPP+CSRD를 한 번 수집으로 대응. 강력하나 18개월 4인엔 범위 과대 → **S1의 로드맵 후반으로 흡수.** 단독 생존 보류.

### S5. CBAM+에너지원가 동시최적화 (raw#26)
- 탄소데이터로 비용절감+규제대응 동시 가치제안 → S1의 ROI 강화 모듈로 흡수 가능. **생존(S1 보강요소).**

### S6. 제품 탄소발자국(PCF) 자동산정 글로벌 바이어 응답 (raw#29)
- 글로벌 바이어(애플/EU 유통 등)가 협력사에 PCF 요구 → CBAM 외 수요. S1과 데이터 동일 → **S1 확장 시장으로 흡수.**

### S7. 가명정보 결합 신청·관리 자동화 (raw#21)
- 규제 lock-in 있으나 시장 협소·B2G 영업난이도↑·데이터수집 해자 약. **생존하되 하위.**
