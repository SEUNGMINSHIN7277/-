# DIAMOND-FORGE 공유 컨텍스트 (모든 도메인 에이전트 필독)

> 이 파일은 5개 도메인 채굴 에이전트가 공통으로 따르는 **채점 기준·규칙·팀 컨텍스트**다.
> 출처: 2026 경기 창업 공모 「G스타 오디션」 "도약리그" 모집공고 원문(HWP) + DIAMOND-FORGE 프롬프트.

---

## 0. 공모전 사실 (HWP 원문에서 추출 — 확정)

- **공고명:** 2026 경기 창업 공모 「G스타 오디션」 "도약리그"
- **주최/주관:** 경기도 / 경기도경제과학진흥원(경과원)
- **접수:** 경기스타트업플랫폼(gsp.or.kr), 2026.6.8(월) ~ **6.30(화) 15:00** (오늘 2026-06-29 기준 마감 D-1)
- **단계:** 모집공고 → 예선(서류, 30팀 내외) → 본선(발표, 15팀) → 액셀러레이팅(9월) → **결선(발표, 4팀 입상)** @ 2026.10.14(수) 수원컨벤션센터, 경기스타트업서밋 **현장 공개 심사(전문가+도민 평가단)**
- **참가분야:** AI, ICT, 반도체, 모빌리티, 친환경·에너지, 로봇, 바이오·헬스 등 기술·지식·신산업 사업화 아이템
- **자격:** 경기도 거주 예비창업가 또는 경기도 소재 7년 이내(**신산업분야 10년 이내**) 창업기업 대표
  - 예비창업: 공고일 기준 본인 명의 사업자등록 없음, **대표 포함 4인 이하**(대표 단독 가능), 대표가 경기도 거주(주민등록등본), 팀원 전원 사업자등록 없을 것
- **시상(총 5,000만원, 세금포함):** 대상 1팀 2,000만 / 최우수 1팀 1,500만 / 우수 1팀 1,000만 / 장려 1팀 500만
- **혜택:** 경기스타트업서밋 부스·밋업, SNS 홍보, 경과원 지원사업·공간 우대, 결선진출자 액셀러레이팅(교육·멘토링)
- **방향성(중요):** 공고가 **"글로벌 스타트업 박람회 연계, 해외시장 진출 기반 마련"**을 명시 → 모든 다이아몬드는 **글로벌 TAM + 해외 진출 시나리오** 필수.

## 1. 평가항목 (R1) — 역공학 채점 함수

| 평가항목 | 추정배점 | 채점 포인트 |
|---|---|---|
| 기획성 | 20 | 문제정의 날카로움, 독창성·논리, 신산업 부합 |
| 사업성 | 25 | 수익모델·단가·원가·마진, 첫 매출 현실 경로, 실현가능성 |
| 성장성 | 20 | TAM/SAM/SOM, 확장성, 글로벌, 5년 스케일 |
| 시장진출 | 20 | GTM, 초기고객/파트너, 진입장벽 돌파, 경쟁우위 |
| 조직역량 | 15 | 팀 구성·전문성, 트랙레코드, **4인 이하 실현 범위** |
| 합계 | 100 | |

> 사업성·실현가능성을 가장 무겁게. 성장성·차별성이 약하면 탈락. **두 축 모두 8.5/10 이상이어야 다이아몬드.**

## 2. 가산점 (R2) — 예선 서류 최대 4점 (합산 총점 최대 100)
- 여성 대표 +2 / 장애인 대표 +2 / 사회적기업 +2 / **청년 대표(만19~39) +0.5**
- → 본 팀은 전원 가천대 재학생 → **청년 가산점 +0.5 확보 가능**(증빙: 주민등록). 여성/사회적기업 해당 시 추가.

## 3. 참가 제외 (R3) — 해당 시 아이디어 즉시 폐기
- 타인 **지식재산권 침해 우려** 아이템 / **게임 업종**(별도 개최) / **사행성·환경오염 유발·반사회적** 아이템
- 과거 본 사업(변화와기회/새로운경기 창업공모) 입상자 / 유사 아이템 누적 상금 1억원 이상 수상자
- → 모든 다이아몬드는 IP 클리어런스 통과 + 게임/사행성/환경오염 아님을 명시.

## 4. 경기도 자산 레버리지 (R5) — 가점·실현가능성↑
판교 테크노밸리(AI·ICT), 용인·평택 반도체 클러스터, 차세대융합기술연구원, 경기도 제조 중소기업 밀집(스마트제조·로봇 실증), 수소·신재생 실증단지, 경과원 지원망. 각 다이아몬드에 "경기도 레버리지 포인트" 1줄 이상.

## 5. IP 리스크 (R6)
공고: 참가신청 후 공개된 아이디어는 법적 보호 불가. → 각 다이아몬드에 IP 전략(특허/영업비밀 우선순위, 공지예외 12개월) 포함 + 제출 전 핵심 청구항 비공개/출원 검토 권고.

## 6. 팀 컨텍스트 (조직역량 채점 시 반드시 반영)

- **대표 김범수** — 가천대 AI·산업공학 복수전공. 빅콘테스트에서 신한카드 데이터로 마케팅 AI 챗봇 구현, 세종시 경진대회 수상. **AI/데이터 분석·기획 강점.**
- **공동창업자·개발 신승민·송채우** — 가천대 소프트웨어학과. UMC 대학연합개발동아리 개발팀장, 정보처리기사·리눅스마스터. **소프트웨어/풀스택 구현 강점.**
- **소재지:** 가천대(성남시 수정구) = **경기도 → 자격·레버리지 충족** (가천대 창업지원단, 성남 판교 인접).
- **단계:** 예비창업(아이디어 단계), 전원 재학생, 4인 이하. **청년 가산점 +0.5.**
- **보유 자산:** 기존 아이템 **"다시(Dasi)"** — 딴짓 차단이 아니라 *복귀의 마찰을 0으로* 만드는 '복귀 엔진'(이탈→복귀 행동 데이터 해자, Leroy&Glomb 2018 학술 근거). founder-market fit("내가 이탈자였다") 강함.

### 팀 적합성 현실 (정직하게 채점에 반영)
이 팀은 **AI/ML·데이터·소프트웨어 구현**에 강한 학생 팀이다. 하드웨어 양산·반도체 공정·중장비 로봇·환경 플랜트는 **자체 양산 역량이 약하다.** 따라서:
- AI·빅데이터 도메인: 조직역량 점수 **높게** 줄 수 있음(자체 구현 가능).
- 로봇·반도체·자원순환 도메인: **"소프트웨어/AI 레이어로 진입하는 쐐기"**(하드웨어는 파트너·기성품 활용)로 설계해야 조직역량 점수가 산다. 순수 하드웨어 양산 아이디어는 4인 학생팀 실현불가 → 폐기.

## 7. 두 심사 관문 (다이아몬드 확정 필수)

### Gate A — 글로벌 딥테크 VC (7인: Sequoia/a16z/Founders Fund/Khosla/Lux/DCVC/한국딥테크VC형)
- 각 VC가 텀시트 YES/NO + 한 줄 이유. **통과: 5인 이상 YES** + "1조 회사 가능" 서사.
- 점검: Why now / 비선형 성장 / 해자 / 팀-시장 적합 / 다음 라운드 가치상승.

### Gate B — 경기도 실심사 시뮬레이터 (가중치 최상)
- R1 rubric 100점 채점(항목별 점수+근거) + 가산점 반영 + R3 위반 점검 + 도민평가단 코멘트("전문용어 없이 30초에 이해? 우리 삶/지역에 와닿나?").
- **통과: 총점 ≥ 90/100 AND 5개 항목 모두 ≥ 항목만점의 80% AND R3 위반 0건.**

### 다이아몬드 확정 조건 (AND 전부)
Gate A 통과 ∧ Gate B 통과 ∧ 과학 킬 0건 ∧ 레드팀 치명결함 모두 반박 가능 ∧ **4인 이하 18개월 내 MVP 가능.**

### 자기개선 루프 (타협 없는 반복)
Gate 미통과 시 버리지 말고 실패 사유를 입력으로 Phase 4(컷팅)로 되돌려 보강 후 재심사. **최대 2회 재시도.** 그래도 미달이면 폐기하고 차순위 생존 아이디어로 진행. **도메인당 반드시 기준 통과 다이아몬드 1개를 확정할 때까지 반복.**
